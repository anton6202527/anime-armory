# 画漫画使用手册

入口 skill：`comic`。产物放在 `创作区/画漫画/<作品名>/`。适合原创漫画、源本改漫画、脚本改漫画、条漫/页漫排版、出图、嵌字、导出和审查。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 从点子开始 | “做一部条漫，主角是县衙女捕快，先建项目。” |
| 源本改漫画 | “把这篇小说前两章改成条漫。” |
| 继续项目 | “继续 `创作区/画漫画/那妖魔是姜大人`，看第2话状态。” |
| 做排版 | “第1话脚本好了，生成条漫 layout 和气泡槽位。” |
| 出图 | “根据 panel_script 生成第1话出图包。” |
| 嵌字导出 | “把第2话嵌字并导出长图。” |
| 审查 | “检查第2话阅读顺序、文字遮挡、角色一致性。” |

## 推荐流程

1. 选择输入模式：原创漫画、源本改漫画、脚本改漫画。
2. 漫画脚本：分话大纲、panel_script、角色/场景/道具设定。
3. 页面排版：layout、阅读顺序、格子坐标、气泡占位。
4. 一致性资产：角色定妆、多视图、禁漂移项。
5. 出图：逐格 prompt/job 包，出图后 post-QC。
6. 嵌字：用 lettering.json 后期绘制文字，不把正文烘焙进图里。
7. 导出/审查：页面图、长图、export_manifest、comic-review。

## Demo

已有项目：`创作区/画漫画/那妖魔是姜大人`。

可试：

```text
检查 创作区/画漫画/那妖魔是姜大人 第2话 是否可以作为发布候选。
```

这个 demo 已完成两话条漫：脚本、排版、出图、嵌字、长图和审查都齐，适合学习漫画闭环产物。

## 避坑

- 漫画最小单位是 panel/格，不是视频 clip。
- 台词、旁白、拟声词优先后期嵌字，方便改文和审遮挡。
- 长线角色进入批量生产前要补专门定妆和多视图。
- 发布前再复核字体、素材授权、平台尺寸和切图规则。
