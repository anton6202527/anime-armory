# 拍广告使用手册

入口 skill：`ad`。产物放在 `创作区/拍广告/<项目名>/`。适合把一句客户需求或完整 brief 做成广告片：创意、脚本、VO、分镜、产品定妆、出图、图生视频、剪辑包装、cutdown、质检。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 一句话立项 | “给星盒手账 App 做一条 30s 抖音广告，先零成本 demo。” |
| 创意策划 | “先出 3 个 big idea 和投放变体。” |
| 脚本/广告法 | “写广告脚本，并检查绝对化用语和 claim 风险。” |
| VO | “先用 estimate 占位配音，正式前再换真实 VO。” |
| 分镜 | “按真实 VO 时长重排 storyboard。” |
| 出图 | “先跑 producer_pack、platform_pack 和 ad-score，再生成出图 prompt。” |
| 交付 | “素材齐了，剪主片、15s、6s 和 9:16 版本。” |
| 质检 | “跑 M0 质检，检查广告法、产品漂移、AI 披露和交付矩阵。” |

## 推荐流程

1. Brief：品牌、产品、卖点、受众、平台、时长、强制项、法律声明。
2. 创意：big idea、一句话主张、情绪路线、KV/投放变体。
3. 脚本：广告脚本、VO、时间轴，先过广告法机检。
4. VO：占位可做 demo；正式分镜前用真实 VO 驱动时长。
5. 分镜：storyboard、镜头时长、字幕。
6. 制片前控：producer_pack、platform_pack、ad-score。
7. 出图：产品/品牌/场景三层定妆，逐镜首尾帧。
8. 出视频：模型路由、图生视频、video_qc。
9. 合成交付：主片、cutdown、多比例、品牌包装。
10. M0 质检：投放前硬项检查。

## Demo

已有项目：`创作区/拍广告/星盒手账App`。

可试：

```text
继续 创作区/拍广告/星盒手账App，先不要花钱，告诉我出图前还要检查什么。
```

这个 demo 已走到出图 prompt 包：brief、创意、脚本、真实 VO、分镜、producer_pack、platform_pack、ad-score 都已有，真实 PNG 和图生视频尚未生成。

## 避坑

- 广告不拆集；多时长、多比例是交付件矩阵。
- 产品包装、logo、App UI 是最严格资产，必须结构化绑定 `PROD_*` / `BRAND_*`。
- 绝对化用语、医疗/功效 claim、对比数据必须有依据。
- 零成本 demo 可以先走到 storyboard，但正式出图/投放前必须补真实 VO、授权和合规。
