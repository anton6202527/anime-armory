# 制漫剧使用手册

入口 skill：`n2d`。产物放在 `创作区/制漫剧/<剧名>/`。适合把小说、源书或故事项目改成 AI 漫剧/短剧：剧本改编、配音/时长、分镜、出图、图生视频、可选合成和验收。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 小说转漫剧 | “把这本小说改成 AI 漫剧，先做前 3 集 demo。” |
| 继续某集 | “继续 `创作区/制漫剧/那妖魔是姜大人` 第3集，先查 gate。” |
| 只做前期 | “先不花钱，完成源理解、开发包、剧本和分镜。” |
| 出图 | “第 1 集素材齐了，进入 n2d-image 前先查 image gate。” |
| 出视频 | “第 3 集视频前置通过后，准备 video prompt 和模型路由。” |
| 验收 | “审第 1 集成片，重点查脸漂、接缝、字幕和发布债务。” |

## 推荐流程

1. 源理解：确认现代白话理解、爽点承诺、人物动机、伏笔和改编边界。
2. 开发包：系列 bible、改编策略、前几集追更弧、试播绿灯。
3. 阶段1：剧本改编，产 voiceover、角色/场景/style、BGM、封面。
4. 配音/时长：按制作模式决定真实配音、占位时长或原生音画。
5. 阶段2：导演排戏包 + 分镜设计，产 storyboard、素材清单、字幕。
6. 出图：先过 image gate，再出共享定妆和逐镜 PNG。
7. 出视频：模型路由、图生视频、接缝和身份继承 QC。
8. 可选尾段：合成、review、score、review-ui、release verdict。

## Demo

已有项目：`创作区/制漫剧/那妖魔是姜大人`。

可试：

```text
继续 创作区/制漫剧/那妖魔是姜大人 第3集，告诉我为什么还不能进入合成。
```

这个 demo 展示了长线项目的真实状态机：第 1-2 集已有成片/验收记录，第 3 集在 video gate 和密集脸漂观察处继续收敛。

## 避坑

- 开局必须选制作模式：配音先行、原生音画、先出视频后配音。
- 默认不在开局固定生视频后端，出视频前由 router/probe 决定。
- 占位配音只适合 demo 时长脚手架，正式出视频前要换真实配音并重定时。
- 脸漂、接缝、道具漂移要回源头镜头改，不要直接剪最终 MP4。
