# 传统产品镜手法 → AI prompt 词汇表（ad 线自持）

传统 tabletop/产品广告的工艺在片场靠灯光师和摄影指导执行；AI 流水线里这些工艺**只存在于
prompt 文字里**。本表把实拍手法翻译成可直接写进 storyboard/出图/出视频 prompt 的词汇。
`ad-script/scripts/product_craft_audit.py` 按"光位/质感手法/角度机位"三轴机检产品镜是否声明。

> 快照性质：手法本身是几十年行规不过期；示例 prompt 措辞随模型迭代自行调优。

## 一、光位（光打在产品周围，不是产品上）

| 实拍手法 | 什么时候用 | prompt 词汇 |
|---|---|---|
| 侧光造型 | 一切需要立体感的包装/食物 | 侧光塑形、明暗过渡、立体轮廓（side light, sculpted shadows） |
| 逆光穿瓶 | 透明/半透明液体（酒/饮料/精华液） | 逆光穿透瓶身、液体内发光、premium 辉光（backlit bottle, lit-from-within glow） |
| 轮廓光/rim | 深色背景上勾产品边缘 | 轮廓光勾边、rim light halo |
| 柔光罩面 | 酱料/乳制品/皮肤 | 大柔光、高光柔和过渡、丝滑（soft wrap light） |
| 底光/桌面反射 | 高端瓶体、表面带微反光桌面 | 桌面微反射、倒影（reflective tabletop, polyurethane sheen） |

**反面**：均匀正面平光 = 电商白底图。产品 hero 镜 prompt 里不写光位，模型默认就是它。

## 二、质感手法（appetite appeal / 材质欲望）

| 实拍手法 | 什么时候用 | prompt 词汇 |
|---|---|---|
| 300fps 升格浇注 | 饮料/酒/酱汁/牛奶 | 高速升格倾倒、液体慢动作拉丝、飞溅悬停（300fps slow-motion pour, splash frozen mid-air） |
| 微距细节 | 气泡/水珠/纹理/纤维 | 微距气泡上升、瓶身凝露水珠、fizz 特写（macro condensation droplets） |
| 冰爽/热气 | 冷饮/热食 | 杯壁挂霜凝露、腾起热气/蒸汽（steam rising, frosted glass） |
| 拉丝/挂壁 | 芝士/蜂蜜/酱料 | 缓慢拉丝、浓稠挂壁、流动截面 |
| 酥脆断面 | 食品咬口/掰开 | 断面特写、碎屑飞散、酥脆声画同步 |

## 三、角度机位（hero angle）

| 实拍手法 | 什么时候用 | prompt 词汇 |
|---|---|---|
| 45° hero | 大多数包装/食物的默认敬畏角 | 45 度俯角 hero 机位 |
| 低角度仰拍 | 让产品"高大"（瓶装/器械/车） | 低角度仰拍、天空/干净背景衬托（low angle heroic） |
| 环绕/orbit | 展示全貌（电子产品/鞋） | 环绕运镜、匀速 orbit、桌面转台 |
| 滑轨推近 | 从场景推向产品细节 | 缓慢推轨聚焦、浅景深渐入（slow dolly-in, rack focus） |
| top-down | 平铺构成/多 SKU 阵列 | 正俯拍平铺、几何排布 |

## 三·五、焦段语言（传统 shooting board 会标焦距,AI prompt 同样吃这套）

| 焦段 | 视觉效果 | 什么时候用 |
|---|---|---|
| 24mm 广角 | 空间气势、透视夸张 | 场景建立镜、汽车/家电"大" |
| 50mm 标准 | 接近人眼、纪实感 | UGC 风、生活流叙事镜 |
| 85-100mm 人像/微距 | 压缩背景、奶油虚化、产品脱背 | 人物特写、产品 hero、食物 |
| 100mm+ 微距 | 纹理放大、气泡水珠 | 质感特写（配合第二节手法） |

写法示例："85mm 浅景深，产品从虚化背景中脱出" / "24mm 低角度广角,车头透视冲击"。

## 四、接线

- **写进哪**：storyboard 产品镜的 `shot/画面/light/运镜` 字段（`product_craft_audit` 在此机检）→
  `ad-image/plan_prompts` 首帧 prompt → `ad-video/plan_prompts` 运镜 prompt。
- **一致性衔接**：光位一旦声明进 `visual_contract` 光位锚，`inherit_contract.py` 会跨镜校验——
  同一产品 hero 系列别一镜逆光一镜顶光（除非有意）。
- **豁免**：endcard/logo/价格板是静版信息位，要稳定可读不要工艺花活，机检自动豁免。

来源（2026-07 采集）：tabletop 布光与液体拍摄行规见 Mark Roberts Motion Control、
Timothy Hogan（beverage hero shots）、PremiumBeat product-shot 指南、BestBoy Media 300fps
liquid 实践——"light belongs around the glass, not on it"。
