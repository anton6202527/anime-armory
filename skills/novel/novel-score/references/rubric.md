# novel-score 评分细则(维度 / 权重档 / 档位 / 判定)

> 百分制。每维先打 **1-10 原始分**,再 ×(权重/10) 汇成百分。题材热度维度必须对标当次联网拉取的 `评分/market_baseline_*.json`、`评分/题材热榜_<date>.md` 和必要的 `资料/research_sources.json`,不是泛评。

> **多判官去偏（关键稿推荐 ≥3 个不同模型家族；≥2 仍向后兼容）**：LLM 判官有 position bias + 单模型偏（LitBench arXiv 2507.00769 / dual-judge）。量规分按判官内 z 归一去宽严偏再聚合、判官间高方差准则不再只标 low，而是该维度**弃权/升级**；成对比稿要 position-swap（两序判同一赢家才算）+ 多判官一致才采纳。确定性执行层已就绪并**已接进 novel-score**：评估 JSON 里可选附 `"judges_panel": {判官: {维度: 1-10}}`（≥2 判官触发）和 `"judge_families": {判官: "openai/anthropic/google/..."}`（缺省从判官名推断）。`score.py` 自动跑 `judge_protocol.aggregate_rubric` + `family_diversity`，把高方差维度标 `judge_decision: abstain` 写进 `score_report.json` + 评分报告（advisory，不改 raw_score/总分），并在 `next_actions` 提示人工复核或换更强跨家族判官。也可独立跑 CLI：`python3 skills/novel/_lib/judge_protocol.py --verdicts v.json [--panel p.json] [--judge-families families.json]`。见 `novel-supervisor/references/critic-loop.md`。单判官单序直接采信的分数视为 low_confidence。

> **判官去偏·长度/格式中立化（z 归一与换序治不了的头号残留偏差）**：z 归一只纠单判官宽严偏移、position-swap 只治位置偏——但对**所有判官同向**的长度偏好与 markdown/格式风格偏差无效，而这恰是当前 LLM 判官最大的残留偏差（位置偏差在前沿模型已很小）。所以评分 prompt 已硬性要求：**只评内容质量，不因更长/更多排版/辞藻更密而加分**；长度/篇幅相近时，优先比较有效信息增量、人物选择、冲突推进、语言准确度和留存力。注水/重复/过度铺陈一律进 ⑦完读·留存 与雷点扣分，绝不因"字多看着充实"加分。判官打分须对照固定 rubric 锚点，不被呈现形式带偏。`score.py` 另写 `judge_bias_advisory` 做事后提示：只提醒复核长度/格式偏好，不改 raw_score/total_score。

## 八维定义 + 看什么(1-10 锚点)

| 维度 | 看什么(高分) | 低分信号 |
|---|---|---|
| **① 题材热度匹配** | 题材/金手指/人设正踩当下红果·抖音·番茄热榜;套路是上升期不是退潮期;有差异化记忆点 | 题材已退潮/烂大街无新意;与目标平台读者口味错位 |
| **② 开篇黄金三章钩子** | 前300字立冲突/钩子,前3章给身份反转·爽点·悬念,代入快,不铺设定 | 慢热、先交代世界观、主角动机模糊、第1章无钩子 |
| **③ 情绪兑现与阅读动力** | 本作承诺的悬念、情感、主题、幽默或爽感持续递进并兑现；商业爽文再看打脸/逆袭等密度 | 长段落没有推进任何读者承诺，情绪与信息停滞；不得仅因文学/慢热作品“爽点少”扣分 |
| **④ 人物塑造与核心机制** | 人物欲望、选择、关系与变化有辨识度；若有能力/系统等高杠杆机制，其边界和后果能持续制造选择 | 人物脸谱化或行为无动机；核心机制万能到消除张力，或作品无此机制却被强套金手指标准 |
| **⑤ 剧情结构与主线张力** | 主线清晰、目标明确、悬念递进、章末钩子、伏笔有收、不注水，并持续推进 `设定/读者契约.md` 的核心题旨 | 主线散、流水账、注水拖更感、断更/烂尾迹象、东拼西凑，或写着写着偏成另一本书 |
| **⑥ 文学性 / 文笔** | 画面感、show-don't-tell、对白有戏、文风统一、少AI味；文字准确、可感、有人味，并符合读者契约里的文学质感 | 大段直白告知、用词重复、文风漂、AI味/同质化、辞藻堆砌但不服务人物或叙事 |
| **⑦ 完读 / 留存潜力** | 章末cliffhanger硬断、每章有信息增量/卡点、追读欲强、单章信息密度合适，且读者承诺有递进/延迟/兑现；有真实读者反馈时完读/弃读数据支持 | 章末收太干、平淡过渡多、读着想划走、信息密度过低或过载，前文承诺长期不推进；真实反馈低完读/高弃读且找不到合理样本解释 |
| **⑧ 新颖度 / 想象力** | 设定/金手指/题材组合有差异化记忆点（可被读者一句话转述传播）；关键转折"意料之外、情理之中"（回看时伏笔成立、不靠神降）；至少一处让老读者惊到但服气的预期违背；熟悉套路混搭出新切口、结局不落模板 | 全程套路复刻、每个转折老读者都能提前猜中、桥段/结局模板化；或反向翻车——为怪而怪、意外靠 deus ex machina、新颖以撕毁读者契约为代价（此时本维不给分，plot_structure 同步扣） |

## 权重档(按 `目标平台` 选)

每维权重(合计 100)。原始分(1-10)×(权重/10)= 该维百分得分。

| 维度 | 均衡向（平台未定·默认） | 商业爽文向(红果/抖音/番茄) | 品质向(起点/晋江/历史) |
|---|---:|---:|---:|
| ① 题材热度匹配 | 12.5 | 18 | 10 |
| ② 开篇黄金三章钩子 | 12.5 | 16 | 12 |
| ③ 情绪兑现与阅读动力 | 12.5 | 16 | 10 |
| ④ 人物塑造与核心机制 | 12.5 | 12 | 12 |
| ⑤ 剧情结构主线 | 12.5 | 12 | 16 |
| ⑥ 文学性/文笔 | 12.5 | 8 | 16 |
| ⑦ 完读/留存潜力 | 12.5 | 10 | 12 |
| ⑧ 新颖度/想象力 | 12.5 | 8 | 12 |
| **合计** | **100** | **100** | **100** |

> ⑧ 与「AI味/雷同」雷点扣分**互补不重复**：雷点罚下限（雷同到无识别度才扣），本维评上限（有多惊喜给多少分）。同一问题不得两头重复计——已在雷点扣过"与市面雷同"的，本维给低分即可，不再叠罚；LLM 生成文本的已知系统性弱项正是新颖与惊喜（相对人类作者），故此维必须显式评，不能默认及格。判低分后的写作侧修法：前提级发散见 `novel-craft/references/premise-divergence.md` §一–七，**中段新奇衰减**（默认名字/开局/金手指塌缩、机械比喻、结局过早可测）见其 §八——评分弱在 ⑧ 时可据此给具体改写抓手，不止扣分。

> 跨平台/历史向等其它平台:在两档间按"越偏短视频流量越靠商业向、越偏付费深度阅读越靠品质向"插值,并在报告里写明所用权重。

## 类型专项评分尺（防止一把商业爽点尺量全部小说）

基础八维仍保留，但不同类型的“好看机制”不同。评分 prompt 必须先判断主类型，再套下列附加解释；不能把“爽点密度低”直接等同于“差”。

| 类型 | 高分关键 | 误判风险 | 额外扣分 |
|---|---|---|---|
| 悬疑 / 刑侦 | 谜面公平、线索递进、嫌疑人动机、人证物证链、反转后可回看 | 慢热铺证不等于注水 | 神降解释、关键证据未提前埋、警方/法医流程外行 |
| 硬科幻 / 科技 | 核心假设清晰、技术约束稳定、人物选择受科学规则挤压 | 说明密度高不必然扣分，但必须服务情节 | 规则随剧情变、科技术语堆砌无戏剧功能 |
| 文学向 / 现实主义 | 观察精度、人物复杂度、语言辨识度、题旨余味、社会肌理 | 无打脸爽点不等于弱 | 人物只作观点传声筒、主题说教、生活细节虚浮 |
| 历史 / 传统文化 | 时代 register、制度/器物/礼法可信、历史缝隙里的个人选择 | 节奏可较缓，但不能掉书袋 | 古今语体串味、考据压过人物、硬改历史因果无标记 |
| 恐怖 / 惊悚 | 气氛递进、未知感、禁忌规则、感官不适、揭示克制 | 信息保留是技法，不是交代不足 | 过早解释、只靠血腥、规则不稳定 |
| 言情 / 纯爱 / 情感 | 关系推进、拉扯逻辑、情绪兑现、亲密边界、人物尊严 | “无事业爽点”不等于弱 | 工业糖精、误会拖延无新信息、角色为虐而降智 |
| 群像 / 家族 / 史诗 | 多线角色功能差异、弧光交叉、势力变化、主题回声 | 单章主角不强不一定扣分 | 角色脸盲、线索久不回流、主线失焦 |
| 轻松 / 搞笑 / 沙雕 / 吐槽流 | 笑点密度且新鲜、吐槽/系统腔一致有戏、反差萌立体、喜剧节奏（包袱抖在末尾就收）、情绪价值=轻松解压 | **"无强爽点/无虐点"不等于弱**——别拿商业爽文打脸密度尺量轻松文，读者要的是"追得轻松" | 强行玩梗/尬笑、时效热梗过期显尬、拿弱势或三观开涮、该严肃的情感高点乱抖机灵泄情绪（评分尺见 `novel-craft/references/喜剧与轻松感.md`） |

评分报告需在“权重档”后写一句：本次使用的类型解释是什么、哪些维度被调档。若项目有 `novel-aesthetic` 样本库，品质向/文学向/历史/悬疑项目应引用其中 1-3 条正向审美样本作为 prose/structure 维度的辅助标尺。

## 雷点扣分项(命中即在总分上再减,单独列)

不是维度,是**红线/退潮信号**,每条按程度 −3 ~ −10:

- 开篇慢热(前3章无钩子) −5~10
- 题材已明显退潮/被平台限流 −5~10
- 主角降智 / 圣母 / 恋爱脑(商业向尤其致命) −3~8
- 注水拖更、单章无信息增量 −3~8
- 题旨偏移 / 读者承诺违约（连续多章不推进核心题旨或偷换开篇承诺）−4~10
- 三观/平台内容风险候选 −5~10（须引用当前平台规则并人工看上下文；关键词命中不得直接判弃稿或封禁）
- AI味重 / 与市面雷同到无识别度 −3~6
- **题材红海 / 同质化饱和**（题材即便在上升期，但当次可追溯市场证据显示同类拥挤，本作又无差异化切口）−3~8。注意与"退潮"区分：退潮=热度在降；本项=**热但挤**，热度高 ≠ 该做。没有来源、日期和可核验口径时只能写待验证假设，不得虚构 ROI 行业数字。
- 文学质感明显不匹配目标平台（品质向尤重）−3~8
- 烂尾 / 明显断更感(完本评估时) −3~8
- 类型误判风险：用商业爽文尺强扣文学向/悬疑/硬科幻慢热，或用文学尺忽略短视频源书前三章留存需求，需在报告中修正，不得直接扣分。

## 书名体检（附加体检项，不计入百分制总分）

评分时若 `_meta.json.title` 已定名，**顺带体检现有书名**——维度沿用 `novel-title/references/title-patterns.md` 的 5 维（各 1-5 分，满分 25）：钩子 / 平台契合 / 角色识别 / 抗撞名 / 可记忆性。

- **不进总分**：书名换起来便宜，不该拖累稿子本身的档位与判定；单列在报告里。
- **抗撞名只做初判**：score 阶段凭常见度估 + 读已有的 `设定/书名撞名检查_*.json`（novel-title 落的）；联网查重仍归 `novel-title`。`unchecked ≠ 不撞名`。
- **needs_rename 条件**：总分 < 15/25，或撞名检查为 `hard_collision`，或 LLM 显式判 needs_rename。
- **路由**：needs_rename 且判定非「弃稿重立」→ `next_actions[]` 追加 `novel-title`（重出候选 + 联网撞名检查）；弃稿重立时不路由（重开自带新名）。
- 书名未定 → 跳过本项，报告里建议先用 `novel-title` 起名。
- **本 skill 只体检现有书名、不出候选**——候选生成 / 排名 / 回写 `_meta.json.title` 全归 `novel-title`。

## 档位 + 判定 + 改写ROI

| 总分 | 档位 | 判定 | 改写ROI 建议 |
|---|---|---|---|
| **≥85** | 爆款潜力 | **过** | 微调即可投/继续写;别过度打磨耽误更新 |
| **70–84** | 合格偏上 | **小改** | 高ROI:润色 + 强化最低的1-2维(常是开篇钩子/爽点),委托 `novel-expand` 或自润 |
| **55–69** | 及格线下 | **大改** | 看题材:**题材对+主线有救**→值得结构级改写(`novel-rewrite` 改主线/换设定,或 `novel-continue` 救烂尾);**题材退潮**→ROI低,倾向重立 |
| **<55** | 不及格 | **弃稿重立** | 多数情况硬改不划算:题材/主线换掉重来更快,委托 `novel-create`;仅当核心创意真有亮点才保留要素重写 |

> 这些分界是内部编辑量规，不是经平台校准的成功率阈值。`过/小改/大改/弃稿重立` 与兼容字段 `go/revise/kill` 均为 advisory；不得单独阻断写作、导出或发布。样本不足、判官高方差、目标平台未定或市场证据薄弱时，应优先输出“不足以裁决”并交作者确认。

**判定必须显式回答用户的两问**:
1. **能不能火**:总分+档位+对标热榜一句话结论。
2. **要不要继续改、改哪**:判定 + 改写ROI + 具体到"改第几章、补哪几维、委托哪个 skill"。

## 报告结构(`评分/评分报告_<date>.md`)

1. **概览表**:八维原始分/加权得分 + 雷点扣分 + 总分 + 档位 + 判定(一屏看完)
2. **逐维**:得分 / 证据引文(原文) / 短评 / 改进抓手
2.5 **书名体检**(附加项):5 维分 + 撞名状态 + 换名结论(见上节)
3. **真实读端证据 / 合成探针分栏**：若有 `reader_telemetry_summary.json`，列完读/弃读/weakest_chapters；若有 `reader_panel_signals.json`，另列为 synthetic/context-only，不混入经验数据，也不自动调分
3.5 **跨章重复率/机械文风先验**(确定性·喂 ⑦完读/留存):score.py 用 `novel/_lib/repetition.py`（与 novel-review 同一真值源）对已加载章节算相邻章 shingle Jaccard 近重复 + 机械开篇 + 跨章整句复用 + **句首句式模板复现** + **句首词高频** + **短句式模板** + **全书/每章 zlib 压缩比(文本多样性代理)** + distinct-n 辅助指标，折成 `repetition_prior`（档 none/mild/elevated/high·负向调分上限 -3·internal-heuristic 非平台硬数字）注入评估 prompt 作 ⑦ 维**负向先验**并计入 `reader_feedback_adjustment`（平台对 AI 内容做连续章节重复率/机械文风质检·高重复/低多样性=弃读信号）。机检只给信号，最终分仍以判官对正文判读为准。
4. **参考分布百分位**:若有合规 reference distribution，列总分百分位与弱项维度百分位
5. **读者契约对齐**:对照 `设定/读者契约.md`,说明核心题旨、读者承诺、文学质感是否被正文兑现
6. **类型专项解释**:说明是否按悬疑/硬科幻/文学向/历史/恐怖/言情/群像等调档，避免误用爽点尺
7. **审美样本参照**:若有 `设定/aesthetic_bank.json`，引用可迁移规则，不复制样本文字
8. **题材热榜对标**:引用 `题材热榜_<date>.md`,点名"踩中/错过/踩雷"了哪些当下热点,标基准日期和证据质量
9. **判定 & 改写ROI**:能不能火 + 要不要改 + 改哪 + 委托路由
10. **下一步**:具体 skill 调用建议(`novel-rewrite`/`novel-expand`/`novel-continue`/`novel-create` → 之后 `novel-review`)
