# 公开对质 / 审讯 / 谈判 / 智斗场景专项

用于章纲命中公开对质、当众揭穿、公堂朝堂、审讯逼问、谈判交易、权谋智斗等场景。对质场的核心不是吵架，而是“筹码递进造成权力翻转”。

## 总原则

1. 开场先立赌注：输的人会失去什么，赢的人能拿到什么。
2. 写清现场规则：谁有裁决权，谁能作证，谁能打断，谁在围观。
3. 每轮只推进一个筹码：证据、口供、把柄、利益、时间、武力、亲情或名声。
4. 每轮都要有反应：沉默、反驳、改口、倒戈、失态、反击或转移话题。
5. 结尾必须落到新行动：定罪、交易、逃脱、灭口、结盟、割席或更大嫌疑。

## 公开对质 / 当众打脸

- 让围观者有功能：见证、施压、站队、误导、拦截或递证。
- 证据不要一锤定音太早；先给对方一次合理反扑，再用下一层证据压住。
- 打脸句要短，落在权力翻转之后，不要靠长篇台词制造爽点。
- 被打脸者必须带走后患：仇恨、灭口、求援、装弱、假认输或反设局。

## 审讯 / 逼问

- 逼问者有筹码，被问者有底线；双方都要能改变策略。
- 问题不要重复，每一问都逼近一个可验证信息。
- 谎言要留下裂缝：时间、称谓、细节、反应速度、证物位置或第三方证言。
- 结尾不要只拿到口供，要决定下一步如何使用这份信息。

## 谈判 / 智斗

- 双方都要有底牌和误判，不能只有主角聪明、对手降智。
- 谈判写“可让步项”和“不可让步项”，让交换有重量。
- 智斗要有至少一次反信息差：对方以为掌握了秘密，主角其实提前设了局，或反过来。
- 胜利要留代价：让出资源、暴露底牌、欠下人情、激怒强敌或埋下反噬。

## 写完自检

- [ ] 开场赌注是否清楚？
- [ ] 每一轮是否都有新筹码，而不是重复嘴硬？
- [ ] 权力位置是否至少翻转一次？
- [ ] 对手是否有像样反扑？
- [ ] 证据归属、交易条款、把柄、敌我变化是否写入 `state_delta`？
