# 对话工艺：潜台词 · 归属 · 一人一腔 · 信息差

`chapter.md` 限「纯对话 ≤ 1/3」、`relationship-scenes.md` 管「关系场景里说什么」，本篇管**对白本身怎么写得有戏**——好的对白不是把信息说清楚，是让读者在"说出口的"和"没说出口的"之间读出张力。写章、`relationship/confrontation/reveal-scenes` 落地、`novel-review` 查「对白无戏/角色一个腔/talking heads」时都读。

> 一句话法则：**对白承载的应是潜台词与博弈，不是信息播报**。能用动作演的别用嘴说；能让读者自己听懂的别让角色解释。

## 一、潜台词（话里有话）——对白的命根

人物**几乎不直说**真实意图。表层在聊 A，底下在争 B。读者听懂落差，才觉得"有戏"。

- **要的 ≠ 说的**：角色想求和，嘴上却挑刺；想挽留，嘴上却说"你走"。让动作/停顿暴露真意（"'随你。'她转身时，手还攥着他的袖口"）。
- **冲突藏在客气里**：越是高张力场合（谈判/质问/掉马），越用克制的话裹住锋芒——绵里藏针比对骂有张力。当众打脸的句法见 `confrontation-scenes.md`。
- **三种制造潜台词的手**：① 答非所问（问的是事，答的是态度）；② 言不由衷（嘴上认怂、行动打脸）；③ 留白（该接的话不接，沉默即态度）。
- ❌ **大白话直给**："我现在很生气因为你骗了我。"——把潜台词说破=没戏。改成行为+短句。

## 二、对白归属（attribution）——透明不抢戏

提示语（dialogue tag）的作用是**让读者不迷路**，不是炫技。

- **"说/道"是透明词**：读者会自动略过，正是它的优点。别为避免重复而堆"咆哮道/讥诮道/幽幽地说"——花式提示语反而打断阅读、替读者下判断。
- **优先用动作节拍（action beat）替代提示语**：`她把茶杯搁下。"那就这样吧。"` ——既标明谁说，又给画面、给情绪，还控制了节奏。这也顺手满足 `chapter.md` 的"反 talking heads / 空间锚点"。
- **副词提示语是警报**：`"我无所谓，"他冷漠地说`——"冷漠地"是在告诉读者该有什么感受，说明对白本身没演出来。删副词，让台词和动作自己证明。
- **三人以上对话**：靠**说话方式差异**（见下）+ 间歇 action beat 区分，而不是每句都挂名字。
- **别一路裸奔**：连续多轮纯引语（无 tag、无 beat、无行内称呼）读者会数不清谁在说——每几轮用 tag 或动作 beat 重新锚定；连续多轮对话零 beat 则是 talking heads（人物成了白房间里的悬浮头），每隔几轮让对话落回身体和房间。
- 机检对应（`dialogue_craft_audit`，全 advisory）：`said_bookism`（华丽说话动词密度）、`untagged_dialogue_run`（连续纯引语跟丢）、`talking_heads_run`（连续无 beat 悬浮）；副词提示语归 `prose_craft` 的 `adverb_dialogue_tag`。

## 三、一人一腔（角色语言指纹差异化）

把所有对白的提示语遮住，读者**仅凭说话方式**就能认出是谁——这是对白的高线。每个主要角色立 2-3 条**语言指纹**，写进 `角色卡.md` 的"口吻习惯"段（见 `setting-bible.md`）：

| 维度 | 差异化举例 |
|---|---|
| **句长 / 语速** | 急性子短句连发；城府深的人话少而慢、爱用反问 |
| **词汇层** | 读书人用典雅词；糙汉爆破口语；古人不说现代词（与 `描写.md` 文白register联动） |
| **口头禅 / 句式** | 标志性起手式或尾音（≤10 字，派生作品可保留，见 `chapter.md`） |
| **回避 / 攻击习惯** | 有人靠装傻回避，有人靠抬杠攻击，有人永远绕开正题 |
| **身份烙印** | 职业/阶层/地域渗进用词（医者爱用病理比喻、商人开口算账） |

- **自检法**：抽一段多人对话，把名字和提示语全删，自己能否分辨各句出自谁？分不清=角色一个腔，回去给指纹。
- **群像层面**：声音只是配角辨识度三维之一（功能/声音/标记），多角色同台不糊成一团的调度见 [`群像与角色弧光.md`](群像与角色弧光.md)。
- ❌ **作者腔统一**：所有人都说着同样机灵/同样文艺的话——这是 AI 味高发区（见 `去AI味.md`），也是 `novel-review` 的 `prose/对白无戏` 重点。

## 四、信息差对白（谁知道什么）

对白张力的一大来源是**在场各方掌握的信息不对等**，读者居高临下看着"说话的人不知道的事"。

- **三种差**：① 角色 A 知、B 不知（A 试探/隐瞒，读者替 B 捏汗）；② 读者知、台上双方都不知（戏剧性反讽，章末信息钩的延伸，见 `hooks.md`）；③ 双方都在演、都以为骗过对方（双重潜台词）。
- **掉马/揭示场景**：靠对白一层层逼近真相，证据链分批抛，别一口气说穿——节奏见 `reveal-scenes.md`。
- **写之前先问**：这场对话里，**每个人各自知道什么、想让对方以为什么**？把这张"信息地图"理清，台词自然有张力。
- **信息地图不用每场重推**：项目若建了知情账 `设定/knowledge_ledger.json`（`novel-wiki/knowledge_sentry.py` 维护），写章包会自动注入在场各方的知情面（谁知道/谁怀疑/谁误信/读者站哪层）；对白造成知情变化后记得记账，机检才能拦"不知情者说破"这类穿帮。

- [ ] 提示语是不是"说/道"+action beat 为主，没堆花式提示语和副词？
- [ ] 遮住名字，主要角色的话能凭口吻认出来吗？

## 五、微张力：每一页的对白摩擦（Donald Maass）

情节层的冲突≠line 级的张力。Maass 判据：**逐页问"这一页哪里有张力"**——对白里的张力不来自吵架，来自**抵抗**：

- **三种摩擦形态**：① 顶回去（拒绝/异议/反问——"凭什么"）；② 岔开（答非所问、转移话题——问案情他谈天气）；③ 收住不说（"此事休提"、话到嘴边咽回去）。
- **反面形态＝全员合作直答**：有问必答、句句配合、零异议——整场对话像接力赛交棒，读者在平路上走。哪怕是盟友闲聊，也要有人误读、有人分心、有人藏了半句。
- **矛盾情绪也算张力**：一个角色同时想留下又想逃、边笑边攥拳——情绪自相矛盾比情绪单一更抓人。
- **机检对账**：`novel-review/dialogue_craft_audit.py` 会标出**整章零摩擦**（frictionless_dialogue）与**直给对白**（on-the-nose：情绪+因果同句说穿）候选——机检只逮形态，"这场戏就该直给"（摊牌/告白高潮）是合法豁免，人判取舍。

- [ ] 有没有一句"说了一半收回去"的话？
