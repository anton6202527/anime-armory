# 动作场景专项写作法

适用于章纲命中打斗、追逐、逃亡、突破、升级、渡劫等高动态场景。目标不是把小说写成分镜脚本，而是让读者能清楚感到：谁在哪里、想要什么、付出什么、局势怎样一轮一轮升级。

## 总原则

- **先写目标，再写动作**：开场先交代本场目标（夺物、脱身、拖延、护人、试探、突破），否则动作再多也是噪声。
- **空间可读**：至少写清入口、出口、障碍、距离、遮挡、制高点或退路中的三项。
- **回合推进**：每 300-600 字要有一次局势变化：优势转移、代价增加、信息揭示、环境变化或新变量入场。
- **能力守恒**：角色只能使用已登记能力；临时爆种必须有代价、伏笔或机缘。
- **伤势与消耗留痕**：受伤、体力、灵力、弹药、道具损坏不能下一段自动复原。
- **情绪随动作显形**：用选择和动作暴露恐惧、狠劲、迟疑、保护欲，不只旁白解释。

## 打斗 / 战斗

- **战前信息差**：写清双方目标、战力差、已知限制、误判点。
- **攻防回合**：每一轮包含“动作 → 反应 → 结果 → 新问题”，避免只堆招式名。
- **代价表**：至少出现一种代价：伤势、资源消耗、暴露底牌、误伤、时间损失、关系裂痕。
- **战术变化**：不要连续用同一招解决问题；第二次使用必须被对手适应或付出更高代价。
- **胜负理由**：胜利来自布局、信息、代价或性格选择，不靠作者硬按。

## 追逐 / 逃亡

- **距离账**：写清追逃双方的相对距离如何变化，别让角色凭空追上或甩开。
- **路线账**：至少给一条路线锚：街巷、屋脊、林线、山道、河岸、廊桥、楼梯、门洞。
- **障碍账**：每段追逐都要有障碍或选择：人群、塌桥、雨雪、暗巷、守卫、岔路、伤腿、负重。
- **资源账**：追逐会消耗体力、灵力、马力、载具、道具和隐蔽性；消耗必须影响后续动作。
- **终点压力**：追逐不能无限延长，要有明确终点或倒计时：城门关闭、援兵抵达、毒发、天亮、阵法合拢。

## 升级 / 突破

- **触发条件**：突破来自积累、危机、悟到规则、外部机缘或牺牲，不能凭空升级。
- **阈值可见**：让读者看到“差一点”的边界：经验满、灵力冲关、瓶颈松动、面板提示、旧伤反噬。
- **代价明确**：升级带来代价或限制：透支、反噬、冷却、暴露、欠债、关系风险、境界不稳。
- **收益具体**：不要只写“变强了”；写清新增能力、属性变化、感知变化或打法变化。
- **战力不跳账**：升级后的表现要符合 `power_system_registry.json`；越级必须有代价、机缘或限制。

## 写完自检

- [ ] 本场目标清楚，不是为打而打、为跑而跑、为升而升。
- [ ] 空间、距离、路线或障碍能被读者复原。
- [ ] 每个动作都有结果，每个结果都改变下一步选择。
- [ ] 伤势、消耗、道具损坏和暴露底牌被写入后续状态。
- [ ] 升级/爆种有触发、代价和收益，没有破坏力量体系。
- [ ] 章末钩子承接动作场景的后果，而不是动作结束就清零。
