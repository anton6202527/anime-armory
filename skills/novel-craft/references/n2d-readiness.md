# 漫剧改编就绪清单 (N2D Adaptation Readiness)

如果小说要流向 `n2d` 做漫剧/短剧（2026 主变现路径：红果头部短剧 70-80% 是番茄小说 IP 改编、
番茄设「爆款之源奖/优质原著奖」奖励为改编而生的原著），**小说侧**就该在写作/审稿阶段
确认每章"够不够漫剧友好"，而不是到 `n2d-script` 分镜时才发现细节不足、回小说返工。

这份清单与 [`n2d-asset-aware.md`](n2d-asset-aware.md) 是**两件事**：
- asset-aware 解决"标了什么"——在正文埋 `[CHAR/PROP/LOC/VFX/OUTFIT_*]` 资产标签。
- 本清单解决"够不够拍"——画面感、台词驱动、空间清晰、视觉冲击。

## 机检（确定性候选线索，先跑）

```bash
python3 skills/novel-review/scripts/n2d_readiness_check.py <作品根> [--range 1-100]
```

落 `审稿/n2d_readiness.json`（kind=`novel_n2d_readiness`），逐章给 4 维 + 候选弱章：

| 维度 | 看什么 | 弱信号（候选） |
|---|---|---|
| **资产标签密度** | 每章去重 `[CHAR/PROP/LOC/VFX/OUTFIT_*]` 数 / 千字 | 0 标签 → n2d 盲猜定妆 |
| **对白占比** | 引号内 CJK 字 / 全章 CJK 字 | < 8% 或 < 本书中位一半 → 旁白过重，难配音/分镜 |
| **视觉锚密度** | 视觉高光词（血/光/剑/雾/焰…）命中 / 千字 | < 本书中位一半 → 画面冲击弱 |
| **场景锚** | 去重 `[LOC_*]` 数 | 0 → 空间几何不清晰，分镜无处落景 |

阈值是**绝对地板 + 本书自标定中位**混合：硬地板抓"完全缺失"，相对中位抓"显著低于本书自身水准"
的弱章，不对不同文风一刀切。机检命中是**线索不是定论**——画面感到底够不够由 LLM 读文本复核。

## 人判（机检盖不住的）

- **场景可视化**：关键场景是否有可落图的空间几何（方位/光源/景别暗示），不是纯心理流。
- **人物关系视觉化**：站位/动作/表情能否撑起分镜，而非全靠旁白交代。
- **台词戏剧性**：对白是否推进冲突、能配音出戏，而非信息倾倒。
- **场景转换清晰**：换场有无明确锚点（时间/地点跳转），避免分镜断链。

## 修法回哪

- 缺资产标签/场景锚 → 回 ghostwriter pass 按 [`n2d-asset-aware.md`](n2d-asset-aware.md) 补埋标签。
- 对白过少/画面感弱 → 回 `novel-expand`（事件骨架不变，增厚可视化细节与台词），不是硬加字。
- 整章纯叙述无戏 → 回章纲（[`outline.md`](outline.md)）确认该章是否本就该有戏剧场面。

> 就绪机检是 **opt-in**：只对"将流向 n2d"的项目跑（`_设置.md` 标记或用户指定）。纯小说投放项目
> 不需要漫剧就绪，跑了也只是参考，不作阻断。
