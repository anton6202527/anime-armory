# 前提发散法（怎么"生成 N 个真差异化方案再挑/杂交"）

`novel-create` 的「创意闸 · 蓝图三方案」要求给出 **3 个真差异化方向**（不是 3 种措辞），并做 `套路自查`。
但此前只规定了"要发散"，没给**怎么发散**——一个先验强的模型仍会吐出 3 个近邻方案。本篇补的是**发散的方法**：
把"生成 → 打分 → 挑/杂交"变成可操作步骤，让差异化不再靠碰运气。配套探测器 `novel-review/scripts/trope_cliche.py`
会在开写前提示"这个开局命中高频套路"，本篇给的是"命中之后怎么真差异化"。

> 边界：本篇是**开写前**（blueprint/outline 阶段）的想象力工艺；写出来后好不好看由 `novel-score` 的 novelty 维度事后判。
> 想象力"前门有闸、后门有审"，本篇补的是**中间那段**——发散本身。

## 一、发散的六个撬棍（每个都能把一个平庸前提撬出新方案）

给定一个 logline，逐个套用下面的撬棍，各产出 ≥1 个变体，再从中选：

1. **金手指反向设计（cost-first）**：先定"这个能力**最疼的代价/最死的限制**是什么"，再倒推能力。
   例：不是"能读心"，而是"每读一次心，就替对方多背一天的记忆——读得越多越不是自己"。限制即卖点。
2. **视角错位（POV cut）**：把故事交给"通常没有话语权"的那个人。反派的会计、龙的猎物、系统本身、
   被穿越者顶替掉的原主。同一事件，换一双眼睛就是新书。
3. **类型杂交（genre×genre 矩阵）**：把本类型 × 一个远类型的**核心机制**嫁接。修仙×职场晋升制度、
   宫斗×刑侦破案、末世×美食经营。要嫁接**机制**（规则/流程/张力来源），不是贴标签。
4. **时代/场域平移**：把一个熟套路搬到它"不该在"的场域，逼出新逻辑。赘婿逆袭→搬到宗门后勤处；
   战神归来→搬到养老院。场域会改写权力关系和爽点来源。
5. **前提取反（invert the given）**：把 logline 里默认为真的一条**翻过来**。"废物觉醒成天才"→
   "天才一夜变废物，且他松了口气"；"重生复仇"→"重生者发现前世的仇人是对的"。
6. **约束逼创意（constraint/SCAMPER/Oblique）**：强加一条硬约束再想。"主角全程不能说话"/"故事只发生在一个房间"/
   "金手指每卷只能用一次"。约束是想象力的助产士——AI 无约束时只会滑向最常见版本。

## 二、生成 → 打分 → 挑/杂交（generate-N-and-pick 的可操作版）

1. **生成**：用上面撬棍产 **≥5 个**候选方向（宁滥毋缺；发散阶段不自我审查）。
2. **打分**：每个候选打三项（各 0-3）：
   - **差异化距离**：和"最近的已知爆款"差多远？（能一句话说清关键差异=高分；说不清=换）
   - **意外×合理**：这个转向是否"意料之外、情理之中"？只意外不合理=噱头；只合理不意外=平庸。
   - **可持续爽点**：这个前提能撑起 N 章的**期待→延迟→兑现**呼吸，还是一个梗用完就空？
3. **挑/杂交**：选总分最高的做主方向；把**落选方向里最亮的那 1 个点**嫁接进来（杂交常胜过单选一个迭代）。
4. **留档**：主方向 + 被否方向 + 一句否决理由，写进蓝图「差异化决策」段。
   —— 这段不是形式：`trope_cliche.py` 会读它判"套路是否已被点名颠覆"，novelty 事后打分也会回看。

## 三、每个方向必须写成的三行（进「差异化决策」段）

```
方向X：<一句 logline>
差异化记忆点：<和最近爆款的关键差异，一句话说清>
最近对标 & 关键差异：《<某爆款>》——同<共性>，但我把<某机制>改成了<某反常规>
```

## 四、套路自查（挑定方向后过一遍）

- [ ] 老读者能否只凭 logline 就预判第 1-10 章走向 + 结局？能 → 回炉或杂交。
- [ ] 命中了 `trope_cliche.py` 的高频套路吗？命中不是罪，但必须在上面三行里写清**怎么颠覆/差异化**。
- [ ] 差异化点是**机制级**（改了规则/代价/权力关系）还是只是**换皮**（换了名字/背景板）？换皮=没差异化。
- [ ] 金手指有没有一个"会疼"的代价/限制？没有 → 回撬棍 1。

## 五、发散的反模式

- ❌ **三个近邻**：三个方案其实是同一个的三种措辞。撬棍没换轴 = 没发散。
- ❌ **为怪而怪**：只追意外、丢了合理性与爽点，是另一种失败（novelty=满分但读者弃书）。
- ❌ **发散完不留档**：否决理由不写进「差异化决策」，下游 novelty 打分和套路探测都接不住，等于白发散。
- ❌ **把撬棍当清单硬凑**：撬棍是产灵感的，不是每本都要用满六个；产出足够差异化的方向即可停。

## 六、派生线也要发散（别只在原创新书用）

- `novel-rewrite`：改写方向不该只是"用户说改哪就改哪"——用撬棍 5（取反）/3（杂交）先给魔改方向也发 2-3 个候选，
  与用户诉求对账后再定（用户诉求优先，但候选能帮用户看清可能性）。
- `novel-spinoff`：配角外传的价值在"**开发原作的哪块留白**"。用撬棍 2（视角错位）列几条候选留白（这个配角
  知道主角不知道的什么？站在哪个道德位置？），挑信息落差/道德张力最大的那条。

## 七、发散采样口径：Verbalized Sampling（对抗 mode collapse 的提示词级修法）

2025 实证（arXiv 2510.01171，Stanford）：RLHF 后模型的套路化根因是偏好数据的**典型性偏差**——
直接连问三次"再来一个"，采样只会围着同一个高概率模式打转（三个近邻反模式的机制成因）。
修法纯提示词、零成本：

1. **一次要 N 个候选 + 各自概率**："给 5 个差异化前提方向，并为每个标注你认为它在同类请求中
   被生成的典型度（高/中/低）"。
2. **刻意取低典型度尾部**：从"低典型度"里挑 2-3 个进三方向池——那里才是真发散区
   （论文实测创意写作多样性提升 1.6-2.1 倍）。
3. **与撬棍组合**：VS 管"采样别塌缩"，六个撬棍管"往哪些轴发散"——先 VS 出宽候选池，
   再用撬棍轴归类/杂交，最后过 `premise_divergence_audit.py` 机检（三候选相似度/共享套路锚）。

同样适用于：卷末转折候选、章末钩子候选、书名候选（novel-title）等一切"多候选挑一"的分叉点。
