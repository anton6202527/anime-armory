# 叙事结构模型库（三幕之外的可选骨架）

`outline.md` 默认用三幕 + ≥2 反转编章纲，够用但不是唯一。长篇不同题材、尤其**漫剧/微短剧**这种
强节奏短章形态，用别的结构模型往往更贴。本篇是一张**可选骨架清单**：编章纲/拆单元时按题材与篇幅选一个当脚手架，
再落到 `outline.md` 的意外性设计位与 `hooks.md` 的爽点配比。不是每本都要套模型——模型是防"结构塌"的护栏，不是镣铐。

## 选型速查

| 篇幅/形态 | 首选骨架 | 理由 |
|---|---|---|
| 漫剧 / 微短剧 / 单元短章 | **起承转结（四拍）** + 单元剧循环 | 四拍天然适配 1000-2500 字强钩子短章；每单元一个完整起承转结 |
| 网文长篇连载 | **卷级三幕 + 章级起承转结** 双层 | 宏观三幕给大弧，微观四拍保证每章有转有钩 |
| 单主角成长/冒险 | **Story Circle（八步）** | 欲望驱动的下降-回归环，最适合"主角要什么→付什么代价→带什么回来" |
| 强情节/悬疑/多线 | **七点结构（Seven-Point）** | 从结局倒推的两个夹点 + 中点翻转，防中段塌 |
| 商业类型片式爽文 | **Save the Cat 15 拍** | 节拍密、爽点位明确；适合要精确控节奏的类型文 |

## 1. 起承转结（Kishōtenketsu / 四拍）——漫剧/短章首选

不靠"冲突对抗"驱动，靠**信息递进 + 一个转**驱动，特别适合强钩子短章：

- **起**：立情境、抛人物欲望（首段就得有微张力，见 `tension-ledger.md`）。
- **承**：顺势推进、加信息、养期待（别平推，每段留一缕未解）。
- **转**：**本拍的灵魂**——一个让读者"啊？"的转向（新信息/反转/危机/关系突变）。转即钩。
- **结**：给一个**未完的收束**——回应了当下，又抛出下一章的钩（章末钩五型见 `hooks.md`）。

> 漫剧用法：每 1 章 = 一个完整起承转结，"转"落在 60-80% 处，"结"就是章末钩。连续章的"转"要**换型**别钝化。
> 单元剧循环：每 3-8 章 = 一个大起承转结单元（一个小目标的完成），单元之间用主线暗线串。

## 2. Dan Harmon Story Circle（八步环）——成长/冒险主角

欲望驱动的下降-回归环（Hero's Journey 的精简可操作版）：

1. **You**（安于日常）→ 2. **Need**（意识到缺什么/被打破）→ 3. **Go**（跨过门槛进入新境）→
4. **Search**（适应、试错、付代价）→ 5. **Find**（得到想要的）→ 6. **Take**（为此付出沉重代价）→
7. **Return**（带着改变回归）→ 8. **Change**（今非昔比）。

> 用法：每一卷/每一大弧套一个环；第 4→5→6 段是主体（占最大篇幅），6（代价）是最易被爽文省略、
> 却最决定重量的一步——省了它，逆袭就悬浮。与 `群像与角色弧光.md` 的 want/need/lie 对齐：Need=lie 被戳破。

## 3. 七点结构（Seven-Point）——强情节/悬疑，从结局倒推

先定 Resolution，再倒推其余点，天然防"写着写着散了"：

1. **Hook**（起点状态，常与结局相反）→ 2. **Plot Turn 1**（进入主线、世界改变）→
3. **Pinch 1**（施压、露出反面力量）→ 4. **Midpoint**（从被动到主动的翻转）→
5. **Pinch 2**（更大压力、看似最糟）→ 6. **Plot Turn 2**（拿到破局的最后一块拼图）→
7. **Resolution**（兑现）。

> 用法：两个 Pinch 是"中段防守"的结构锚（对齐 `novel/_lib/sweep_schedule.py` 的 40-60% 加密回扫带）；
> Midpoint 必须是**主角能动性的翻转**，不是又一次被打。

## 4. Save the Cat 15 拍——类型爽文精确控节奏

Opening Image → Theme Stated → Set-up → Catalyst → Debate → **Break into Two** → B Story →
Fun and Games（"承诺给读者的爽点"密集区）→ **Midpoint**（假胜/假败）→ Bad Guys Close In →
**All Is Lost** → Dark Night of the Soul → **Break into Three** → Finale → Final Image。

> 用法：Fun and Games = 你在封面/简介里"承诺"的核心爽点必须在这段密集兑现（对齐 `reader-contract.md`）；
> All Is Lost 是全书最低点，之前的"虐"在此触底（对齐 `hooks.md` 的虐—期待—爆发）。节拍太密时只取
> Catalyst / Midpoint / All Is Lost / Finale 四个硬锚即可。

## 5. Scene 与 Sequel（场景/后续）——补"反应处理"的缺失单元

`scene-cards.md` 有主动的 **Scene**（目标→阻碍→冲突→转折→价值变化），但没有**反应单元 Sequel**。
一个高潮/打击之后，读者需要角色**消化**——省了它，情绪没有落点，人物像没有内心。

- **Sequel（反应单元）三步**：**Reaction**（情绪/生理的即时反应）→ **Dilemma**（面对新处境的两难，
  每个选项都有代价）→ **Decision**（做出选择，产生下一个 Scene 的新目标）。

> 用法：大转折/大爽点/大打击之后插一个短 Sequel（可以只有一段），让情绪落地、让下一个目标"长"出来。
> 与 `情绪节奏.md` 的"扬"之后的呼吸对齐；纯 Scene 连打 = 读者喘不过气也没有代入。

## 与既有工艺的接口

- 选定骨架后，**反转/钩子仍落** `outline.md` 的意外性设计位 + `hooks.md` 的钩型轮换与爽点波浪配比。
- 情绪拍走向查 `情绪节奏.md`（题材化抑→蓄力→扬）；每页微张力查 `tension-ledger.md`。
- 骨架只管"大梁怎么搭"，不替代逐章工艺；同一本书**宏观一个模型 + 章级起承转结**双层最稳。

## 反模式

- ❌ **套模型套到僵**：为了凑齐 15 拍硬塞节拍，节奏反而假。模型是护栏不是填空题。
- ❌ **只有大结构没有微张力**：卷级三幕漂亮，但每页死水——照样弃书（见 `tension-ledger.md`）。
- ❌ **漫剧硬套长篇三幕**：短章强钩形态用起承转结/单元剧更贴，硬套三幕会让每章"没头没尾"。
