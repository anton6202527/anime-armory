# 女频情感：颗粒度 · 心理戏 · CP张力曲线 · 糖度配比

现言、古言、甜宠、先婚后爱、破镜重圆、大女主言情等女频题材是否适合当前目标平台，必须以项目 `评分/market_baseline_*.json`、`评分/题材热榜_*.md` 与 `资料/research_sources.json` 为准；未跑实时基准时，本篇只作为写作模板，不当作热度结论。`情绪节奏.md` 给甜宠/先婚后爱的题材三拍，`relationship-scenes.md` 给单场关系戏，本篇专补**女频区别于男频爽文的那层"情感颗粒度"**——女频读者吃的不是事件密度，是**情绪的精确刻画与关系温度的可信变化**。写言情向章节、`novel-review` 查「情感悬浮/发糖发腻/工业糖精」时读。

> 一句话法则：**女频的爽 = 情绪被精准看见**。男频靠"做成了什么事"爽，女频靠"那一刻的心动/心痛被写准了"爽。事件是载体，情绪才是产品。

## 一、情感颗粒度（把一种情绪拆成层）

不要用"她很心动 / 她很难过"这种**情绪标签**。把一个情绪拆成**生理反应 + 微动作 + 念头闪回**三层，让读者自己得出标签——这是女频版的 show-don't-tell（与 `chapter.md`「动作描述代替状态描述」同源，但更细到情绪内部）。

- **心动**别写"心动"：写失措的小动作（指尖发紧、不敢看、把话题岔开）、生理失序（耳热、呼吸乱、听不清别人说什么）、不合时宜的念头（"他袖口有皂角味"）。
- **心痛**别写"心碎"：写身体的钝（手凉、嗓子堵、动作变慢）、过度的镇定（笑着把碗洗完）、记忆的反扑（想起他从前说过的一句话）。
- **颗粒度判准**：删掉这个情绪的"命名词"，光靠描写读者还认得出是哪种情绪吗？认得出=颗粒度够。

## 二、心理描写（内心戏的量与法）

女频比男频允许更多内心戏，但**不是越多越好**——心理独白堆成段=节奏塌、AI 味重（见 `去AI味.md`）。

- **量**：单段内心戏 ≤ 150 字一气（比 `chapter.md` 的 200 字更严），要长就用动作/对话切开。心理:动作:对话大致 3:4:3，别让独白盖过场景。
- **法**：内心戏要**有转折、有矛盾**（"她告诉自己不在乎，可还是回了头"），不是情绪的反复咏叹。一段独白若只是把同一情绪换词说三遍=注水，删。
- **潜台词优先于独白**：能用一个动作或一句言不由衷的话演出来的心理，就别用独白说破（与 `dialogue.md` 潜台词联动）。

## 三、CP 张力曲线（关系温度只进不退）

女频主线是**关系温度的爬升曲线**，读者追的就是这条线。

- **温度不可逆**：每次重要互动后，两人关系的"已确认温度"只升不降——退回去=前面的兑现作废，读者背叛感最强（`relationship-scenes.md` 同律）。可以有误会回落"体感"，但读者要清楚地基没塌。
- **拉扯有度**：靠误会/错位制造张力是手段，但**误会不能靠降智维持**——一句话能解开却偏不说=读者弃书（`情绪节奏.md` 甜宠翻车项）。误会要源于信息差或性格，且有合理的不说破的理由。
- **里程碑要挣来**：心动、确认心意、第一次靠近、和解，这些 CP 里程碑是女频的"爽点"，必须由人物的选择和处境**挣来**，不是作者到点发糖（`reader-contract.md` 通则）。
- **双向**：现代女频尤其忌"舔狗式单向"。两人都要有**主动**的时刻，关系才立得住。

## 四、糖度配比（甜 / 虐 / 平的呼吸）

- **甜要挣来、虐要有用**：撒糖前先有小障碍（甜宠三拍 误会→拉扯→撒糖）；虐是为了让后面的甜更响，不是为虐而虐。无意义的虐 = 读者疲劳。
- **工业糖精预警**：连续多章无障碍的甜=腻（匀速撒糖按 `情绪节奏.md` 注水处理）。糖也要波浪，大甜（关系跃迁）压在里程碑，小甜（日常互动）密布过渡章。
- **BE / HE 是契约**：结局走向（HE/BE/开放）是写进 `读者契约.md` 的硬承诺，中途偷换=毁约（女频读者对 BE 雷点极敏感，见 `平台雷点.md`）。

## 五、女频高频雷点（先避开再谈写好）

下列在女频（尤其晋江系）是高频弃书雷点，立项时与 `读者契约.md` 的"价值边界"对齐，平台差异详见 `平台雷点.md`：

- 男主非洁 / 男主出轨 / 男主对女主用强；女主被过度作践（虐女主无底线）。
- 圣母白莲女主（晋江容忍度最低）；女主降智配合反派/男主。
- 结局 BE 而前期未给契约预期；主线被副 CP / 群像抢戏。

> 这些是"默认雷"，不是绝对禁区——若刻意写要在 `读者契约.md` 显式登记并向读者预警（晋江"排雷"文化即源于此）。

- [ ] 内心戏有没有超量？每段独白是否有转折/矛盾，而非情绪复读？

- [ ] 最近几章是不是匀速撒糖（腻）或匀速虐（疲劳）？甜虐有呼吸吗？
