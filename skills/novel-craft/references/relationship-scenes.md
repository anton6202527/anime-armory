# 关系情绪兑现场景专项

用于章纲命中告白、表白、心动、决裂、误会爆发、和解、救赎、互相救场、吃醋、护短、疗伤等场景。关系场的目标是让“关系温度”发生不可完全回退的变化。

## 总原则

1. 先标关系温度：本场前两人的状态是疏离、试探、依赖、误会、互相利用还是压抑喜欢。
2. 情绪必须被选择逼出来：危机、误会、代价、第三者、秘密或共同敌人。
3. 用动作兑现，不靠解释：靠近、后退、收手、挡刀、递物、改称谓、停顿、扶住、放开。
4. 台词要有潜台词：嘴上说任务，实际上说在意；嘴上冷淡，动作却保护。
5. 场景后要改变下一章行为：信任额度、称谓、身体距离、阵营、目标或禁忌。

## 告白 / 心动兑现

- 告白前要有压抑或误会，不要凭空甜。
- 让一方先做风险动作：承认、停留、保护、拒绝利益、暴露弱点。
- 甜点要短而准，保留未完全说出口的余味。
- 如果是强钩章节，可把“回应”断在下一章。

## 决裂 / 误会爆发

- 决裂必须有触发点：谎言暴露、价值冲突、保护失败、身份差、旧伤复燃。
- 双方都付出代价；不要把一方写成纯误会工具人。
- 决裂台词不宜长，最好落在一个不可撤销动作上：转身、收回信物、拔剑、关门、改称谓。
- 留下可追裂缝：证据缺一环、仍有牵挂、共同敌人逼近或第三者藏了真相。

## 和解 / 救赎 / 互相救场

- 和解不是一句道歉，要有补偿动作、风险承担或旧承诺兑现。
- 救赎场景要给被救者选择权，避免只被动获救。
- 互相救场最好让两人的能力互补，一人补另一人的短板。
- 和解后关系不能完全回到原点，至少改变一个称谓、距离、信任或共同目标。

## 写完自检

- [ ] 情绪是否由选择或代价逼出来，而不是作者宣布？
- [ ] 是否有一个具体动作承载情绪转折？
- [ ] 下一章行为会不会因本场关系变化而不同？
