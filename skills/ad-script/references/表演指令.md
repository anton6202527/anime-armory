# 表演指令词汇表——可演动作，不是结果形容词（ad 线自持）

传统导演工艺的第一纪律：**给演员可演的过程，不给结果**（playable vs result direction）。
"自然点/开心点/要有高级感/演出喜欢的感觉"是结果指令，人类演员演不了，AI 更演不了。
AI 流水线里表演只存在于 prompt 文字里——storyboard 人物镜必须写进三轴，
`scripts/performance_cue_audit.py` 机检，`ad-image/ad-video` 的 plan_prompts 原样继承。

## 三轴写法

### ① 情绪/状态（写节拍，不写"要有情绪"）
- 用**转变**："皱着眉刷手机 → 看到价格眼睛一亮"（一镜内给 before→after 最有戏）
- 用**身体化状态**：松了口气 / 如释重负 / 嘴角忍不住上扬 / 疲惫地揉眼 / 嫌弃地撇嘴
- 反面：开心、自然、有感染力、高级（形容结果，无法执行）

### ② 视线（视线差一寸，情绪差一档）
- 看向产品 / 低头看手里的瓶身 / 看向镜头外的孩子 / 与同伴对视一笑
- **直视镜头**是强指令（打破第四面墙，证言/口播用），不要无意识乱用
- 群戏写清谁看谁；产品镜写清"视线落点在产品"，否则 AI 常给游离眼神

### ③ 可演动作（具体物理动词）
- 拧开闻了一下 / 挤一泵在手背抹开 / 单手拎起 / 递给副驾 / 按下开关等它亮
- 动作要**服务卖点**：防漏就倒过来晃，轻便就单指拎，速干就抹完立刻碰袖口
- 反面：使用产品、展示功能、表现出很好用（都是摄影机拍不到的抽象词）
