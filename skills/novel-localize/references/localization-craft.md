# 本地化工艺 (Localization Craft)

novel-localize 的工艺参考：术语锁 schema + 文化适配规则 + 逐章任务包结构。
正向标准在此，机检口径在 `scripts/localize_check.py`。

## 术语锁 schema（`出海/<lang>/术语表.json`）

本地化的"定妆库"——先锁后翻，跨章零漂移。`localize_check.py` 按 `source` 字段查漏锁。

```json
{
  "version": 1,
  "lang": "en",
  "terms": [
    {"source": "沈念",   "target": "Shen Nian",      "type": "person",  "note": "贵妃，音译保留姓在前"},
    {"source": "断魂崖", "target": "Soul-Severing Cliff", "type": "place", "note": "意译，突出杀机"},
    {"source": "玄阴功", "target": "Dark Yin Art",    "type": "skill",   "note": "功法，半意译"}
  ]
}
```

- **type**：person / place / sect（门派）/ skill（功法）/ item（法宝）/ title（称谓）/ term（独有设定词）。
- **译法策略**（按 `出海目标平台` 所在市场习惯）：人名常音译（拼音去声调/按目标语拼写习惯）；地名/门派/功法可意译或音意混合；称谓（陛下/本宫/师尊）按目标文化等效，不直译拼音。
- **一名一译**：同一 source 全书唯一 target；要改回术语表改一处 + 受影响章重跑，**不在单章即兴另译**。
- **抽取来源**：`设定/角色卡.md`·`世界观.md`·`锚点表.json` + 全书高频专名；先机器抽候选，再人工定译名。

## 文化适配规则（不是直译）

| 维度 | 直译陷阱 | 本地化做法 |
|---|---|---|
| 成语/俗语 | 字面翻 → 失味/不知所云 | 用目标语等效表达；无对应则改写其意 |
| 称谓/honorifics | 本宫/奴婢/师尊 拼音直出 | 按目标文化等效（如英语用头衔/名字 + 语气） |
| 计量/时间 | 三炷香/一里 直留 | 换算或加注（a few minutes / about half a mile） |
| 文化梗/典故 | 直译典故名 | 本地化等效梗，或淡化为通用表达 |
| 语气/文风 | MT 平板直白 | 贴目标读者口味（YouTube 短剧源更口语、节奏快） |

> 文化适配是否到位是**人判**——`localize_check.py` 只兜确定性的未译残留/术语漏锁/覆盖，不评"地不地道"。

## 逐章本地化任务包（喂翻译后端）

每章一包，结构化注入，避免后端即兴：

- **术语表**：本章涉及的 source→target 专名子集（强约束，照表不另译）。
- **文化适配规则**：上表相关条目 + 本章特殊点（双关/诗词/谐音需特殊处理的标记）。
- **本章中文正文**：源文本。
- **目标**：产 `出海/<lang>/章节/第NN章.md`，专名照术语表，文化梗适配，语气贴 `出海目标平台`。

`翻译后端` 选择点决定由谁执行：LLM 代理（注入后逐章生成）/ 专业MT（外部引擎初翻）/ 人工 / 混合（MT 初翻 + LLM 或人工润色）。

## 与下游 n2d 的衔接

`出海目标平台` 选 YouTube/TikTok 短剧·漫剧改编源时，本地化产物可标 `n2d-ready`：译文同样要满足漫剧友好（参 `novel-craft/references/n2d-readiness.md` 的对白/画面/场景锚），让本地化版也能进 n2d 出海漫剧。
