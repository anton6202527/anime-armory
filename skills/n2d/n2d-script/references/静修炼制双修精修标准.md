# 静修 / 炼制 / 双修精修标准

适用：打坐、静坐、冥想、闭关、吐纳、炼丹、炼器、开炉、成丹、淬火、双修、合修、双人疗伤。目标不是把画面堆满，而是让观众看见“修炼过程真的被制作了”：姿态、呼吸、能量路径、材料状态、火候、成品揭示和关系边界都可读。

## 1. 静修镜（`meditation_cultivation`）

**高级感来自少动但有层次**：
- 人物：坐姿、手印、重心、衣摆、发丝、呼吸节奏必须锁住。
- 能量：灵气从环境进入身体，或沿丹田/经脉/周天运行，只走一条主路径。
- 内在结果：内视、心魔压制、气海波纹、境界松动、灵气沉静，单镜只给一个结果。
- 环境响应：尘粒、烛火、符纸、池水、云雾或阵纹随呼吸轻动。

**必写字段**：`posture_lock`、`breath_cycle`、`energy_flow`、`aura_vfx_lock`、`inner_state_beat`、`environment_stillness`、`micro_motion`、`readability_beats`、`degrade_plan`、`keyframe_plan`、`post_cue_points`、`physics_guard`。

**推荐拆镜**：姿态建立 → 吐纳周天 → 内在响应 → 收功留白。

**降级**：身体漂、手印乱变或灵气路径混乱时，改静态坐姿关键帧 + aura overlay；内视改短插入镜，不让视频模型自由生成“意识空间”。

## 2. 炼丹 / 炼器镜（`alchemy_forging`）

**观众需要看懂工序**，不能只写“火光大作”：
- 炼丹：投料 → 升温 → 凝丹 → 开炉。
- 炼器：熔炼 → 锻打 → 淬火 → 出器。
- 每镜只承载一个工序段；成丹/出器/炸炉给 `reveal_frame` 可读半拍。

**必写字段**：`furnace_or_forge_lock`、`material_sequence`、`process_stage_ladder`、`flame_control`、`heat_curve`、`material_state_ladder`、`tool_hand_pose`、`product_lock`、`reveal_frame`、`vfx_asset_lock`、`success_or_failure_beat`、`failure_or_success_safety`、`readability_beats`、`degrade_plan`、`keyframe_plan`、`post_cue_points`、`physics_guard`。

**贵感做法**：
- 炉体/锻炉/主材料/火焰/成品先入 `PROP/VFX` 资产库。
- 火候曲线写清颜色、亮度、节奏和峰值，不靠“炫酷火焰”泛词。
- 材料状态写“药材干燥→化液→凝珠”或“矿石熔融→金属胚→符纹成形”等阶梯。
- 产品揭示要定格：丹纹、剑锋、法器纹样、失败裂纹或爆烟形态都要锁。

**降级**：炉体/成品变形时，改炉口 CU、手部投料、火焰 overlay、产品静态揭示和角色反应镜。

## 3. 双修 / 合修镜（`dual_cultivation`）

双修模板只用于成年人、双方明确自愿、非露骨的修炼/疗伤/能量循环表达。它不是情色模板。

**硬边界**：
- `adult_consent_lock` 必须写成年人、双方自愿、剧情关系允许。
- `non_explicit_boundary` 必须写无裸露、无性行为动作、无未成年人语义。
- 身体表现保持克制，奇观交给 aura/VFX、呼吸同步和关系状态。

**必写字段**：`adult_consent_lock`、`non_explicit_boundary`、`paired_posture_lock`、`distance_boundary`、`contact_points`、`energy_circulation`、`breath_sync`、`aura_vfx_lock`、`relationship_state`、`readability_beats`、`degrade_plan`、`keyframe_plan`、`post_cue_points`、`physics_guard`。

**推荐安全构图**：
- 掌心相抵：只露手、袖口、灵力光环和两人半身。
- 背靠背运功：身体无缠绕，能量环绕两人形成闭环。
- 并坐手印：保持安全距离，用光流表达气息交汇。
- 疗伤合修：伤处不裸露，改衣物外侧光纹、脉络光点或反应特写。

**降级**：接触不稳、身体重叠、边界风险或露骨倾向出现时，立即改手印特写、背影剪影、光雾淡出、反应镜或只拍能量循环。

## 4. 音画卡点

- 静修：低频气息、轻粒子、短静默留白；BGM 不顶满。
- 炼制：火焰床、炉鸣、金属/药材变化声、开炉 chime；成品揭示可给短停顿。
- 双修：双人呼吸同频、低能量 hum、灵力循环 swell；不要用情色化音效。

## 5. 审片重点

- 静修：坐姿是否守住；灵气路径是否可读；内在结果是否清楚。
- 炼制：炉体/材料/火色/成品是否跨帧不漂；阶段是否按 ladder 递进；揭示帧是否能停读。
- 双修：成年人/自愿/非露骨边界是否明确；接触点和身体归属是否稳定；能量循环是否承担主要表达。
