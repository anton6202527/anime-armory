# 亲密动作精修标准

适用：接吻、亲吻、近吻、额头吻、脸颊吻、拥抱、抓腕、拉扯、牵手、搀扶、抚脸、扶肩、疗伤贴近。目标是让关系动作细腻、可读、稳定，而不是把亲密动作写成大幅度身体缠绕。

## 1. 接吻 / 近吻（`kiss_or_near_kiss`）

接吻镜是高风险近景：两张脸接近、手部靠近脸、表情变化都容易导致脸融合和身份漂。

**必写字段**：`age_context_lock`、`consent_lock`、`non_explicit_boundary`、`relationship_state`、`approach_path`、`face_angle_lock`、`contact_or_near_contact_frame`、`hand_position_lock`、`body_overlap_limit`、`breath_pause`、`micro_expression_beats`、`readability_beats`、`degrade_plan`、`keyframe_plan`、`post_cue_points`、`physics_guard`。

**推荐拆镜**：自愿靠近 → 脸部角度与呼吸停顿 → 接触/近接触帧 → 分开或留白。

**安全表达**：
- 优先 closed-mouth gentle kiss、forehead kiss、cheek kiss、near-kiss pause。
- 禁止露骨舌吻、脱衣、性行为暗示和未成年人性化。
- 年龄语境不清时，用近吻停顿、额头吻、脸颊吻、错肩或反应镜。

**降级**：脸融合、嘴部漂、手穿模、边界不清时，拆成靠近、眼神/呼吸停顿、手部/发丝插入、反应镜和分开落幅。

## 2. 拥抱 / 拉扯 / 抓腕（`hug_or_pull`）

拥抱类的关键不是“抱住”两个字，而是谁主动、手臂怎么绕、身体哪里重叠、何时松开。

**必写字段**：`consent_boundary`、`contact_points`、`force_direction`、`body_overlap_limit`、`occlusion_order`、`body_part_ownership`、`hold_or_release_frame`、`release_frame`、`relationship_state`、`readability_beats`、`degrade_plan`。

**推荐拆镜**：接触前距离 → 手臂/手腕接触 → 力量方向或拥抱停住 → 松开/被拉近/反应。

**贵感做法**：
- 把情绪放在停顿、手指收紧、肩背微动、呼吸和脸部反应，不靠大幅身体纠缠。
- 抓腕/拉扯必须写 `force_direction`；拥抱必须写 `hold_or_release_frame`。
- 身体遮挡写 `occlusion_order`，手臂归属写 `body_part_ownership`。

**降级**：全身拥抱不稳时，改半身拥抱、肩背特写、手腕特写、OTS 反打、分开后的表情。

## 3. 普通亲密互动（`intimate_interaction`）

牵手、搀扶、抚脸、扶肩、疗伤贴近等低幅度互动，也要写清接触点和边界。

**必写字段**：`consent_boundary`、`contact_points`、`distance_boundary`、`body_overlap_limit`、`occlusion_order`、`body_part_ownership`、`relationship_state`、`readability_beats`、`degrade_plan`。

**推荐拆镜**：距离变化 → 接触点建立 → 视线/呼吸停顿 → 反应或松开。

**降级**：手部不稳时改手部静帧 + 低幅度动作；身体重叠不稳时改 OTS、侧脸、道具插入或正反打。

## 4. 审片重点

- 两个角色脸/服装/手部归属是否稳定。
- 接触点、遮挡顺序、力量方向和释放/停住帧是否可读。
- 表情变化是否“锁脸不锁情”：只动肌肉，不重塑五官比例。
- 是否遵守自愿、非露骨、年龄语境清楚的边界。
- 失败后是否按 `degrade_plan` 拆镜，而不是继续加形容词硬生成。
