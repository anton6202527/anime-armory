# 对白与活人感（改编态台词 craft）

> **定位**：阶段1 剧本改编**写 voiceover/台词时读**的生成态 craft。AI 能写对白，难写**活人感**——直陈情绪、说教、旁白代角色总结，是短剧观众的头号劝退，也是 AI 输给真人的那一格。本文教**怎么把源小说的叙述/心理描写改成「像真人在说、值得被演」的漫剧台词**。
>
> **它是「教」，不是「审」**：写完用 `scripts/subtext_audit.py` 自检（advisory，不阻断）；audit 命中的每类 AI 味，回本文对应条改。craft 靠例子不靠说教——下面每条都给 `源句 → AI味直译 → 活人感改写` 对照。
>
> **边界**：本文管对白质量，不管剧情结构（看 `拆集法.md`）、不管节拍留存（看 `beat_audit`）、不管分镜（看 `分镜语法.md`）。不新增机检闸（设计宪法 B10）。

---

## 0. 介质前提（漫剧/短剧的对白约束）

- **短、可表演、可一口气配完**：本线 voice-first，台词长度受 `配音/时长清单.json` 物理约束；写时就估口播秒数，别拖到分镜才发现超时返工。
- **完播率驱动、前 3 秒定生死**：冷开场第一句台词要么带钩、要么让位给视觉钩，不能是寒暄。
- **信息回报 + 情绪回报叠加**：爽点台词不能只有情绪宣泄，要同时推进信息（谁、为什么、接下来）。
- **一句一信息点**：长句拆短；从句套从句是叙述腔，不是说话。

---

## 1. 改编的核心动作：旁白 → 台词

源文本是小说（叙述 + 心理描写 + 上帝视角）；漫剧要的是**被角色说出来、做出来**的东西。改编不是把旁白念出来。

**一句话判据**：*这句旁白，能不能让某个角色「说出来」或「做出来」？* 能就转，不能才留旁白。

**心理描写外化三法**：
1. **转潜台词**——把内心活动改成一句「能透出它、但没说破」的台词。
2. **转动作/物件**——用一个具体动作或道具承载情绪（攥紧/松手/把杯子推远）。
3. **转他人反应**——让对手戏角色的反应镜替观众读出情绪。

**旁白的合法保留区**（其余尽量清）：大跨度时间压缩、信息密度爆炸的设定交代、需要上帝视角才能成立的悬念。

**叙述腔黑名单**（小说能用、台词不能用）：
- 书面连接词：「然而 / 与此同时 / 不禁 / 顿时 / 旋即 / 殊不知」。
- 上帝视角动词：「他意识到 / 她明白 / 心里清楚」——这些要么转台词，要么转表演。
- 成段从句、形容词叠用、对仗排比——朗读出来就是「AI 在播稿」。

## 2. 活人感八条（前 4 条对位 subtext_audit，后 4 条补它抓不到的盲区）

> audit 现抓 4 类词汇级 AI 味：①自陈情绪 ②情绪概括（旁白代总结）③动机过度解释（因为…所以…）④信息直给（其实我是…）。下面 ①–④ 给「怎么写对」直接对位，⑤–⑧ 是 audit 抓不到、但更决定活人感的盲区。

### ① 潜台词 > 直给（对位审计①自陈情绪）
不让角色报自己的情绪，给一句**透出它**的具体话。
- 源句：她非常生气，觉得被背叛了。
- ❌AI味：「我真的很生气，你背叛了我。」
- ✅改写：「（把茶杯轻轻放正）你昨晚，几点回的？」

### ② show-not-tell（对位审计②情绪概括）
不让旁白替角色总结情绪，用动作/答非所问/转移话题外化。
- 源句：他感到一阵绝望。
- ❌AI味：旁白「他感到无比绝望。」
- ✅改写：（台词）「……行。那就这样吧。」（动作）把名单折好，放进了最里层口袋。

### ③ 动机藏进行为（对位审计③动机过度解释）
别用「因为…所以…/之所以…是因为…」说穿动机；让选择本身暴露动机。
- 源句：因为怕被发现，所以他决定先下手。
- ❌AI味：「因为我怕你查到，所以我必须先动手。」
- ✅改写：「在你翻那本账之前，我们得先聊聊。」

### ④ 设定靠情境逼出（对位审计④信息直给）
身份/世界观别靠「其实我是…/你忘了我是你…」硬塞 exposition；让冲突逼它浮现。
- 源句：其实他是失踪多年的大皇子。
- ❌AI味：「其实我才是真正的大皇子，你忘了吗。」
- ✅改写：「这枚玉佩——你是从哪儿，拿到我母妃的东西的？」

### ⑤ 留白与未尽之言（audit 盲区）
打断、欲言又止、沉默，常比说满更有力。短剧观众的脑补就是参与感。
- ❌写满：「我等了你三年，你却娶了别人，我恨你也忘不了你。」
- ✅留白：「三年。」「……你都知道了。」「我什么都不知道。我只是路过。」

### ⑥ 具体 > 概括（audit 盲区）
用能看见的细节名词，代替抽象情绪词。
- ❌：「我们以前那么幸福。」
- ✅：「你以前煮面，总要多卧一个蛋。」

### ⑦ 言行不一 / 口是心非（audit 盲区·短剧观众嗑的张力）
表层说 A、底层是 B；让台词和真实意图错位，观众读差值。
- 场景：她其实想留他。
- ✅：「走啊。门没锁。」（手却没从他袖子上松开）

### ⑧ 信息不对称对白（audit 盲区）
角色知道的 ≠ 观众知道的 ≠ 对方知道的。同一句话在三层信息差里产生张力。
- 观众已知他下了毒，角色不知——「这杯，是我特意给你温的。」一句普通话变利刃。

## 3. 漫剧介质的对白节奏

- **冷开场首句**：第一句台词承担钩子责任（悬念/欲望/反差/危机/情绪任一），不寒暄、不背景板。
- **一句一信息点**：信息密时拆成数个短句轮替，别堆进一句长台词。
- **长度贴时长清单**：写时估口播秒；一句要能被配音演员一口气说完，说不完就是书面句。
- **爽点台词 = 双回报**：情绪宣泄的同时推进信息。
  - ❌只情绪：「我终于赢了！太爽了！」
  - ✅双回报：「赢了。——现在，轮到我念你们的名字了。」（情绪：翻盘爽 + 信息：反攻预告）

## 4. 角色声音差异化（活人感的另一半）

全员一个「AI 旁白腔」是最大的 AI 味。硬指标：**遮住角色名，能否凭台词认出是谁？** 同场多人对白必须能**盲听辨人**。

### 角色声音卡（先做纯文档约定，写在角色卡/series_bible 的角色条目下）
每个有台词的角色，落这几项，改编每句台词都锚定它：
- **核心信念 / 当下欲望**：他说话是为了得到什么、护住什么。
- **语速与句长**：急促短句 / 绵长迂回 / 惜字如金。
- **语体档（文/白/阶层/方言色彩）**：读书人 vs 市井 vs 江湖 vs 宫廷，用词层级不同。
- **口头禅 / 标志句式**：一两个反复出现、专属他的说法。
- **回避话题**：他绝不正面接的那类问题（用回避本身演出内心）。
- **情绪表达档**：外放（直接喊）↔ 压抑（越痛越平静）。
- **对象切换**：对上位者 / 对爱人 / 对敌人，同一角色的语气怎么变。

### 用法
- 改编每句台词前，先问「这是**这个**角色会说的话吗」，不是「一个角色会说的话」。
- 同场 ≥2 人对白：交替读一遍，若换了名字也成立，说明没差异化，回声音卡重写。
- 数据来源：`character_arc_ledger` / `performance_signature` 已有的人物信息可作底；声音卡是它们的「怎么说话」补充。

## 5. 题材适配的对白侧重

- **视觉奇观题材（玄幻 / 末世 / 系统流等）**：动作/场面镜可让台词退位给画面；但**系统提示语、金手指、招式命名**这类标志性台词要有记忆点（观众会复述/玩梗的那几句）。
  - **系统流集尾钩别喊成宣言**（实战回灌·常见坑·对位 §2③④）：金手指/野心不要让主角一口气宣布出来。
    - ❌AI味（动机+金手指直给）：「总有一天我也能修仙！只要我觉醒了系统，就能改变这一切！」
    - ✅改写（show 决心 + 把系统转成视觉钩）：「记住了。」（挑起水桶，回头望一眼云里的仙峰，声音压低）「……这水，总有一天该是别人替我挑。」——集尾视觉钩：他掌心一行只有自己看得见的微光字一闪。
    - 为什么更好：决心靠「回望+压低嗓+一句具体的反转图景」演出来；系统金手指作**视觉悬念**留到集尾，比喊出来更勾人，也更贴原生音画（能演就别念）。
- **情感为主题材（都市 / 女频情感等）**：对白**扛全部情感**，潜台词密度要求最高——**这是最不能偷懒的地方**，也是 AI 最容易露怯的地方，§2 八条逐条过。
- **对白雷区（各题材通用）**：悬浮（不像人间话）/ 油腻（爹味说教）/ 降智（角色为推剧情犯蠢）/ 疲软套路（已被观众用烂的模板台词，别原样照搬）。

## 6. 教 ↔ 审闭环

1. 改编写完 → 跑 `python3 scripts/subtext_audit.py <作品根> 第N集`（advisory，report-only）。
2. 它命中的每类，回本文对应条改：自陈情绪→§2①、情绪概括→§2②、动机过度解释→§2③、信息直给→§2④、集级直白率偏高→§1+§2 整体过一遍。
3. **写死**：subtext_audit 是 advisory、不 block（设计宪法 B10）。它是写完的自检清单，不是扣分门；它抓的是**候选**交人判，不计真隐含度。

## 7. 改编对白 checklist（一页速查）

每集/每场改编后过一遍：
- [ ] 旁白是否已尽量转成台词或画面？剩下的旁白都在 §1 合法保留区？
- [ ] 有无角色直陈自己情绪 / 旁白代总结情绪？（§2①②）
- [ ] 有无「因为…所以…」说穿动机 / 「其实我是…」硬塞设定？（§2③④）
- [ ] 关键情绪点是否用了潜台词 / 具体细节 / 言行错位，而非说满？（§2⑤⑥⑦）
- [ ] 遮住角色名，台词能盲听辨人吗？同场多人没有「一个腔」？（§4）
- [ ] 冷开场首句带钩？（§3）
- [ ] 爽点台词做到情绪+信息双回报？（§3）
- [ ] 台词长度贴口播时长，没有书面长句？（§0、§3）
- [ ] 题材对白雷区（悬浮/油腻/降智/疲软套路）没踩？（§5）
