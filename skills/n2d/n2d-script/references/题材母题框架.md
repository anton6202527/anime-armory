# 题材母题（motif）框架 —— n2d 一等概念总纲

> 这是 n2d「母题/复现场景」一等概念的人读契约总纲（与 `打斗分镜.md` / `仙侠场面分镜.md` 同档）。
> 机器真值在 `n2d/_lib/n2d_const.py`（检测关键词、id、字段）+ `出图/共享/motif_registry.json`（数据）+
> `专项镜头模板库.md`（镜头契约）+ `asset_registry.json` 的成长 VFX（lifecycle 状态机）。改这里要同步那几处。

## 1. 什么是母题（motif）

穿越/系统流等爽文里有一类**高频复现的"母题场景"**：系统面板出现、主角升级、系统刷新/签到/抽奖、爆装备、金手指触发。它们的共同结构是：

- **相对固定的场景模板**——每次出现观众一眼认得（同一套视觉语言、机位逻辑、台词腔调）。
- **每次出现带成长属性**——面板进化、等级只增不减、属性数值攀升、道具升级。固定中有递进，正是爽感来源。

做好母题桥段，观众爱看；做砸了（每次都重画、面板忽大忽小、等级数字 AI 渲染成乱码、升级毫无递进感），就废了一个核心爽点。所以 motif 是 n2d 线内**一等概念**，贯穿 题材检测 → 镜头设计 → 台词 → 出图 → 出视频 → 合成 全流程。

**系统面板是首个落地样板。** 后续 level_up / system_refresh / signin / gacha / loot / cheat 只在 `MOTIF_TYPE_KEYWORDS` 加枚举值 + `motif_registry.json` 加配置，**不改架构**。

## 2. 三个已拍板的设计决策

1. **通用母题框架 + 系统面板首样板**——见上。
2. **混合渲染**——AI 生图对清晰文字/数字几乎渲染不准，而面板恰恰全是文字数值。所以：
   - n2d-image 让 AI **只画发光光幕底框 / 符纹边框 / 内部空白发光区**（`VFX_系统面板`，跨集锁色锁形），**禁止 AI 把任何文字/数字/等级烤进图**（prompt 强制 negative）。
   - 等级/属性/标题等**数值文字由 n2d-compose 期 Pillow overlay 叠上去**（复用字幕 overlay 管线 `render_panel.py`），保证数字永远清晰、随成长精确变化。
3. **检测+建议，默认不阻塞**——split/分镜阶段自动识别题材与母题桥段，写入 `生产数据/motif_plan_第N集.md`。`母题增强=仅建议` 时保留建议并继续；项目显式开启、用户改写，或有效 `仅高风险停审` 授权覆盖该可逆内容节点时，才把 `motif_id`/`template` 注回 `storyboard.json`、写 `motif_registry.json`。若注入影响下游出图/出视频，新增 scope/calls/成本统一进入对应阶段预算包；包获批后不按母题或镜头重复询问。

## 3. 全链路：检测 → 模板 → VFX → overlay → 机检

```
小说正文/storyboard
   │  ① motif_detector.py（n2d-script）：detect_genre + detect_motif_clips
   ▼
生产数据/motif_plan_第N集.{json,md}   ← 建议态，人读、人确认
   │  ②（人确认后）motif_detector --write
   ▼
storyboard.json clip.template_contract（template=system_panel, motif_id=…）
出图/共享/motif_registry.json（motif 定义 + 成长 progression）
   │  ③ n2d-image：绑 VFX_系统面板，prompt 强制 negative 掉文字
   ▼
出图/共享/asset_registry.json（VFX_系统面板：forms 等级档 + lifecycle 只进不退）
   │  ④ asset_lifecycle.py 机检面板成长不回退（image_qc advisory）
   ▼
出视频：首帧锁面板（不变形/不位移/不出文字），系统光作该镜专属色
   │  ⑤ n2d-compose：render_panel.py 读 progression+overlay_spec
   ▼
成片：清晰等级/属性文字层叠在 AI 光幕底框上（面板层在字幕层之下）
```

## 4. motif_registry.json 数据契约

落点：`出图/共享/motif_registry.json`（与 `identity_registry.json`/`asset_registry.json` 同级）。`kind = "n2d_motif_registry"`。

motif 是**桥段/场景级**概念（绑多资产 + 台词 + overlay），与 `asset_registry.json` 的**单资产级**互补——所以单独建文件，不塞进 asset_registry（否则污染 `asset_lifecycle.py` 的 per-asset 校验和 gate 的 id 前缀检查）。motif **引用** VFX 资产，**成长状态机本体仍落 VFX 资产的 `lifecycle`**。

```jsonc
{
  "kind": "n2d_motif_registry",
  "version": 1,
  "motifs": [{
    "motif_id": "MOTIF_系统面板",          // 前缀 MOTIF_（对称 LOC_/VFX_）
    "motif_type": "system_panel",          // n2d_const.MOTIF_TYPE_KEYWORDS 的键
    "scope": "第1集起复用",
    "detection": {                          // 命中的检测特征（可解释，便于人复核）
      "keywords": ["系统", "面板", "属性", "等级"],
      "min_hits": 2
    },
    "growth_state_machine": {
      "bound_vfx": "VFX_系统面板",          // → asset_registry.assets[].lifecycle（状态机本体）
      "monotonic_fields": ["level", "panel_tier"],   // 只增不减字段（机检退级=block）
      "progression": [                       // 逐次出现的成长快照（单调推进）
        {"at_clip": "EP01_CLIP05", "level": 1, "panel_tier": "v1_素纹",
         "title": "系统", "attrs": {"力量": 10, "敏捷": 8}},
        {"at_clip": "EP03_CLIP12", "level": 5, "panel_tier": "v2_流光",
         "title": "系统", "attrs": {"力量": 30, "敏捷": 22}}
      ]
    },
    "shot_template_id": "system_panel",      // → 专项镜头模板库.md §12
    "dialogue_patterns": {
      "trigger_lines": ["叮——检测到宿主", "系统绑定成功"],
      "narrator_role": "系统",                // render_subs.py 已把"系统/旁白"→灰小字 narrator
      "tone": "机械音/无情感/简短"
    },
    "overlay_spec": {                        // 混合渲染：compose 期文字层规格（render_panel 读）
      "anchor": "panel_center",              // 光幕底框内的锚区：panel_center|panel_top|panel_left
      "fields": ["title", "level", "attrs"], // 渲染哪些字段
      "color": [180, 230, 255],              // 系统青（RGB）
      "lock_to_clip_range": true             // 数值取 progression 中 at_clip ≤ 当前 clip 的最新快照
    }
  }]
}
```

## 5. 成长状态机：只进不退（复用现成机器）

面板"每次刷新都进化、等级只增不减"靠两层机检，**零新增状态机代码**：

- **VFX 层**：`VFX_系统面板` 用 `forms[]`（v1_素纹 / v2_流光 / v3_符纹 = 等级档位）+ 结构化 `lifecycle`（`states` + `transitions`，下标即时间序）。`asset_lifecycle.py:validate_lifecycle` 已机检 `lifecycle_regression`（面板退档=block），image_qc advisory 调用。见 `n2d-image/references/资产引用注册层.md`。
- **motif 层**：`progression` 的 `monotonic_fields`（level/panel_tier）由 `motif_detector.validate_progression_monotonic` 校验逐次只增不减。

两层同源理念：固定模板 + 单调成长。改动档位只能往前加，不能回退。

## 6. 镜头模板（system_panel）

见 `专项镜头模板库.md` §0.2（通用 motif 模板形态）+ §12（system_panel 契约）。要点：

- **beats**：面板浮现 → 数值刷新 → 主角反应（升级镜在"数值刷新"处给等级跳变特写时机）。
- **camera_rule**：面板正对屏幕、不随镜头透视畸变；面板悬浮位置稳定。
- **continuity_must**：面板跨集锁色锁形（VFX）、等级只增、**内部文字区留空给 overlay**。
- **negative（关键）**：面板内不出现任何可读文字/数字/汉字/等级/进度条刻度。
- motif 专属字段：`motif_id` / `vfx_asset=VFX_系统面板` / `text_layer=overlay` / `growth_ref`（指向 progression 当前快照）。

## 7. 台词设计

母题台词有强烈腔调统一性，写进 `dialogue_patterns`：

- **系统音**：机械、无情感、简短（"叮——""检测到宿主""恭喜宿主，等级提升至 Lv.5"）。`narrator_role="系统"` → 字幕走灰小字 narrator 样式（render_subs 已支持）、配音走系统音色（一角一色跨集对账）。
- **主角反应**：升级/爆装备处给情绪台词或内心 OS，是爽点释放点（可标 `钩子=climax` → 字幕暖金大字）。
- 触发句 `trigger_lines` 跨集保持句式一致，强化"母题"识别度。

## 8. 各阶段落点速查

| 阶段 | skill | 干什么 |
|---|---|---|
| 题材+母题检测 | n2d-script `motif_detector.py` | 识别题材、母题桥段，出 motif_plan 建议 |
| 题材记录 | `_设置.md` `题材`/`母题增强` 选择点 | 检测预填、可覆盖 |
| 镜头模板 | n2d-script `专项镜头模板库.md` §0.2/§12 | system_panel 模板契约 |
| 面板视觉 + 成长 | n2d-image `VFX_系统面板`（forms/lifecycle） | AI 出锁色锁形空光幕底框 |
| 出图 prompt | n2d-image `prompt_format.md` | 绑 VFX + 强制 negative 掉文字 |
| 面板成长机检 | n2d-image `asset_lifecycle.py` | 退档=block（零新增代码） |
| 出视频 | n2d-video `prompt_format.md` | 首帧锁面板、系统光专属色 |
| overlay 数值层 | n2d-compose `render_panel.py` | 读 progression+overlay_spec，叠清晰文字 |
| 跨剧复用 | n2d-asset-market `export/import-motif` | 母题 pack（import 重置 progression 从 Lv.1） |

## 9. 加一个新母题（例：签到 signin）

1. `n2d_const.MOTIF_TYPE_KEYWORDS` 加 `signin` 关键词（已预置）。
2. `motif_registry.json` 加一条 `motif_type=signin` 的 motif，配 `bound_vfx`（可复用 `VFX_系统面板` 或新建签到弹窗 VFX）、`shot_template_id`、`dialogue_patterns`、`overlay_spec`。
3. 复用 `system_panel` 模板形态（§0.2 通用 motif），或在 `专项镜头模板库.md` 加专属模板。
4. 无需改检测器/渲染/机检代码——它们都按 motif_type 泛化。
