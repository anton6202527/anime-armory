# 导演视角 Prompt 八维 / 出图·出视频 prompt 装配规范（全阶段共用）

> **核心信念**：同一张定妆、同一个场景，**画师**问"画面里有什么、美不美"；**导演**问"这个镜头**为什么这么拍**、它在替剧情说什么"。
> 漫剧的廉价感，一半来自"每张图都是平视正面、打光均匀、表情到位的好看插画"——好看，但**不会叙事**。把 prompt 从画师视角升级成导演视角，就是每条 prompt 都按下面**八维**想全、按序装配。
> 这不等于放弃人物好看。除非角色圣经、剧情或用户特别说明“丑、怪、病、老、恐怖、粗粝写实、非主流”等，人物默认仍按当下主流可播审美和镜头友好来写：脸部比例协调、五官清晰有辨识度、妆造服装精致耐看、光影让脸立体好看；只是这条审美必须服务角色 DNA、状态和镜头叙事，不能把所有人洗成同质化网红脸。
> 本文件是 `分镜语法.md`(空间/镜头怎么切) 与 `导演节奏.md`(时间/留存) 的**落地层**：那两份决定"切什么镜、走什么节奏"，本文件决定"**这一镜的 prompt 怎么写**"。
> n2d-script(分镜剧本/素材清单)、n2d-image(出图 prompt)、n2d-video(视频 prompt) 三处都按本框架装配。

---

## 一、八维：画师视角 → 导演视角

| 维度 | 画师视角（只回答这个就停）| 导演视角（还必须回答）| prompt 里的体现 |
|---|---|---|---|
| **① 镜头** | 画全身 / 画特写 | **为什么是这个景别**（ELS/LS/MS/MCU/CU/ECU）+ 焦段/景深（广角=张力夸张·长焦=压缩偷窥·浅景深=主体抽离背景）| `中景，长焦浅景深，背景虚化` |
| **② 机位** | 正面、平视 | **角度+高度+关系+物理镜头**：平/俯/仰视、过肩/正反打；绑定**焦段(mm)**和**光圈(f-stop)**（广角=张力夸张·长焦=压缩偷窥·浅景深=主体抽离） | `低角度仰拍，14mm超广角，f/8深景深` |
| **③ 人物** | 长得好看、穿得对 | **身份锁定**（拼角色卡『锚点句』锁脸锁妆造）+ **人物审美基线**（默认主流审美、镜头友好、好看但不网红脸）+ **此刻状态**（伤痕/泪痕/发丝凌乱/衣衫破损/血污——人物随剧情"被改写"）| `同一少女[锚点句]，五官清晰协调、妆造精致但保留清冷气质，左颊有新伤，发髻松散` |
| **④ 动作** | 摆个静态 pose | 静帧=抓**动作最强的一瞬**（挥剑到顶点前、转身回眸瞬间）；视频=**人物运动 + 表情变化**（performance，见 §三）| 图：`剑尖抵喉的定格瞬间`；视频：`缓缓抬眼→眼神由茫然转杀意` |
| **⑤ 场景** | 背景画对 | **场景定妆锚**（跨集复用同一张）+ **时间**（昼/夜/黄昏）+ **环境状态**（雨/雾/烛火明灭/陈设凌乱）——交代时空 、烘托情绪 | `冷宫内[场景锚]，深夜，烛火将熄，地面积尘` |
| **⑥ 光影** | 打亮、看得清 | **光替剧情说话（物理光照）**：光源动机（烛光/月光）+ **色温(Kelvin)** + 方向/塑光手法（伦勃朗光/负补光）+ 调性（高调明快/低调压抑）| `5600K冷月光，伦勃朗布光，低调，面部一半加负补光(Negative fill)` |
| **⑦ 情绪** | 表情到位 | **本镜情绪词**（茫然/阴狠/决绝…）+ **张力词**（克制/紧张/爆发/释放）→ 驱动运镜幅度+念白+剪辑节奏 + **色调情绪**（冷青=疏离/暖橙=温情/血红=危机）| `情绪=隐忍的恨；张力=克制；冷青色调` |
| **⑧ 画质** | 高清、精致 | **画风词统一**（依 `global_style.md` + `style_contract`，禁漂移）+ 所选 `基础视觉风格` 的渲染/线条/材质级别 + **画幅** + **视频兼容锚定句**（固定后端拼对应模型；未固定拼通用兼容锚定）+ **负面词堵漏** | `按基础视觉风格派生的画质词，9:16，[固定模型锚定句/通用视频兼容锚定句]；负面：多手指、风格漂移…` |

> **顺序不是死的，但维度不能漏**。写每条 prompt 时心里过一遍这八维——尤其最易漏的**②机位 / ⑥光影 / ⑦张力**，它们正是"画师插画"和"导演镜头"的分水岭。

## 二、八维装配模板（图 prompt 通用骨架）

把八维按"先定框架（镜头/机位）→ 填主体（人物/动作/场景）→ 加灵魂（光影/情绪）→ 锁规格（画质）"的顺序写成一句连贯 prompt：

> **图片 prompt 也不是越多越好**：图片阶段负责把视觉变量锁成像素，所以可以比视频 prompt 更细；但必须结构化，不能把角色卡全文、世界观、剧情解释和后端路由理由整段塞进单条 prompt。标准是“视觉变量明确、互相不打架”：定妆图锁档案，分镜图锁这一帧怎么拍。

```
[①镜头] [②机位]，[③人物=锚点句+人物审美基线+状态] 正在 [④动作]，
置身 [⑤场景+时间+环境状态]，[⑥光影]，
整体 [⑦情绪+张力+色调]，[⑧画风词+渲染级+画幅+视频兼容锚定句]
负面：[统一负面词 + 本镜堵漏词]
```

**实例（画师视角 vs 导演视角，同一镜）**：

- ❌ 画师：`一个穿红衣的古装少女站在宫殿里，很漂亮，高清`
- ✅ 导演（示例为 `基础视觉风格=写实电影感`；其他风格按 `style_contract` 替换画质/禁忌）：`中景偏近、长焦浅景深；低角度仰拍过肩；同一少女[锚点句：丹凤眼/眉心朱砂/月白滚红边宫装]，鬓发微乱、指节攥白，正缓缓抬眸冷笑；冷宫正殿[场景锚]，深夜，残烛明灭、梁上积尘；单侧烛光做逆光勾边、伦勃朗三角光、低调；情绪=隐忍翻涌的杀意、张力=克制、冷青压暗红色调；写实电影感画质词、9:16、[即梦风格锚定句]。负面：画风漂移、多指、塑料感`

**定妆图提交口径（中性档案，不上剧情八维）**：

```text
角色身份：{CHAR_xx/形态 + 锚点句 + 角色圣经引用}；
年龄/年龄档：{明确年龄或年龄档；未知先补角色卡，不用模糊少女/少年替代}；
固定外貌：{脸型/五官比例/发型/体态/肤色质感等身份不变量}；
服装妆造：{服装剪影/层次/材质/主辅色/配饰/妆容；无配饰写无}；
定妆要求：{中性表情、正面/45°/侧面/背面/半身或全身、脸部特写、统一中性灰白/18%灰棚拍底、柔和均匀光、无剧情场景}；
画风规格：{项目基础视觉风格 + 画幅 + 渲染/材质纪律}；
禁止：{不要戏剧光、不要剧情动作/剧情状态、不要夸张表情、不要改年龄、不要改服装主色、不要网红脸同质化、不要文字/logo/水印}；
```

**分镜图提交口径（剧情镜头，上完整八维）**：

```text
身份保持：{CHAR_xx/形态 + 定妆/脸部特写/服装/场景/道具参考；明确从共享定妆 image2image/多图参考派生}；
镜头构图：{景别/机位/焦段感/轴线/视线方向/画幅；与相邻镜的景别阶梯关系}；
动作瞬间：{只抓一个最强定格或首帧起幅；动作顶点交尾帧/锚帧，不在一张图塞完整动作链}；
场景光影：{场景/时间/光源动机/主光方向/色温/色调；继承本场光位锚}；
情绪张力：{本镜情绪 + 张力词 + 画面信息焦点，服务剧本可看性合同}；
画风规格：{项目基础视觉风格 + 9:16 + 视频兼容锚定句 + 风格禁忌}；
禁止：{不要换脸、不要改年龄、不要改服装、不要改场景/光位、不要新增人物/道具、不要文字/logo/水印、不要风格漂移}；
```

## 三、视频 prompt：八维 + 让它"动起来"

视频 prompt 在八维之上，把 **④动作** 与 **②机位** 升级为"运动版"，其余维度由首帧 PNG 已经锁定（出图阶段做完），视频阶段**只调运动**。这里的“详细”不是把角色卡、场景卡、光影设定整段再写一遍，而是把动作、运镜、节奏和禁漂项写清楚；首帧已经锁住的视觉变量只做保持，不重定。

- **④动作 → 人物运动 + 表情变化**：写清"从什么状态→到什么状态"（抬眼/转身/挥袖/落泪），别只写静态。
- **②机位 → 运镜**：**固定机位是普通镜默认值，不是“缺少运镜”**。先写 `camera_motivation/运镜动机`：摄影机移动究竟揭示了什么新信息、改变了什么空间关系；答不出来就固定，让人物表演、画内调度、停顿和剪辑承载张力。确有动机时再参考 `skills/n2d/references/运镜/manifest.json`，落成 `CAMERA_MOVE_LEXICON` 里的单一结构化词 + 速度/方向/起止点；爽点或高光本身不自动授权环绕、轻甩或冲击变焦。
- **视线与头部朝向**：摄影机默认是旁观者。除明确 POV、破第四墙或对镜叙事外，角色眼睛、鼻梁轴和头部始终锁定戏内对手/道具/动作落点，保持三分之四、侧向或过肩关系；不得为“显脸”把角色吸成迎镜头表演。
- **情绪节奏**：按时间段写情绪/停顿/张力变化，锚定本镜运动幅度与剪辑节奏。
- **动态细节**：烛火摇曳/晨雾流动/衣袂飘动/妖气扩散——给画面"活气"，但不改首帧设定。

```
首帧保持：{保持首帧已锁定的人物身份、服装、场景、光位、道具位置和画面重心；不重定视觉设定}；
人物运动：{一条主动作链，从什么状态到什么状态} → {表情变化，幅度可控}；
镜头运动：{推/拉/摇/移/跟/环绕/固定 + 速度词，服务本镜张力}；
视线与头部朝向：{戏内目标 + 画左/画右/镜头外方向 + 三分之四/侧向/OTS；只有明确 POV/破第四墙才直视摄影机}；
情绪节奏：{按时间段写情绪/停顿/张力变化，如 [0-2s] 克制呼吸 [2-5s] 眼神压近 [5-7s] 定住}；
动态细节：{场景里的环境动态 ≥1 条，只做随动，不新增设定}；
禁止：{不要换脸/换衣/改场景/改光位/新增人物或道具/生成文字logo水印；非 native_speech 镜不要生成原生人声}；
```

> 视频阶段**不重定**①镜头/③人物外貌/⑤场景/⑥光影/⑧画风——那些在出图阶段已用首帧锁死（"先在图阶段把视觉变量锁死，视频只调动作/运镜"）。视频里改了这些 = 与首帧打架 = 闪烁漂移；复杂动作靠锚帧、Motion Control、拆 Clip 或实现分解，不靠长 prompt 硬压。

## 三-A、导演运镜审查 sidecar（从故事到 prompt）

阶段2 `storyboard.json` 定稿后先跑：

```bash
python3 skills/n2d/n2d-script/scripts/director_camera_plan.py <作品根> 第N集 --write
```

它会生成 `生产数据/director_camera_plan_第N集.json/md`，逐 Clip 输出三类内容：

- `findings`：检查缺运镜声明、自由散文、缺速度档、无动机摄影机运动、非 POV 的迎镜头视线，以及近景大表情的高风险运镜。
- `image_prompt_injection`：给 `01_分镜出图.md` 的 `镜头/机位`、`起幅·运动余量`、`构图防呆`、`视线表演`；固定镜不虚构摄影机运动余量，只给人物动作与戏内视线留空间。
- `video_prompt_injection`：给 `01_clips.md` 的 `导演意图`、`起幅`、`落幅`、`镜头运动`、`视线表演`、`运动精修`、`动态细节`。普通镜默认固定；只有明确 `camera_motivation/运镜动机` 或连续空间动作才推荐移动。若 `video_model_routes.json` + 后端证据能确认 `control_idiom`，还会附 `后端控制写法`，缺新鲜证据则降级通用自然语言。

这份 sidecar 不替代导演判断。若它和剧情状态、轴线或模板契约冲突，以 `storyboard.json` 为真值，人工改写；但改写后的 `镜头运动` 仍必须是结构化运镜词 + 速度/方向/起止点。需要挑运镜时，先看 `skills/n2d/references/运镜/manifest.json` 的结构化条目和 `README.md` 图片索引，再写进 `镜头运动`。

## 四、各阶段取哪几维

| 阶段 | 文件 | 用到的维度 |
|---|---|---|
| **n2d-script 分镜剧本** | `分镜剧本.md` | 先定 ①②④⑤⑥⑦（导演意图层，文字描述）——每镜标景别+机位+光影动机+情绪张力 |
| **n2d-image 定妆** | `角色\|场景定妆.md` | ③人物 / ⑤场景 / ⑥光影(中性定妆光) / ⑧画质——**不锁**①②④⑦（定妆是中性参考，不带戏） |
| **n2d-image 分镜图** | `01_分镜出图.md` | **八维全上**（§二模板），首帧把视觉全锁死 |
| **n2d-video 视频** | `01_clips.md` | ④动作+②运镜+⑦张力+动态细节（§三），其余维度继承首帧 |

> 注意分工：**定妆图是"中性档案"**（正面、均匀光、无戏，只为锁脸锁造型），**分镜图才上全八维**（带机位/光影/情绪的"剧照"）。别把定妆图也打成戏剧光——那样它当参考图时会污染下游。

## 五、导演视角自查清单（每条分镜/视频 prompt 落笔前过一遍）

- [ ] **①镜头**：景别明确且**有理由**（不是默认中景）？需要时写了焦段/景深？
- [ ] **②机位**：写了角度/高度（不是默认正面平视）？机位选择**服务情绪**（仰=压迫/俯=渺小/过肩=对峙）？守轴线？
- [ ] **③人物**：拼了角色卡锚点句？默认人物审美是否主流、镜头友好、好看但不网红脸？写了"此刻状态"（伤痕/凌乱/服装变化），而非永远定妆态？
- [ ] **④动作**：图=抓了动作最强一瞬？视频=写了运动轨迹+表情变化（不是静态）？
- [ ] **⑤场景**：场景锚 + 时间 + 环境状态都在？
- [ ] **⑥光影**：写了光源动机+方向+调性？**光在叙事**（不是均匀打亮）？
- [ ] **⑦情绪**：本镜情绪词 + 张力词 + 色调情绪三件齐？张力词与运镜/念白一致？
- [ ] **⑧画质**：画风词依 global_style？画幅对？视频兼容锚定句拼对了吗（固定模型/通用兼容）？负面词堵了本镜的漏？
- [ ] **最易漏三维复检**：②机位、⑥光影、⑦张力——这三维有没有偷懒回到画师视角（正面/均匀光/无张力）？

> 一句话：**八维全想到，才从"画一张好看的图"变成"拍一个会叙事的镜头"。** 配合 `分镜语法`(镜头空间) + `导演节奏`(留存时间) 三份一起过，才算导演级 prompt。
