# 拆集法 / 集边界决策规范（阶段1·拆集必读）

> 目的：定**集与集之间的边界**——一部小说切成多少集、每集起止在哪。
> 这是 `导演节奏.md` 的**前置**：`导演节奏` 管「一集**内部**怎么走（留存曲线）」，本文件管「**集与集之间**的刀切在哪」。先切对边界，集内节奏才有意义。
> **一句话**：集边界由**结尾的悬念断点**和本集 **冲突→看点→钩子** 闭环决定，不由字数或时长决定。`节拍盖过字数，剧情闭环盖过时长，剧情丰满盖过省时长`——**而这一切只为一个目标：让这集「好看 / 值得专门看」。好看是拆集要最大化的目标(北极星)，合理与剧情饱满是它不能击穿的地板**（好看的代价绝不能是降智/糖精破合理、或删因果跳逻辑破饱满）。
>
> **⬆ 上有剧级层（`追更骨架.md`·Gap1）**：P0→P6 是**单集**边界铁律，但"整部怎么排、哪几集是大反转/付费墙、断点强度怎么跨集分布"在 `追更骨架.md`。单集闭环对了不等于整部追得动——**先画整部留存骨架（开篇黄金集群/情绪递进区/大反转集/卡点集/断点梯度，按 `变现模式` 免费/付费/海外），再用本文件逐集下刀**。机检：`boundary_audit.py` 的「剧级追更骨架」段。
> **边界启发式词典按 `题材` 选择点切换（Gap3）**：`split_novel`/`boundary_audit` 的冲突/爽点词面默认覆盖古装爽文/修仙；女频情感/悬疑/都市经 `题材` 切换专用词典，避免非爽文题材粗拆退化成"一路并入无闭环"。

## 拆集优先级（从最先下刀到最后微调，逐级让位）

下刀按 P0→P6 顺序判断；**低优先级永远让位于高优先级**——字数/时长（P4）冲突时，永远服从断点（P0）/闭环（P1）。

### ★ 北极星 — 每集必须有一个「核心看点」（P0→P6 都为它服务）

P0→P6 是**手段**，它们共同服务一个**目标**：让观众觉得这集**好看、值得专门看**。下刀前先回答一句——**"这集的核心看点是什么？"**——答不出来、或看点太弱，这集就不该独立存在（合并/重构），哪怕它 P0 断点完美、P1 闭环完整。**"断点完整但平庸无看点"的集照样会被划走。**

**核心看点必须归到四类之一**，并自问"够不够强到值得单独看"：

1. **爽点 / 打脸逆袭** — 压制后的反杀、扮猪吃虎、当众打脸、扬眉吐气。经典爽剧主轴。
2. **强反转** — 身世 / 阵营 / 金手指 / 关系的颠覆，认知被推翻的那一下。全剧脊梁。
3. **情绪峰** — 共鸣 / 虐点 / 燃点 / 泪点的情绪高潮。2026 观众从"即时爽"转向"细腻情绪共鸣"、近 60% 会重看——**情绪峰是留存与口碑的新增量，不再是爽点的附属**，女频情感 / 治愈 / 悬疑题材尤其靠它立集。
4. **视觉奇观** — 大战 / 觉醒 / 法宝出世 / 渡劫 / 末日 / 万人场等只有 AI 能低成本突破实景的画面高潮。**这是 AI 漫剧对真人短剧的差异点（护城河）**，拆集时要把奇观当**整集的锚点**——别埋在中段、也别让集边界把一个奇观劈成两半（机检见 `追更骨架.md` 视觉奇观放置）。

> **好看 ≠ 强行爽（地板铁律）**：好看是目标，但它的代价**不能**是**降智 / 工业糖精**（破合理）或**删因果、跳逻辑**（破剧情饱满）——2026 多部高预期剧正因"反派全员降智"口碑崩塌。看点要立在合理与饱满的地板**之上**：先有可信的因果与人物，看点才"爽得住 / 哭得动 / 燃得起"。合理与饱满不是比好看低一级的目标，是好看不能破的下限。

### P0 — 先找「结尾」，不找「开头」（第一性原理）

一集的边界由它**结尾的悬念断点**决定。拆集第一步不是数字数，是**在原文里扫所有"最吊胃口、可硬断"的点**，那些点就是集的**右边界候选**：

- 危机悬置（刀架脖子上 / 门被推开 / 倒计时归零前一瞬）
- 真相半露（抖出一半，关键那句不说）
- 反转预告（一个眼神 / 一封信 / 一道系统音 = 要变天的信号）

把候选断点标出来，**集 = 两个相邻强断点之间**。`--by-chapter` 让粗胚先贴章界，但**章界 ≠ 断点**，必须人工把右边界 snap 到最近的强断点（可 ±一段）。

> 反例：某集结尾停在「她走进了大殿」——这不是断点，是半场戏。往后挪到「大殿门在身后合上，龙椅上坐着的人，是她以为已经死了的人」。

### P1 — 每集装下一个完整「冲突→看点→钩子」闭环

每集至少含一个 **冲突→看点→钩子** 的微弧——观众一集**看到一个高潮 / 出一次气**，并且愿意点下一集。**看点 = 北极星四类之一**（爽点/打脸 · 强反转 · 情绪峰 · 视觉奇观），**不再窄化成只有"爽点或反转"**：女频情感/治愈题材的看点可以是情绪峰，奇观向题材的看点可以是视觉高潮。

- **拆集第一大忌：整集全是铺垫、零看点 / 零出口**。宁可把相邻铺垫段并进有看点的那集，也不要切出一个"纯憋着"的集。
- **剧情丰满是硬约束**：闭环不是只留三个关键词；必须保住人物动机、冲突起因、铺垫承接、爽点兑现和集尾钩子。不能为了让一集更短，把必要镜头/段落剪掉，让观众觉得"怎么突然这样"。
- 例外：当本集的"憋"本身**断在爽点引爆前一帧**（P0 的危机悬置），这个 cliffhanger 就是它的出口——允许。
- 爽点要有"憋—放"距离：跨集时，"憋"可放在上集尾、"放"在下集头，但**别把一个完整爽点劈成两半各放半个**（上集没爽、下集莫名其妙）。

### P2 — 切点要让**下一集**能 0-3s 冷开场

边界不只服务"本集怎么收"，还服务"**下集怎么起**"。

- 切点之后的第一段，必须能当**冷开场钩**（最炸的画面/台词）起。
- **不许切出"以纯过渡/交代戏开头"的集**（下集第一句是"话说三天后……"= 切错了）。
- 检验：把切点想象成下集第 0 秒——这一秒抓得住人吗？抓不住，把边界往前/后挪到能抓人的地方。

> **集首拉力与结尾断点同权（2026 数据修正·G1）**：P0 强调"先找结尾"，但 2026 Sensor Tower 公开口径显示——**下一集的解锁率与"本集开场钩子强度"的相关性高于上一集的集尾 cliffhanger**。所以集首不能只当"接住上集那根钩"的连续性问题（P2 的本义）来对待：**开场本身要够强够深**，光"有个钩"不够，要在前两拍里给到 conflict/suspense/reversal 至少一条强层（直给冲突 / 抛悬念 / 反转直入），别把最炸的信息留到中段。机检：`beat_audit.py` 的 `cold_open_pull_strength`（开场四层加权评分；低于地板 `cold_open_pull_weak=warn`·正式出图前阻断，单层达标但偏薄 `cold_open_pull_thin=info`）——这是**逐集**前置审计，与 `--series` 的跨集冷开场链互补。

### P3 — 钩子密度达标，杜绝「纯过渡集」

中段每 15-20s 一个钩子（悬念/欲望/反差/信息/危机，见 `导演节奏.md §二`）。

- 一段原文太平（长环境描写 / 大段内心戏 / 流水账交代），**两条路**：① 压缩进相邻集；② 与相邻动作集**合并**，让平淡段被高张力段"带飞"。
- **绝不**让平淡段独立成集——那是必划走的"纯过渡集"。
- 若某段戏信息量撑不起一集、又删不掉，就**并集**（一集可跨多章）。

### P4 — 时长只是软节奏意图，不设硬上下限

时长只做**节奏意图/容量估算/统计提示**，不是下刀依据，也不是放行或阻断的硬标准。

- **前长后短**（默认）只是节奏倾向：第1集更充分立世界观/主角欲望/系列总钩，后续更碎快追更。
- 默认粗拆不锚字数，先找章/场景/强钩候选；`--target` 只是高级报告参考，不参与切点决策。字数换算是高方差代理（对白/打斗压缩少、环境/心理压缩多）。
- 某集为保完整闭环而明显短或长，**直接保留**，记录原因；配音/原生音画实测后只做节奏复核，不得为凑秒数拆断一场戏、一个爽点或一个集尾钩子。
- **不得为省时长删剧情**：拆集/精修可以压缩重复描写、合并平淡段、调整边界、改写为更高密度台词，但不能删掉推动因果、人物选择、情绪递进、伏笔回收、动作转折的必要镜头或段落。真要删除，必须标为"重复/非剧情必要"，并在边界决策里写明为什么不伤连贯。

### P4.5 — 先做「改编取舍」，别把弱信息硬拆成镜头

边界定完、写 `voiceover.txt` 前，先把原文节拍分成五类，并判断是否需要短剧化改写：

- `dramatize / 成戏`：有冲突、选择、后果、反转、情绪峰、视觉高光，必须变成对白/动作/镜头。
- `narrate / 旁白一笔带过`：必要但弱视觉、弱动作的信息，用短旁白/独白/系统音带过。
- `defer / 后文带出`：现在解释会拖节奏，后面可由动作、道具、台词、结果自然露出。
- `merge / 并入相邻节拍`：过渡、承接、重复心理，可贴到更强的戏里。
- `omit / 删除`：重复、无因果负载、删掉不影响动机/伏笔/状态/关系。

这一步的目标是**减少无意义 clip 和接缝**：一段不重要的解释，如果硬拍成镜头，会多一次人物站位、表情、道具、尾帧、视频随机性的风险。能用一句旁白或后文行为带出的，就不要拆成一个视觉空转 clip。但取舍必须有账：`omit` 不能删因果/动机/伏笔/状态；`defer` 必须写清后文承接点；`narrate` 必须短，不把整段设定塞成长旁白。建议产物见 `formats.md §0.5 adaptation_triage.json`。

**允许适度改细节/剧情，但必须有账**：为了短剧紧凑、高潮叠起、好看，可以把内心戏外化成当众对质、把分散压迫合并成一场强冲突、把早讲的设定延后到道具/台词里揭示、把弱开场改成更强视觉钩，或合并小角色承担同一剧情功能。记录 `change_type`（如 `rewrite_detail/reorder/intensify/add_hook/combine_minor_role`）和 `adaptation_delta`（changed_from/changed_to/preserved_function/short_drama_reason/payoff_guard）。底线：不能改掉主角核心动机、因果链、人物关系方向、伏笔兑现义务和世界/系统硬规则；改了也要让观众更容易看懂、更想追，而不是只为了省镜头。

### P5 — 尽量切在场景 / 视角 / 时间的自然幕界（生产成本）

在满足 P0-P4 的前提下，**优先把断点踩在**：

- 换场景（出宫→入府）、换视角（A 的戏→B 的戏）、时间跳跃（当夜→次日）处。
- 好处：跨集断点踩在自然幕界，能**降低跨集崩脸/场景漂移**，且利于**定妆库与分镜复用**（同一集内尽量同场景/同主角集合，少切换 = 少漂移）。
- 当强断点（P0）正好落在幕界——最理想，优先采用。

### P6 — 角色登场节奏 + 首集加权

- **新角色分摊登场**：别一集塞太多新面孔；每个重要角色给一个"立人设"的高光时刻（主角登场本身就是好集头钩）。新角色集中爆发 = 观众记不住 = 弃剧。
- **首集单独加权**：首集除自身闭环外，还要扛 **世界观 + 主角核心欲望 + 系列总钩（追完整部的那个大悬念）**——所以通常更充分，留存投资最高。重切时把更多开篇内容并进第1集。

## 拆集自查清单（开拆后逐集核对·配合 `导演节奏.md` 集内自查）

- [ ] **★北极星** 每集能一句话说出**核心看点**（爽点/打脸 · 强反转 · 情绪峰 · 视觉奇观 四选一）？看点够强到值得单独看？没有"断点完整但平庸无看点"的集？视觉奇观集是否被当作整集锚点（未埋中段、未被切点劈半）？
- [ ] **★地板** 看点不是靠降智/糖精（破合理）或删因果跳逻辑（破饱满）换来的？合理与饱满这两条下限都没被"为了好看"击穿？
- [ ] **P0** 每集结尾都落在一个强断点（危机悬置/真相半露/反转预告），没有一集停在半场戏/平淡处？
- [ ] **P1** 每集都有至少一个完整 **冲突→看点→钩子** 闭环（或断在看点引爆前一帧的合法 cliffhanger）？没有"纯铺垫集"？
- [ ] **剧情丰满** 人物动机、冲突起因、铺垫承接、爽点兑现都还在？没有为了省时长删掉必要镜头/段落，导致因果跳跃或情绪断层？
- [ ] **P2** 每集切点之后能 0-3s 冷开场？没有"以纯过渡/交代戏开头"的集？
- [ ] **P3** 没有"纯过渡集"？平淡段都被压缩或并入相邻动作集？
- [ ] **P4** 没有为凑时长/字数切断一场戏、爽点或钩子？没有为省时长删必要剧情？明显短/长但闭环成立的已记录原因、待配音/原生音画实测后做节奏复核？
- [ ] **P4.5** 写词前已做改编取舍？弱信息已标 `narrate/defer/merge/omit`，没有把可旁白/后文带出的段落硬拆成视觉空转 clip？所有 `omit/defer` 都有不伤因果/承接位置说明？若改关键细节/剧情，是否写了 `change_type/adaptation_delta` 并保住动机、因果、伏笔、人物弧和系统规则？
- [ ] **P5** 断点尽量踩在换景/换视角/时间跳跃处？同一集内场景/主角集合尽量收敛（利于复用、防漂移）？
- [ ] **P6** 新角色分摊登场、各有立人设时刻？首集承担了世界观+主角欲望+系列总钩？
- [ ] **章 ≠ 集**：没有机械"一章=一集"？节拍跨多章的已合并、长章的已上/下集？

> 一句话：**`拆集法` 让"切在哪"对，`导演节奏` 让"切出来的每一集"追得停不下来。** 先过本清单（集边界），再过 `导演节奏` 清单（集内留存）。
