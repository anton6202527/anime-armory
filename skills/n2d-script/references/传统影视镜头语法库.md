# 传统影视镜头语法库（n2d 落地）

本库把传统影视 coverage 翻译成 n2d 可执行合同。目标不是堆“电影感”词，而是让 storyboard、出图 prompt、出视频 prompt 和 review gate 都能追同一套镜头语法。

## 对话 / 对峙优先

- 建立镜：先交代地点、行动轴线、A/B 位置、主光方向和关系高低。
- 双人镜：只负责关系建立，不承担强表情和长台词。
- OTS 过肩：必须写清谁的肩/侧背/背头在前景，谁是焦点，焦点看向哪边。
- Clean single：关键台词、强反应、身份锁脸用单人干净镜，不把多张清晰脸挤进 9:16 近景。
- Reaction shot：信息落到谁身上，就拍谁的反应；沉默、吸收压力、尾钩都可以靠反应镜成立。
- Insert / cutaway：手部、道具、火把、门框、尘土、狼爪、系统面板底框都可做信息、节奏和越轴缓冲。

## 连续性剪辑

- Match on action：下马、拔刀、推门、递物、扁担落肩、狼爪弹出等动作跨镜时，上一镜出点要等于下一镜入点。
- Eyeline cut：角色看向画外目标，再切目标或目标反应；视线方向必须能推出目标方位。
- J-cut / L-cut：声音先入或尾句压到下一镜只作为 compose 意图登记，视频 prompt 默认不生成原生旁白。
- Re-establishing / buffer：越轴、换阵位、从群像切近景、从内心戏回现实，必须用建立镜、空镜、道具插入或中线移动重建空间。

## 压迫与揭示

- 纵轴对压：竖屏最适合用深处/前景、上/下、高/低位表达权力关系。适用于跪求、审问、反派从村道深处压出、主角步步逼近。
- 压迫性低角度：低角度必须说明权力功能，并与反打镜的高度/距离匹配。
- 信息揭示特写：每个特写只揭示一个信息点。证物、狼爪、黑衣赤纹、系统底框、眼神变化都能做揭示特写。
- 蒙太奇省略：背景、赶路、重复劳动、训练和快闪用物件/动作/状态差异压缩，不展开成长戏。

## 9:16 特别规则

- 不要频繁横向多人并排，尤其不要让两张以上清晰脸同时挤在近景里。
- 优先前景肩部 + 背景脸、纵深站位、上下高低位、道具插入和反应近景。
- 群体镜先做建立和层级，关键脸再拆 clean single / OTS / reaction。
- 反打不是躲避多人同框，而是更专业地把关系、表情和身份拍清楚。
