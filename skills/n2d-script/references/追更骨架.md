# 追更骨架 / 剧级留存骨架（阶段1·拆集的"剧级层"·Gap1）

> 目的：在 `拆集法.md` 的 **P0→P6 单集边界**之上，补一层**整部的留存骨架**——哪几集立世界观、哪几集情绪拉满、哪几集是大反转/付费墙，断点强度怎么跨集分布。
> 分层：`追更骨架`（整部怎么排）→ `拆集法`（每集切在哪）→ `导演节奏`（每集集内怎么走）→ `分镜语法`（每镜怎么切）。
> **一句话**：单集闭环对了不等于整部追得动；2026 红果免费模式倒逼"全剧延续性"，付费/海外模式倒逼"卡点峰值"——拆集时必须先画整部的留存骨架，再逐集下刀。

---

## 一、为什么需要剧级层（市场依据）

- **红果免费模式（完播率/留存率导向）**：补贴从"按分钟撒币"变"效果导向"，完播率/留存率不达标就没钱。不能只赌前十集，要保**整个故事的延续性**——断点要**平均强**，最怕**连续弱钩集群**让观众在中段批量划走。
- **付费/小程序剧（前十集定律）**：1-4 集立世界观+主要人物+重点剧情，5-8 集推进并把情绪拉到极致，9-10 集卡点留钩勾起付费。付费墙集必须是**全剧最强 cliffhanger**。
- **海外竖屏（ReelShort/TikTok）**：比付费更碎更狠，前 3 集就要立钩，节拍更密。
- **AI 漫剧留存比真人低 25-30%**：节奏/断点是可量化补回的一环，剧级骨架是把"留存"从直觉变成可体检的结构。

---

## 二、剧级骨架的五个结构件

拆集（粗切→节拍重切）时，除逐集判 P0→P6，还要在 `脚本/_拆集复核.md` 顶部画出整部骨架：

1. **开篇黄金集群（前 3-4 集·留存投资最高）**：首集扛 **世界观 + 主角核心欲望 + 系列总钩（追完整部的大悬念）**；前几集钩子**强度递增**，不许出现弱钩集。对应 `拆集法.md` P6 首集加权 + P2 冷开场。
2. **情绪递进区（中段）**：每集张力阶梯整体上抬，避免长段平台期；这里是连续弱钩集群的高发区，重点盯。
3. **大反转集（≥1-2 个·全剧脊梁）**：身世/阵营/金手指/关系的颠覆性反转，定位到具体集号，作为留存的"二次起飞点"。
4. **付费/AD 卡点集（看变现模式）**：付费=付费墙集；免费=广告位/章末卡点 + 中段保留关键集。卡点集的断点强度必须=全剧顶格。
5. **断点强度梯度**：整部的集尾断点强度（强/中/弱）分布要**健康**——无连续弱钩集群、卡点集顶格、开篇集群无弱钩、收尾留系列总钩。

---

## 三、变现模式 → 骨架差异（`变现模式` 选择点）

`变现模式`（软默认/高级覆盖，不列首跑必问；默认 **免费**）驱动卡点定位与断点策略：

| 变现模式 | 结构重心 | 断点策略 | 卡点 |
|---|---|---|---|
| **免费**（默认·红果/番茄） | 全剧延续性、完播率 | 断点**平均强**，消灭连续弱钩集群 | 不设单点付费墙；中段保留关键集 + 章末钩 |
| **付费**（小程序剧） | 前十集卡点峰值 | 付费墙集（约第 8-10 集，及之后每 ~10 集续费点）顶格最强 | 付费墙集 = 全剧最强 cliffhanger |
| **海外**（ReelShort/TikTok） | 前 3 集立钩、更碎更狠 | 节拍更密、断点更频 | 类付费但前移、卡点更密 |

> 变现模式不改 P0→P6 边界铁律本身，只改**整部断点强度的分布目标**与**卡点集定位**。

## 四、机检：boundary_audit 的剧级输出

> **叙事一致性审计优先级（G-S1·2026-06-24·ConStory-Bench arXiv 2603.05890）**：`beat_audit.py <作品根> --series` 末尾给一个 report-only 的「中段×高熵」一致性审计优先表（`narrative_risk_profile`）——长篇 LLM 一致性 bug 经验上聚集叙事**中段 + 高 token 熵段**，故按 `mid_arc_weight × token_entropy` 给每集排风险分，建议前 1/3 的集让 `n2d-review/consistency_audit` 深审 + 加密抽帧/人审（≥4 集才给；不改判定、不阻断）。

`boundary_audit.py` 在逐集体检表之外，输出 **「剧级追更骨架」** 段（题材词典按 `题材` 选择点切换，见 Gap3）：

```bash
python3 skills/n2d-script/scripts/boundary_audit.py <作品根>            # 全剧骨架体检
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> 2-10       # 精修窗口
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> --json     # 机器可读（series_arc 块）
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> --strict   # 阶段1入口硬门
```

它机检并报：
- **断点强度分布**（强/中/弱计数）——强=悬念标点+词钩齐，中=其一，弱=无（软断恒判弱）。
- **连续弱钩集群**（≥2 连续弱钩集）——断点流失高风险段，建议并入相邻强断点集或补强集尾钩。
- **疑似无闭环/纯铺垫集**——缺冲突或缺爽点/反转（P1），复核是否并入相邻集。
- **开篇集群钩子梯度**——前 3-4 集若有弱钩，提示留存投资不足（P6/前十集定律）。
- **变现模式卡点定位**——付费/海外列出付费墙集并校验其断点是否顶格；免费提示"消灭连续弱钩集群"。

> 这些是**确定性预筛**，不替代人/LLM 判钩力。高风险骨架先把决策写进 `脚本/_拆集复核.md`，再逐集写词。
> 逐集**集内**留存曲线（黄金3秒/钩子密度/集尾 cliffhanger）见 `n2d/references/导演节奏.md`；集内节拍密度机检见 `beat_audit.py`（Gap4/5）。
