# 追更骨架 / 剧级留存骨架（阶段1·拆集的"剧级层"·Gap1）

> 目的：在 `拆集法.md` 的 **P0→P6 单集边界**之上，补一层**整部的留存骨架**——哪几集立世界观、哪几集情绪拉满、哪几集是大反转/付费墙，断点强度怎么跨集分布。
> 分层：`追更骨架`（整部怎么排）→ `拆集法`（每集切在哪）→ `导演节奏`（每集集内怎么走）→ `分镜语法`（每镜怎么切）。
> **一句话**：单集闭环对了不等于整部追得动；免费发行更看全剧连续消费，付费发行更看项目明确卡点前后的承诺与转化——拆集时先画整部留存骨架，再逐集下刀。具体阈值必须由目标平台合同或本项目第一方数据校准。

---

## 一、为什么需要剧级层（市场依据）

- **免费模式（完播/连续消费导向）**：不能只赌前几集，要保**整个故事的延续性**；连续弱钩集群是优先复核段。平台结算与分发规则会变化，执行前以目标平台官方合同为准。
- **付费/小程序剧**：付费墙位置由具体平台、发行合同或本项目第一方数据决定；一旦项目明确了卡点，该集必须有与付费承诺匹配的强断点。没有项目证据时，第 8/10 集等经验位置只能作讨论候选，不能成为默认硬门。
- **海外竖屏**：平台、地区和付费路径差异很大，不预设统一“更碎更狠”阈值；先记录目标平台，再用本项目留存/解锁漏斗校准。
- **反同质化与反降智**：剧级骨架要让四类看点（爽点/反转/情绪峰/视觉奇观）穿插配比，不能一种看点堆到底，也不能用降智/糖精换爽。视觉奇观是 AI 漫剧可主动经营的差异化锚点，但仍须服务剧情功能。

---

## 二、剧级骨架的六个结构件

拆集（粗切→节拍重切）时，除逐集判 P0→P6，还要在 `脚本/_拆集复核.md` 顶部画出整部骨架：

1. **开篇黄金集群（前 3-4 集·留存投资最高）**：首集扛 **世界观 + 主角核心欲望 + 系列总钩（追完整部的大悬念）**；前几集钩子**强度递增**，不许出现弱钩集。对应 `拆集法.md` P6 首集加权 + P2 冷开场。
2. **情绪递进区（中段）**：每集张力阶梯整体上抬，避免长段平台期；这里是连续弱钩集群的高发区，重点盯。
3. **大反转集（≥1-2 个·全剧脊梁）**：身世/阵营/金手指/关系的颠覆性反转，定位到具体集号，作为留存的"二次起飞点"。
4. **付费/AD 卡点集（看变现模式）**：付费=付费墙集；免费=广告位/章末卡点 + 中段保留关键集。卡点集的断点强度必须=全剧顶格。
5. **断点强度梯度**：整部的集尾断点强度（强/中/弱）分布要**健康**——无连续弱钩集群、卡点集顶格、开篇集群无弱钩、收尾留系列总钩。
6. **看点类型分布（北极星四类的跨集配比）**：整部不能全堆**爽点/打脸**一种看点，以免同质化疲劳。把四类看点（**爽点/打脸 · 强反转 · 情绪峰 · 视觉奇观**）在全剧穿插：爽点打底、反转作脊梁、情绪峰承载人物回报、视觉奇观作差异化锚点；每集核心看点写进人工 `_拆集复核.md`，再结合项目反馈调整配比。

## 三、变现模式 → 骨架差异（`变现模式` 选择点）

`变现模式`（软默认/高级覆盖，不列首跑必问；默认 **免费**）驱动卡点定位与断点策略：

| 变现模式 | 结构重心 | 断点策略 | 卡点 |
|---|---|---|---|
| **免费**（默认·红果/番茄） | 全剧延续性、完播率 | 断点**平均强**，消灭连续弱钩集群 | 不设单点付费墙；中段保留关键集 + 章末钩 |
| **付费**（小程序剧） | 项目发行合同/第一方漏斗定义的卡点峰值 | 已配置付费墙集顶格最强；未知时只建议补政策 | 卡点来自项目显式配置 |
| **海外**（竖屏发行） | 依目标平台与地区做早段留存校准 | 节拍与断点频率按第一方数据校准 | 卡点来自项目显式配置 |

> 变现模式不改 P0→P6 边界铁律本身，只改**整部断点强度的分布目标**与**卡点集定位**。

## 四、机检：boundary_audit 的剧级输出

> **叙事一致性审计优先级（G-S1·2026-06-24·ConStory-Bench arXiv 2603.05890）**：`beat_audit.py <作品根> --series` 末尾给一个 report-only 的「中段×高熵」一致性审计优先表（`narrative_risk_profile`）——长篇 LLM 一致性 bug 经验上聚集叙事**中段 + 高 token 熵段**，故按 `mid_arc_weight × token_entropy` 给每集排风险分，建议前 1/3 的集让 `n2d-review/consistency_audit` 深审 + 加密抽帧/人审（≥4 集才给；不改判定、不阻断）。
> **看点高潮位复核（北极星看点④·阶段2·report-only）**：`--series` 还产 `highlight_climax_profile`——**用真实 `镜头时长.json`** 量每集最强看点（爽点💥/峰值情绪/信息+情绪叠加）落在时间轴哪个百分位，flag **集内"虎头蛇尾"**（`highlight_too_early`：看点堆前段 <45%、高潮后长尾再无钩）与 **"平庸无看点集"**（`no_highlight_beat`：有时长却零看点拍）。这是 `boundary_audit` 拆集层词面奇观初筛**够不到的时间轴维度**：拆集层只有词/集尾强度、没有真实秒；storyboard 定稿出 `镜头时长.json` 后此检才激活，两层分工互补。健康高潮位约 60-85%（爽点后留 1-2s 再集尾 cliffhanger）。

`boundary_audit.py` 在逐集体检表之外，输出 **「剧级追更骨架」** 段（题材词典按 `题材` 选择点切换，见 Gap3）：

```bash
python3 skills/n2d-script/scripts/boundary_audit.py <作品根>            # 全剧骨架体检
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> 2-10       # 精修窗口
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> --json     # 机器可读（series_arc 块）
python3 skills/n2d-script/scripts/boundary_audit.py <作品根> --strict   # 阶段1入口硬门
```

它机检并报：
- **断点强度分布**（强/中/弱计数）——强=悬念标点+词钩齐，中=其一，弱=无（软断恒判弱）。
- **连续弱钩集群**（≥2 连续弱钩集）——断点流失高风险段，建议并入相邻强断点集或补强集尾钩。
- **疑似无闭环/纯铺垫集**——缺冲突或缺爽点/反转（P1），复核是否并入相邻集。
- **开篇集群钩子梯度**——前 3-4 集若有弱钩，提示复核开篇投资；这是可校准启发式，不是跨平台定律（P6）。
- **显式卡点策略 + 付费墙强度入闸**——`变现模式=付费/海外` 并不自动生成第 8/10 集卡点。只有 `_设置.md` 的 `付费卡点集/付费墙集`，或 `脚本/paywall_policy.json` 中带来源的 `paywall_after_episode/paywall_episodes/unlock_points` 才进入 `cliffhanger_targets`；已配置卡点若断点不足，输出 `weak_configured_paywall` blocker。策略未知时只产 advisory `paywall_policy.status=unknown`，不硬挡。免费档不设单点付费墙。
- **视觉奇观放置（report-only·北极星看点④）**——含大战/渡劫/觉醒/法宝出世/万人场/末日等视觉高潮的集，机检 **奇观是否被切点劈成两半**（上集尾 + 下集头同含奇观词）或 **奇观集断点偏弱**（奇观没收在集尾高潮位、疑埋中段未当锚点）。建议把奇观当整集锚点（AI 漫剧差异点）。**纯报告，不进 strict 闸**（仅"含奇观词"本身不报，只报放置问题，避免噪声）。

> 这些是**确定性预筛**，不替代人/LLM 判钩力。`series_arc` 始终按全剧 rows 计算；高风险边界以稳定 `blockers[].code + 双侧 boundary_contract` 进入 `boundary_review.json`。机器 draft 与人工决定分离，改边界必须有 applied receipt 后再逐集写词。
> 逐集**集内**留存曲线（黄金3秒/钩子密度/集尾 cliffhanger）见 `n2d/references/导演节奏.md`；集内节拍密度机检见 `beat_audit.py`（Gap4/5）。
