# 现代都市 / 悬疑场面分镜

本文件用于都市、悬疑、刑侦、商战、校园、现实向爽文等题材的高频场面。目标不是把镜头写得“更现代”，而是把现代物件、屏幕文字、证据链和低光空间关系锁成可执行契约，避免出图/出视频时出现车体漂移、屏幕乱码、证据变形、尾随方向跳变。

## 0. 总原则

1. **现实物件先入库**：长期复用车辆、手机、电脑、监控画面、票据、钥匙、录音笔、证物袋、工牌、合同等，先登记到 `asset_registry` 的 `VEHICLE/PROP/EVIDENCE`，锁剪影、颜色、编号、磨损、标志位。
2. **可读文字走 overlay**：手机聊天、短信、来电、转账、定位、监控时间码、电脑邮件、合同条款、车牌等，默认 `text_layer=overlay`。AI 只画设备底图、反光、模糊 UI 或空白界面，清晰文字由 n2d-compose 叠。
3. **空间轴线比气氛词重要**：走廊、停车场、电梯、办公室、审讯室、街口、车道、高架，都要写 `floor_plan/axis_rules/screen_direction`，不要只写“压迫感”“神秘感”。
4. **一镜只揭一个信息**：屏幕插入只读一条关键信息；搜证只发现一个物证；尾随只做一次逼近/露出/躲开；追车只做一次变道/刹车/撞点/逃脱。
5. **风格影响表现，不改变模板**：赛博都市、写实刑侦、校园青春、港风夜雨、日系悬疑都可以改变光色、镜头质感、服装和场景，但 `road_vehicle/screen_insert/evidence_search/stealth_stalk` 的字段仍要完整。

---

## 1. 现代车辆 / 车流 / 追车（`road_vehicle`）

**使用场景**：出租车、网约车、警车、救护车、摩托、电动车、公交、城市高架、公路追车、停车场急刹、车内驾驶反应。仙侠马车/兽车仍用 `vehicle_ride`；现代道路车辆用 `road_vehicle`。

**拆法**：
- 建立车型：锁车型、颜色、车灯、车轮数量/位置、车牌是否可见、驾驶位。
- 车道方向：锁 `screen_direction`、车道、路口/高架/停车场平面关系。
- 运动感：速度交给轮转、路面线、街灯、车流、护栏、雨水和镜头跟拍。
- 结果拍：只做一个变道、刹车、转弯、擦肩、追近或抵达。

**额外必填字段**：`vehicle_lock`、`wheel_rotation`、`driver_control_lock`、`lane_lock`、`traffic_flow`、`speed_curve`、`spatial_path`、`camera_path`、`screen_direction`、`parallax_layers`、`readability_beats`、`degrade_plan`

**保真实现**：车外高速全景不稳时，拆轮胎、后视镜、司机手、仪表盘、车窗外掠过、车内反应、车停住落幅。追车升级为多镜段落时，先用 `chase` 锁追逃距离，再用 `road_vehicle` 锁具体车体/车道。

---

## 2. 手机 / 电脑 / 监控屏幕（`screen_insert`）

**使用场景**：聊天记录、短信、来电、通话界面、定位、转账、付款码、邮件、电脑屏幕、监控回放、CCTV 时间码、录音波形、弹窗提示。

**拆法**：
- 设备建立：锁手机/电脑/监控屏的型号、方向、边框、持有关系。
- 信息读取：屏幕内容走 `overlay_content`，给 0.6-1.2s 稳定可读半拍。
- 反应承接：切手部、眼神、反打或证据物，不在同镜里再塞新动作。

**额外必填字段**：`device_lock`、`screen_content_ref`、`text_layer`、`overlay_content`、`reflection_policy`、`hand_pose_lock`、`readability_beats`

**硬规则**：`text_layer=overlay` 是默认。AI 不负责生成可读中文、数字、聊天气泡、时间码、金额、账号、车牌；除非项目显式决定少量 baked 文本并接受重抽风险。

---

## 3. 搜证 / 物证发现 / 证据链（`evidence_search`）

**使用场景**：翻抽屉、查档案、发现血迹/指纹/脚印/钥匙/票据/录音笔/照片、证物袋入画、照片墙/线索板、现场勘查。

**拆法**：
- 搜查路径：手从哪里进画、翻开什么、遮挡顺序如何。
- 物证露出：`reveal_frame` 给物证完全露出的半拍。
- 证据链承接：拍照、装袋、标号、角色反应或贴到线索板。

**额外必填字段**：`clue_object`、`search_path`、`reveal_frame`、`evidence_chain`、`hand_pose_lock`、`occlusion_order`、`contamination_guard`、`readability_beats`

**保真实现**：物证必须入 `PROP/EVIDENCE`，锁形态、污渍、编号、折痕、位置。不要一镜连续“翻找→发现→追人→打斗”；发现后若进入追逐/打斗，分别切到 `chase` / `fight_exchange`。

---

## 4. 尾随 / 潜入 / 暗走廊（`stealth_stalk`）

**使用场景**：尾随、跟踪、潜入、躲藏、窥视、门缝观察、停车场暗处、楼梯间、档案室、手电光扫过、目标消失。

**拆法**：
- 建立距离：谁在前、谁在后、隔几米、屏幕方向和遮挡物。
- 遮挡逼近：门框、货架、车柱、窗帘、雨伞、玻璃反光只选 1-2 层主遮挡。
- 明暗控制：灯源、暗区、手电范围、剪影边缘写清。
- 露出或躲开：只做一个 `reveal_or_hide_beat`。

**额外必填字段**：`screen_direction`、`distance_curve`、`occlusion_layers`、`light_shadow_lock`、`speed_curve`、`spatial_path`、`camera_path`、`parallax_layers`、`reveal_or_hide_beat`、`readability_beats`、`degrade_plan`

**保真实现**：潜入镜不等于把画面调黑。要让观众看清关系：脚步声、手电边缘、门缝视线、半张脸剪影、目标影子，都比大段黑场更稳定。若变成奔跑追逐，切 `chase`；若进入审讯/对质，切 `public_confrontation`。

## 5. 都市/悬疑常见场面与模板选择

| 场面 | 首选模板 | 备注 |
|---|---|---|
| 高架车流、追车、急刹、停车场驶入 | `road_vehicle` | 锁车体、车道、轮转、车流和驾驶控制 |
| 车内低幅度对话/眼神 | `dialogue_shot_reverse` 或 `dialogue_closeup` | 车外运动可用窗外 parallax 承接 |
| 手机聊天、来电、定位、转账 | `screen_insert` | 文字/数字走 overlay |
| 电脑邮件、监控回放、时间码 | `screen_insert` | 监控噪声/扫描线可 baked，文字仍 overlay |
| 搜抽屉、发现血迹/指纹/票据 | `evidence_search` | 物证入 `EVIDENCE`，锁 reveal_frame |
| 证据当众揭穿/反应链 | `reveal_reaction_chain` | 证物来源可接 `evidence_search` |
| 审讯室、谈判桌、办公室对质 | `public_confrontation` | 锁权力座位、证据阶梯和反应顺序 |
| 尾随、潜入、门缝窥视 | `stealth_stalk` | 锁距离曲线、遮挡层、明暗 |
| 跑巷、楼梯间追逐 | `chase` | 若有具体车辆则并用 `road_vehicle` 段落 |
| 多人办公室/会议室群戏 | `ensemble_blocking` | 主次分层，清晰脸登记槽位 |

## 6. 出视频自查

- [ ] 车辆镜是否写 `road_vehicle` 字段，且车体/车轮/车道/屏幕方向不靠模型自由发挥？
- [ ] 屏幕镜是否 `text_layer=overlay`，并把聊天、数字、时间码交给 compose？
- [ ] 搜证镜是否只揭一个物证，写了 `clue_object/search_path/reveal_frame/evidence_chain`？
- [ ] 潜入尾随是否写了距离曲线、遮挡层、光影锁和唯一露出/躲开拍？
- [ ] 都市/悬疑风格是否只影响光色、材质、镜头质感，而没有省略模板字段？
