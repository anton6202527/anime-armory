## 〇、核心方法论（和打斗共用的一句话）

> **把一段奇观拆成关键帧 → 用图把关键帧锁死 → 用首尾帧让视频只做"帧间插值/受控运动"（不让 AI 自由发挥）→ 用剪辑+音效+特效在后期补"感"（速度感/危机感/打击感/恢弘感）。**

这是 n2d「先出图锁死、图生视频只控运动」铁律在所有奇观戏上的延伸。崩，根因都是"让 AI 自己编"；解法都是"形态由关键帧图决定，视频只负责受控地动起来"。

**这几类场面共同的三大死因 → 解法（速查）：**

| 死因 | 现象 | 解法（落到哪一步）|
|---|---|---|
| 让 AI 编大动态 | 飞行飘忽、追逐丢距离、雷击乱闪 | **关键帧出图锁死 + 首尾帧/受控运动引导视频**（image+video）|
| 奇观元素漂 | 飞剑/云/坐骑/马车/飞舟/劫雷/丹火/阵图每镜不一样 | **奇观元素进共享定妆库**（image，和角色脸/法宝特效同等）|
| 没"空间/递进交代" | 看不懂谁在哪、强度没层次 | **establish 广角 + 节奏曲线分段**（script）|

**和"动背景不动人"的关键技巧**：飞行/御兽/马车/飞舟/追逐这类"高速移动"，**别让 AI 乱动人物或载具主体**（一动就崩姿态、接触、车体和脸），而是**锁住人物姿态/骑乘接触/车体/飞舟剪影，让背景、云层、速度线、步态循环、轮转和镜头跟随动起来**——速度感来自背景与镜头，不来自主体自身变形。这是本文件最值钱的一条。

## 一、御剑飞行 / 飞行类（御剑·御物·腾云·踏空·轻功掠空）

### 1.1 难点
飞行 AI 最易：人物**飘**（姿态不稳像悬浮）、剑/云**不稳**（每帧形态变）、**没速度感**（像定在原地）、背景**贴图感**（人与景两层皮）、镜头不知怎么动。

### 1.2 关键帧拆解（飞行三态）
| # | 态 | 画什么 | 景别/运镜 |
|---|---|---|---|
| 1 | **起飞** | 落剑/踏空/腾身，剑光亮起、衣袂气劲鼓荡、足下生云 | MS/LS·由下仰拍（显腾起）|
| 2 | **巡航**（定妆级）| **标准飞行姿态**：御剑（前倾/负手立剑）或腾云（盘坐/踏云），背景云层/山河高速后掠 | LS/跟拍·侧飞或对冲 |
| 3 | **机动** | 转向/俯冲/急停/穿云——飞行里的"爽点" | CU/主观·快推或下坠 |

**铁律**：
- **巡航姿态定一张"飞行定妆"复用**（如 `定妆_主角御剑巡航.png`），全程同姿态，只换背景与镜头——这是治"飘"的根。
- **速度感 = 背景流动 + 镜头跟随 + 速度线/拖光**，不靠人物动。
- 飞剑/法器/云的形态**进共享定妆库**（`定妆_青锋飞剑.png`、`定妆_脚下祥云.png`），锁颜色/形状/拖尾。

### 1.3 节奏曲线
establish 远景（交代"在飞·飞向哪"，长镜 2-3s）→ 跟拍中景（姿态+速度，1-2s）→ 机动特写/主观（俯冲穿云=爽点，碎切快）→ 抵达/落地（留白缓收）。**赶路别匀速长飞**，给一个机动爽点（穿云/俯冲/对冲镜头）才不闷。

### 1.4 视频要点（n2d-video）
- **首尾帧锁姿态**：首帧=起飞，尾帧=巡航；或首尾都用巡航帧（姿态几乎不变），运动全交给背景与镜头。
- prompt 写：**"人物姿态几乎保持不变；云层/山河向后高速掠过；镜头侧向跟飞（或对冲快推）；衣袂、剑穗、发丝向后飘"**——明确"动的是背景不是人"。
- `template_contract` 必写 `flight_path / altitude_curve / speed_curve / camera_path / parallax_layers / mount_or_cloud_lock / readability_beats`，视频 prompt 逐项继承到 `动作编排契约`。
- 机动镜头才让人物动（转头/俯身下压），且给镜头同步运动掩护。

### 1.5 迷你示例
```
Clip 御剑追赶（1.6s · 巡航→俯冲）
首帧：出图/第N集/图片/御剑_巡航.png（前倾御青锋，负手，云海背景）
尾帧：出图/第N集/图片/御剑_俯冲.png（同人同剑，身体前压、剑尖下指）
视频 prompt：人物姿态由前倾转为前压下俯（小幅）；脚下青锋稳定（参考 定妆_青锋飞剑）；
            云海向后高速翻涌、地表山峦快速下移并放大；镜头跟飞并下压跟俯冲；
            衣袂剑穗发丝全向后疾飘、叠速度线拖光。
```

## 二、御兽 / 坐骑（骑灵兽·妖兽·仙鹿·灵马·龙背飞掠）

### 2.1 难点
御兽/坐骑比普通飞行多一层物理关系：**骑手、坐骑、鞍具/缰绳、接触点、步态循环**必须同时稳定。AI 易把人浮在兽背上、腿穿进兽身、坐骑体型/角/鳞/毛色漂、奔跑步态重置、方向一会左一会右。

### 2.2 关键帧拆解（骑乘四拍）
| # | 拍 | 画什么 | 镜 |
|---|---|---|---|
| 1 | **建立坐骑** | 坐骑全貌、骑手位置、体型比例、鞍具/缰绳 | LS/MS·侧向或三分之四 |
| 2 | **上背 / 起步** | 骑手坐稳，手握缰绳或抓鬃，坐骑第一步发力 | MS·低角度 |
| 3 | **步态巡航** ⭐ | 锁一种主步态（奔跑/踏云/跃步），背景和尘土后掠 | LS·侧向跟拍 |
| 4 | **转向 / 抵达** | 越障、急停、转头、落地，给结果镜 | MCU/反应/低角度 |

**铁律**：
- 坐骑必须进共享资产库（`BEAST/MOUNT_XX`）：体型、头角/鳞片/鬃毛、毛色、鞍具、缰绳、标志纹样都锁死。
- `mount_contact` 是成败核心：骑手臀部/大腿/脚蹬/手部接触点、遮挡顺序、腿在兽背两侧的位置必须写清。
- `gait_cycle` 只写一种主步态；速度感交给尘土、草木、披风、鬃毛、前景遮挡和侧向跟拍，不让 AI 在一镜里从慢走变冲刺再跳跃。
- `screen_direction` 全程一致；换向必须单独给转向镜，不能在巡航镜里突然反向。

### 2.3 视频要点
- `template_contract` 必写 `mount_contact / gait_cycle / harness_lock / speed_curve / spatial_path / camera_path / screen_direction / parallax_layers / readability_beats / degrade_plan`，视频 prompt 逐项继承到 `动作编排契约`。
- 首尾帧优先锁同一个侧向姿态：首帧=起步/巡航，尾帧=同方向小幅位移或停步；坐骑外形不变，背景、鬃毛、衣袂、尘土动起来。
- 不稳时保真实现：坐骑头部/蹄爪特写 → 骑手握缰反应 → 侧向奔跑短镜 → 停步/抵达镜。不要一镜全景长跑还转向。

### 2.4 迷你示例
```
Clip 灵狼载主角穿林（1.8s · 巡航）
首帧：御兽_灵狼侧奔.png（主角稳坐鞍上，左→右）
尾帧：御兽_灵狼穿过前景树影.png（同人同狼同方向，腿和缰绳接触不变）
视频 prompt：mount_contact=骑手臀部压在鞍垫中央、大腿夹住狼背两侧、右手握缰在狼颈上方；
            gait_cycle=四足奔跑循环，狼体型/银鬃/额角不变；
            screen_direction=左→右；前景树干快速划过，草叶尘土向后飞，镜头侧向跟拍。
```

## 三、马车 / 载具行进（马车·车驾·兽车·轮式法器）

### 3.1 难点
马车/载具最容易崩在**车体结构、车轮数量与旋转方向、马匹/兽与车辕缰绳连接、车内外空间关系**。AI 常见问题是车厢变形、轮子忽多忽少、轮子不转或反转、马匹和车身断开、人物在车内站位漂。

### 3.2 关键帧拆解（行进四拍）
| # | 拍 | 画什么 | 镜 |
|---|---|---|---|
| 1 | **载具建立** | 车厢剪影、车轮数量/位置、马匹/兽、车夫与缰绳 | LS·侧向建立 |
| 2 | **轮转 / 蹄步** ⭐ | 车轮旋转、马蹄/兽蹄节奏、道路尘土 | CU/低角度 |
| 3 | **侧向跟行** | 车厢外形稳定，背景后掠，车内可见人物影 | LS/MS·侧跟 |
| 4 | **颠簸 / 急停 / 抵达** | 越过石坎、拐弯、车帘掀动、停在门前 | 动作切/反应镜 |

**铁律**：
- 马车/载具必须进 `VEHICLE/PROP` 资产库：车厢形状、轮子数量、车辕、窗帘、纹样、主色、损旧程度锁死。
- `vehicle_lock` 锁车体；`wheel_rotation` 只管轮转方向/速度；`harness_lock` 锁马匹/兽与车辕、缰绳、车夫手部的连接。三者分开写，避免车身也被“旋转”带变形。
- 速度感来自车轮、马蹄、尘土、车帘、前景树石和背景视差，不来自车厢变形。
- 车内戏和车外行进尽量拆：外景表达“车在走”，内景表达人物反应；不要一镜既要看清车外高速又要看清车内多人表演。

### 3.3 视频要点
- `template_contract` 必写 `vehicle_lock / wheel_rotation / harness_lock / speed_curve / spatial_path / camera_path / screen_direction / parallax_layers / readability_beats / degrade_plan`，视频 prompt 逐项继承到 `动作编排契约`。
- 首尾帧锁同一车体剪影，wheel_rotation 写“前后轮同向顺时针/逆时针、速度与路面相符”，禁止“轮子变数量/车厢改造型”。
- 不稳时保真实现：车轮特写、马蹄/兽蹄特写、车夫手握缰、车内人物反应、抵达停步，靠剪辑拼出行驶。

### 3.4 迷你示例
```
Clip 山路马车疾行（1.5s · 侧跟）
首帧：马车_山路侧向.png（两匹黑马拉四轮车，画左→画右）
尾帧：马车_过石坎.png（同车同马同方向，车厢微颠）
视频 prompt：vehicle_lock=四轮木车厢、青布车帘、前后轮位置不变；
            wheel_rotation=四个车轮同向快速滚动，轮毂不增减；
            harness_lock=两匹黑马缰绳连接车辕，车夫双手握缰；
            screen_direction=左→右；前景树影快速划过，山路尘土向后扬起。
```

## 四、飞舟 / 御物飞行（灵舟·云舟·飞梭·飞行法器·大型御物）

### 4.1 难点
飞舟/御物飞行不是“人物御剑”的小尺度飞行，而是**载具剪影 + 空间高度 + 云层/山河视差 + 乘员/甲板关系**。AI 易把飞舟越飞越像别的船、桅帆/阵纹乱变、尺度忽大忽小、航向翻转、云层贴图感重。

### 4.2 关键帧拆解（飞舟四拍）
| # | 拍 | 画什么 | 镜 |
|---|---|---|---|
| 1 | **入画 / 起航** | 飞舟或法器剪影出现，阵纹亮起，云雾被推开 | ELS/LS·仰角或远景 |
| 2 | **巡航** ⭐ | 船体姿态稳定，云海/山河/前景遮挡高速后掠 | LS·侧向跟飞 |
| 3 | **机动** | 穿云、转向、俯冲、悬停，最多一个动作 | 主观/俯冲/慢推 |
| 4 | **抵达 / 显景** | 飞舟停在山门/秘境前，交代目的地和比例 | ELS→LS |

**铁律**：
- 飞舟/法器必须进 `VEHICLE/PROP` 资产库：船体剪影、船舷、桅帆/龙骨/阵纹、拖光颜色、甲板尺度锁死。
- `vehicle_lock` 锁载具外形；`flight_path` 写画面路径；`altitude_curve` 写高度变化；`screen_direction` 写航向；`parallax_layers` 写云/山/前景遮挡层。
- 飞舟巡航时**船体少动，背景多动**。转向/俯冲/悬停拆成短镜，不能一镜连续做入画、转弯、俯冲、降落。
- 乘员若要清脸，拆甲板反应镜；飞舟外景只表达空间、速度和尺度。

### 4.3 视频要点
- `template_contract` 必写 `vehicle_lock / flight_path / altitude_curve / speed_curve / spatial_path / camera_path / screen_direction / parallax_layers / readability_beats / degrade_plan`，视频 prompt 逐项继承到 `动作编排契约`。
- 首尾帧锁同一飞舟剪影：首帧=云海左侧入画，尾帧=右上方穿云或抵达；船体只小幅位移，云层/山河/前景遮挡制造速度。
- 不稳时保真实现：飞舟入画远景 → 云层掠过特写 → 甲板人物反应 → 目的地远景抵达。

### 4.4 迷你示例
```
Clip 灵舟穿云抵达山门（2.0s · 巡航→显景）
首帧：飞舟_云海左入.png（青铜灵舟，阵纹蓝光，左→右上）
尾帧：飞舟_山门前悬停.png（同一灵舟剪影，远处山门出现）
视频 prompt：vehicle_lock=青铜灵舟剪影、三层船舷、蓝色阵纹和拖光不变；
            flight_path=画左下入画沿云海弧线到画右上；altitude_curve=低云层→穿云抬升→山门前悬停；
            screen_direction=左下→右上；前景云层高速掠过，远山慢移，镜头侧向跟飞后缓推山门。
```

## 五、追逐（地面轻功追 / 御剑空中追 / 法术追逐：剑气法宝在后追人）

### 5.1 难点
追逐 = 连续运动 + 空间关系，AI 易丢 **谁追谁 / 距离感 / 方向**；双人同框跑必崩；背景重复单调；**轴线乱**（一会左→右一会右→左，看着像迎面对跑）。

### 5.2 关键帧拆解（追逐四拍）
| # | 拍 | 画什么 | 镜 |
|---|---|---|---|
| 1 | **发现 / 拉开** | 逃者狂奔、回头瞥见追者；交代初始距离 | 逃者镜（主观回头）|
| 2 | **逼近** | 追者迫近、距离缩小（剪辑制造"越追越近"）| 追者镜 |
| 3 | **险情** | 障碍/分叉/绝路/反击——追逐的"心跳点" | 环境/正反打 |
| 4 | **结果** | 甩开（喘息）或被擒（接下一段戏）| 收束镜 |

**铁律**：
- **正反打交替代替双人同框**（追者镜 ↔ 逃者镜），**靠剪辑制造距离变化**，别强求一镜两人追。
- **轴线一致**：追逐方向全程同向（都左→右），换向要给一个明确的转向镜过渡，否则观众方向感崩。
- **速度感同飞行**：镜头跟拍 + 背景流动 + **前景遮挡物快速划过**（廊柱/树干/人群掠过镜头）+ 偶发障碍。
- 路线环境锚点入库（过同一座桥/林/街），别每镜换地图。

### 5.3 节奏曲线
紧（快切碎，跟拍）→ **险情顿一下**（障碍/绝路放大危机，半拍慢）→ 更紧（提速）→ 结果（甩开=留白喘息 / 被擒=硬切定格）。追逐就是"紧—险—更紧—放"。

### 5.4 视频要点
- 单人跟拍 clip（追者一段 + 逃者一段），别一镜两人；用**主观镜头**（逃者回头看追者迫近 / 追者视角锁定背影）拉代入。
- prompt：**"人物原地跑动姿态循环；背景与前景遮挡物向后高速流动；镜头跟拍（侧随/背跟）"**——又是"动背景"。
- `template_contract` 必写 `screen_direction / distance_curve / obstacle_beats / speed_curve / spatial_path / camera_path / parallax_layers / overtake_or_escape_beat`，只允许一条主距离变化。

### 5.5 迷你示例
```
Clip 巷中追逃（险情拍）
逃者镜(0.7s·快)：少女狂奔回头，惊惶；前景廊柱快速划过镜头
追者镜(0.6s·快)：黑衣人贴地疾掠迫近，画面同向（左→右）
险情镜(0.9s·半顿)：前方死巷/横出障碍——危机放大，少女急刹
后期：脚步/破风快节奏 + 险情瞬间 BGM 抽一下 + 心跳低频
```

## 六、渡劫 · 突破（`tribulation_breakthrough` · 天劫雷云 / 渡劫雷电 / 境界突破光柱）

### 6.1 难点
雷电 / 天劫光柱 AI 乱闪、不连贯、**雷与人的接触点假**（雷不知劈在哪）、光效漂、缺"**层层加码**"的递增节奏（一道雷和九道雷拍得一样就不燃）。

### 6.2 关键帧拆解（渡劫五段·递增）
| # | 段 | 画什么 | 节奏 |
|---|---|---|---|
| 1 | **天象异变** | 乌云汇聚、天地变色、罡风起（establish）| 长镜·缓推，憋 |
| 2 | **首劫·试探** | 第一道劫雷劈下，人物凝神承受 | 中速 |
| 3 | **连劫·递增** | 一道比一道猛、越来越密越来越亮 | 逐道加速 |
| 4 | **死生一劫** ⭐ | 最凶一劫（爽点顶点）：雷柱轰顶、护体几碎 | **顿帧·CU·最长** |
| 5 | **突破** | 撑过 → 光柱冲天 / 气势暴涨 / 境界跃升 | 爆发后留白 |

**铁律（和打斗命中帧同构）**：

- **层层加码**：劫雷一道道来，每道间留"喘息+蓄力"，最后一道最长、最亮、顿最久。别九道雷平均用力。
- 劫雷形态 / 护体光 / 突破光柱**进共享定妆库**（`定妆_紫劫雷.png`、`定妆_突破金光柱.png`），多道雷复用同一定妆不同角度/粗细。

### 6.3 视频要点
- 雷落用**首尾帧**（将落：雷蓄于云 → 击中：雷柱触体），AI 只插值雷的下落，不自由乱闪。
- 人物承受：**锁姿态**（凝立/单膝撑地），光效闪烁/雷光交给特效与后期，别让 AI 动人。
- 突破：光柱**上升运动** + 人物气势张开（缓抬头/睁眼），镜头缓拉远显恢弘。

### 6.4 后期（n2d-compose）

- 递增感：每道雷的音量/闪白强度逐道加大，最后一道顶。
- 突破：光柱起 + **BGM 推到全曲最高潮** + 持续亮白过曝 0.3s + 长留白让"成了"沉下来。

## 九、大场面 establish（山门洞府 / 秘境奇观 / 万人朝拜 / 仙山云海）

### 9.1 难点
大远景 AI 易**糊**、世界观**贴图感**、跨镜**地理不一致**、**人/景比例失调**（仙山该巍峨却显小）。这不是动作戏，是"**空间交代**"，最容易被随便一镜带过而显廉价。

### 9.2 关键帧拆解（进入三镜·由远及近）
| # | 镜 | 画什么 | 运镜 |
|---|---|---|---|
| 1 | **大远景·气势** | 全貌：仙山 / 宗门 / 秘境全景，云海衬底 | ELS·缓摇 / 航拍缓降 |
| 2 | **中景·地标** | 标志性局部（山门匾、主峰、巨阵）| LS·缓推 |
| 3 | **人物入画** | 把人放进世界（小人 / 小舟入画）| MS·人景同框 |

**铁律**：
- **比例尺：以小衬大**——放一个小人 / 小舟 / 飞鸟在画里，衬出仙山之巍峨（不放参照物就显小）。
- **地理锚点入库**：标志性地点建"**场景定妆**"（沿用角色卡/场景卡机制，大场面也要锚），**跨集复用同一张 establish**，别每集换山门。
- **三镜递进，别一镜糊一片**：一镜既要恢弘又要每个细节清楚 = AI 必糊；分"远全貌→中地标→近人物"三镜走。
- 运镜慢（缓推 / 缓摇 / 航拍下降），让观众"看清世界"。

### 9.3 后期
配**空灵 BGM + 环境音**（风 / 钟 / 鹤唳 / 诵经底噪），慢节奏，给世界"呼吸感"。establish 镜不抢戏、给足时长（2-4s），是"喘息 + 沉浸"位。

## 十、斗法对轰（法术对撞 / 僵持顶法 / 压制反压）

### 10.1 难点
两人放法术对轰 = 双主体 + 光束相撞 + **力量对比**，AI 易：光束乱飘、撞点不知在哪、僵持没张力、谁压谁看不懂、双人同框崩。
> 与打斗的区别：打斗（`打斗分镜.md`）是**近身命中**（五帧·命中接触）；斗法对轰是**远程能量对冲 + 僵持顶法**，多一个"撞点位置较劲"的力量对比段——故独立成节。

### 10.2 关键帧拆解（对轰五拍）
| # | 拍 | 画什么 | 镜 |
|---|---|---|---|
| 1 | **双方蓄法** | 各自掐诀/凝灵力、法术将出（正反打）| 甲镜 / 乙镜 |
| 2 | **对轰·相撞** ⭐ | 两道法术在中间撞上，撞点炸开能量团/顶住 | 撞点 CU/双人极远 |
| 3 | **僵持·顶法** | 撞点僵在中间、能量团较劲；**撞点偏谁谁弱** | 撞点 + 表情特写切 |
| 4 | **压制 / 反压** | 撞点推移——一方占上风，光墙推向另一方 | 撞点移动 + 占优方 |
| 5 | **破防·轰飞** | 撞点击穿，败方护体碎、被轰飞 | 败方 MS·快 → 留白 |

**铁律**：
- **撞点 = 这场的"命中帧"**（同打斗命中帧地位）：撞点独立出图，画能量对冲炸团/挤压、放射状速度线。
- **别一镜塞两人对轰**：用正反打（甲放招镜 → 乙放招镜 → 中间撞点镜），撞点镜可双人极远或只给能量团。
- **双方法术光束/能量进共享定妆库**（同 §〇 入库 + `打斗分镜.md §五`），**两色区分**（如金 vs 黑）全程一致。
- **僵持靠"撞点位置移动"叙事**（偏谁谁弱）+ 表情特写（咬牙 / 吐血 / 狞笑）快切，别让 AI 自由演较劲。

### 10.3 节奏 / 视频 / 后期
蓄法（憋）→ 相撞（炸）→ 僵持（持续紧，可叠对话/较劲台词）→ 压制（撞点推移、提速）→ 破防（顿 + 轰飞 + 留白）。
- 视频：撞点镜用**首尾帧**（相撞 → 撞点偏移）锁能量走向；放招人**锁姿态**（顶法姿态不变）只动光效。
- 后期：撞点持续嗡鸣轰响、光团呼吸明灭；压制时音量推高；破防 = 炸雷级 impact + 闪白 + 震屏 + BGM 抽真空再起。

### 10.4 迷你示例
```
Clip 顶法破防（僵持→破防）
相撞镜(双人极远·0.8s)：金掌劲 vs 黑魔焰在中央撞成光团（参考 定妆_金掌劲/定妆_黑魔焰）
僵持切(各0.4s)：甲咬牙稳住 / 乙狞笑加力——撞点缓偏向甲（甲渐弱）

破防(0.6s·顿+爆)：乙护体黑光碎裂被轰飞 → 0.8s 留白缓拉

```

## 十一、神魂场面（`soul_manifestation` · 神识探查 / 元神出窍 / 夺舍夺体 / 神魂攻击）

### 11.1 难点
神魂/神识是"**看不见的东西可视化**"，AI 易：元神形态**漂**（每镜不一样）、**"二我"穿帮**（肉身+元神同框不像同一人）、神识探查拍成**空镜没信息**、夺舍的"两魂相争"**看不懂**。

### 11.2 关键帧拆解（按子类型）
| 子类型 | 拆解 | 要点 |
|---|---|---|
| **神识探查** | 眉心光点 → 神识波纹扩散（俯视掠过山河/人群）→ 锁定（波纹回缩聚焦）| 主观 + 俯视给信息，少人物动作 |
| **元神出窍** | 肉身入定（盘坐闭目）→ 元神虚影自天灵升起（半透明、与肉身同貌）→ 元神行动 | **"二我"同框**：元神=肉身的半透明发光态 |
| **夺舍 / 夺体** | 入侵魂（黑雾/异色元神）扑向目标 → 两魂相争（体表光色拉锯）→ 夺舍成（睁眼变神色/瞳色变⭐）| 成败帧是爽点，单独出图 |
| **神魂攻击** | 神魂之力击中元神 → 魂体震荡/裂纹（命中帧同打斗）| 命中帧独立出图 |

**铁律**：

- **神识探查靠"波纹 + 主观 + 俯视"给信息**，别拍成纯空镜（观众得"看见神识扫过哪里"）。
- **夺舍"两魂相争"靠体表光色拉锯 + 表情狰狞切**，别要求一镜画两个魂打架。
- 神魂攻击命中帧同打斗命中帧（独立出图 + 顿 + 音效）。

### 11.3 节奏 / 后期
神识=波纹扩散（缓）→聚焦（顿）；元神出窍=入定（静）→升起（缓、神圣感）→行动；夺舍=扑入（快）→相争（拉锯紧）→成败（顿 + 变色爽点）。
- 后期：神识=空灵嗡鸣 + 波纹音；元神出窍=缥缈 BGM + 升起气音；夺舍相争=低频压迫 + 两音色拉锯，夺舍成=一记定音 + 瞳色变特写；神魂攻击命中=闷响 + 魂体闪。
- 视频：元神升起用**首尾帧**（肉身 → 元神升起）；"二我"**锁两者姿态、只动半透明度/光**；夺舍扑入用首尾帧。

## 十四、一句话总纲

> **飞行/御兽/马车/飞舟/追逐——锁主体形态，速度交给背景、视差、步态循环、轮转和镜头；渡劫/炼丹/法阵/斗法对轰——拆递增、爆发帧(命中/撞点)单独出图、奇观元素入库锁死；神魂——元神=肉身半透明派生治"二我"、神识靠波纹给信息；大场面——三镜由远及近+比例尺+地标复用。** 和打斗同源：关键帧锁死、视频只受控运动、后期补"感"。完整拆招见各节；打斗一类见姊妹篇 `打斗分镜.md`。
