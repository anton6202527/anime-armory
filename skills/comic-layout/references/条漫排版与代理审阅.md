# 条漫排版与代理审阅

## 默认决策

- 保留高分辨率制作母版；按目标平台在导出阶段派生宽度、格式、质量和纵向切片，不用发布尺寸反向限制母版细节。
- 每个滚动段同时检查完整长段和手机可视窗口：入口是否立即可读、文字是否能在移动端辨认、关键揭示是否被切在尴尬位置、连续两屏是否缺少节奏变化。
- `validator=pass` 只证明结构事实；制作代理还要审阅格子轻重、滚动呼吸、主体/文字避让、段尾钩子和跨段兑现。

## 当前一手依据

- [Clip Studio Paint Webtoons](https://help.clip-studio.com/en-us/manual_en/540_comic/Webtoons.htm)：提供手机 on-screen area、指定导出宽度、连续长图和按像素纵向切分，支持“母版—手机窗口—平台切片”三层检查。
- [Tapas 发布漫画章节](https://help.tapas.io/hc/en-us/articles/1260802028970-Series-Basics-How-to-publish-a-comic-episode-on-Tapas)：当前页面宽940px、PNG/JPG/GIF、单文件10MB，并明确建议用桌面端和移动端预览文字可读性。
- [WEBTOON CANVAS 图片规格](https://webtooncanvas.zendesk.com/hc/en-us/articles/32913712749588-File-Size-Overview-What-to-Know-before-Publishing-your-Comic-on-WEBTOON-CANVAS)：缩略图与文件限制会更新；执行发布前重新核验官方页面或 Creator Dashboard，不把旧快照当永久规则。

访问日期：2026-07-15。平台规则属于动态信息，公开发布前必须重新核验。

## 用户授权制作代理

只有用户明确选择 `审阅策略=用户授权制作代理` 时，制作代理才可代行缩略分镜、排版、原稿收尾、参考处方、内部技术审查等常规可逆审批。每次审批必须：

1. 先通过确定性 validator 和上游 SHA 检查；不得签收确定性缺件或过期合同。
2. 查看 JSON 真值与 SVG/contact sheet/手机窗口预览，不只看脚本命令成功。
3. 在审批备注中引用项目授权文件、审阅范围、证据和结论。
4. 对启发式告警给出明确判断，不把相似度分数伪装成事实。

以下仍需用户介入：付费或预算范围扩大、外部发布/商业交付、版权/授权/敏感合规、不可逆删除或覆盖、改变核心故事/角色/美术方向、存在两个影响显著且无证据优势的方案。代理授权不扩大这些权限。
