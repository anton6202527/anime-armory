# 漫画审查 checklist

## 脚本

- 本话有明确开场吸引。
- 每格 `story_function` 不为空。
- 台词不过长，旁白不重复画面已经表达的信息。
- 结尾有收束或钩子，不是纯中断。

## 排版

- `传统原稿流程=启用` 时，应有 `排版/第N话/name_board.json`，并记录页流、格子轻重、翻页钩子、气泡优先方向和原稿安全框。
- 阅读顺序明确。
- 大格用于重点时刻。
- gutter 和安全边距稳定。
- 气泡占位不遮挡脸、手、动作接触点、关键道具。
- 页漫/投稿规格应有 `trim_box`、`safe_area`、`inner_frame` 和出血/裁切风险提示；关键脸、手、道具、拟声词和气泡不得压进危险区。

## 传统原稿收尾

- `传统原稿流程=启用` 时，应有 `出图/第N话/finishing/finishing_plan.json`。
- 每格至少有 `ink_plan`、`black_fill_plan`、`tone_plan` 或 `value_plan`、`effects_plan`；黑白页漫/日漫网点风格建议显式 `tone_plan`。
- 黑场服务焦点和情绪，不是简单压暗画面；不能遮掉角色识别特征、手脚、关键道具或动作接触点。
- 网点/灰阶服务材质、空间深度和情绪层次；不能让主体、背景和文字留白混成一团。
- 速度线、集中线、冲击闪、漫符和背景省略必须指向动作路径、视线焦点或情绪读点；不能乱铺。
- 出图 job 应带 `traditional_finish_contract`，否则 prompt 只是在泛泛要求“漫画风”。
- `lettering_sfx_plan.mode=drawn_sfx` 只适用于拟声词；对白、旁白和系统正文仍后期嵌字。

## 图像

- 必需 panel 图齐全。
- 主角脸、发型、服装、标志物跨格稳定。
- 含角色格已在 `panel_script.json` 写 `gaze_target`、`eyeline_direction` 和 `character_integrity/completeness_notes`；眼神锁具体戏内目标，不写“坚定眼神/看前方/远方”，不无理由看读者镜头。
- 人物完整性不因漫画风格降级：头发、脸、手、脚、服装、标志物和关键道具完整可读；动作格不裁掉叙事必要部位。
- 含场景格已写 `scene_anchor_id`，且该 `LOC_` 已登记在 `visual_contract.scene_anchors`；空间布局、光位/冷暖、轴线视线、常驻物件和禁漂移项可跨格继承。
- 多人同格已写 `spatial_relationships/blocking/staging`：谁在画左/画右、前景/后景、遮挡、接触点和正反打轴线都明确。
- 同一 `LOC_` 场景跨格不得随机换建筑结构、门窗位置、主光方向、冷暖光、人物左右关系或常驻道具；剧情改光/换轴/换景必须在脚本里说明。
- 生图模型/渠道、风格锚和 `style_contract` 统一；`comic_style_consistency_第N话.json` 没有 block，场景族群调整只能用于脚本计划内的光线/场景变化。
- 同一话不能突然从影视级写实国漫跳到低细节彩漫、现代写真、页游塑料感、泛韩漫脸或明显不同调色。
- 同场景冷暖光、饱和度、细节密度和照片感应稳定；有意回忆/蒙太奇变调需要能从脚本叙事解释。
- 单个 panel 不能被模型画成三联画、照片墙、内部分栏、多面板拼贴、外框图或带截图边的设计稿；需要蒙太奇时应是一张连续画面里的重影/远近重复身影。
- `定妆级别=长线专门定妆` 时，常驻角色的 `front / three_quarter / side / back / face` 专门定妆图必须补齐；短 demo 才允许只用锚点过渡。
- 动作能读懂，手部和道具关系清楚。
- 手脚归属清楚：脚尖、鞋靴、脚步、踩踏、跪地或踢击不能被画成手；手掌不能替代脚掌，脚趾不能像手指。
- 武器、道具和地面接触点不穿模、不融合；关键落点应能一眼读懂。
- 背景不抢主体，文字区域有留白。

## 嵌字

- 错字、漏字、标点统一。
- 字号在移动端可读。
- `export_manifest.json` 应记录 `lettering_slot_qc`，嵌字槽位 QC 接触表文件存在且 `missing_slots` 为空。
- `文字语言=中文` 时最终导出只渲中文；`英文`、`中上英下`、`英上中下` 时对应语言字段齐全，英文较长时字号自动更小但仍可读。
- 拟声词不遮挡关键动作。
- 对白文字直接包在不规则气泡内，不再叠一层矩形文字框。
- 空白气泡/无字旁白框不得留在最终导出；没有文字的槽位不画气泡，已烘焙在图里的空泡应回 `comic-image` 重出或明确标为返修。
- 旁白框和对白气泡层级清楚。

## 导出

- `export_manifest.json` 存在。
- 长图已分段，文件命名稳定。
- 缺图列表为空，或已标为草稿不可发布。
- 草稿阶段字体和素材权利未最终确认只记 `info`；正式发布/商用前必须确认，否则 `block`。
