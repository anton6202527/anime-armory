# comic 基础视觉风格候选

核验日期：2026-07-06。`基础视觉风格` 是给 story bible、style guide 和出图 prompt 的基础方向，不绑定具体模型、平台或某位画师。项目 `_设置.md` 可写预设，也可写 `预设(补充词)`；无法归类时写 `自定义(...)`。

## 使用规则

- 优先用“发行形态/地域传统 + 渲染技法”描述，例如 `韩漫清透条漫(现代恋爱, 柔光)`、`黑白日漫页漫(热血战斗, 高密度网点)`。
- 不写具体在世画师、具体 IP、角色名或“某作品同款”；需要参考时改写成可执行的技法词：线条、上色、明暗、材质、构图和节奏。
- `基础视觉风格` 只负责默认美术语言；角色脸、服装、场景色彩、禁漂移项仍写进 `设定库/story_bible.md` 或 style guide。
- 预设不够时不要硬套，可用 `自定义(清线, 低饱和, 古典悬疑, 单色点缀)`。

## 外部核验依据

- WEBTOON 官方说明长竖图会按上传限制自动优化切分，单张最大维度为 `800x1280`；这支持 `韩漫清透条漫`、`彩色国漫条漫` 等竖向全彩候选的发布形态假设。参考：https://www.webtoons.com/en/notice/detail?noticeNo=1766
- Clip Studio 的 webtoon 教程说明竖向漫画通常围绕手机屏幕宽度、长画布和分段导出组织，也强调 webtoon 里的竖向格式和色彩自由度。参考：https://www.clipstudio.net/how-to-draw/archives/157055
- New York Public Library 的 manga 入门说明日漫通常黑白出版，并常按右至左阅读；这支持 `黑白日漫页漫`、`日漫网点热血` 等候选。参考：https://www.nypl.org/blog/2018/12/27/beginners-guide-manga
- Clip Studio TIPS 的 manga effects 总结了集中线、速度线、排线、网点/半调等常见漫画效果；这支持日漫网点、少女漫画、复古半调等技法标签。参考：https://tips.clip-studio.com/en-us/articles/10107
- Europe Comics 与 The New Yorker 对 `ligne claire` 的说明集中在清晰轮廓、强色彩、少排线或均匀线宽；这支持 `欧漫清线` 候选。参考：https://www.europecomics.com/reading-list-ligne-claire/ 与 https://www.newyorker.com/culture/cover-story/cover-story-2018-05-14
