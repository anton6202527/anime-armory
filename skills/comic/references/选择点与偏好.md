# comic 选择点与偏好

选择点首次询问并写入项目 `_设置.md`；同一项目之后沉默沿用。用户显式改选择点时走 `comic-settings` 落档、审计、重置或同步全局默认。合规、不可逆、付费或覆盖已有导出的动作每次重新确认。

| 选择点 | 推荐默认 | 说明 |
|---|---|---|
| 生产档位 | 连载标准 | `短篇验证` / `连载标准` / `连载高一致性` / `出版交付`；通过 `comic-settings set <作品根> 生产档位 <档位>` 原子化展开为定妆、形态继承、一致性硬闸等一组自洽设置 |
| 输入模式 | 原创漫画 | `原创漫画` / `源本改漫画` / `脚本改漫画` |
| 漫画形态 | 条漫 | `条漫` / `页漫` / `四格` / `分镜稿`。deterministic layout 现支持单列条漫 `longstrip_single_column`、页漫 LTR/RTL `paged_grid_ltr|paged_grid_rtl` 和纵向四格 `yonkoma_four_rows`；复杂跨页、破格、斜格或特殊装帧仍需人工调整并重新签收 |
| 阅读方向 | 从上到下 | 条漫默认从上到下；页漫可选从左到右或从右到左 |
| 目标平台 | 通用 | 只作尺寸和分段建议，不写死平台；导出/审查阶段经 comic 自有 platform profile 校验已知一手规格 |
| 页面尺寸 | 竖向 1440 宽 | 仅为默认画布；可按平台修改 |
| 单话分段高度 | 0 | 导出长图时的默认最大分段高度；0 表示单张长图不分段 |
| 传统原稿流程 | 启用 | `启用` / `关闭`；所有漫画形态都必须走 `comic-name` 的缩略分镜/name board 层，用于确认页流、阅读顺序和气泡占位；关闭只跳过 `comic-finishing` 的墨线/网点/效果线收尾 |
| 出图稿层 | 完成稿 | `完成稿` / `草稿/name` / `铅笔稿` / `清线稿` / `墨线+黑场` / `网点完成稿` / `彩色完成稿` / `自定义(...)` |
| 原稿规格 | 数字条漫 | `数字条漫` / `数字页漫` / `B5商漫` / `A4投稿` / `四格原稿` / `自定义(...)`；影响 trim/safe_area/bleed |
| 版式模板策略 | 自动缩略分镜 | `自动缩略分镜` / `手工缩略分镜` / `模板库` / `关闭` / `自定义(...)`；旧项目的日文值会由 settings 适配层归一为中文值 |
| 审阅策略 | 逐阶段用户确认 | `逐阶段用户确认` / `用户授权制作代理` / `自定义(...)`；代理只代行常规可逆创作审阅，不得跳过确定性阻断、预算扩大、合规/权利、外部发布、不可逆操作或核心方向变更 |
| 网点策略 | 风格驱动 | `风格驱动` / `显式tone_plan` / `灰阶替代` / `关闭` / `自定义(...)` |
| 效果线策略 | 剧情驱动 | `剧情驱动` / `显式effects_plan` / `轻量` / `关闭` / `自定义(...)` |
| 基础视觉风格 | 彩色国漫条漫 | 风格词进入 style guide，不直接绑定模型；候选见 `视觉风格候选.md` |
| 风格锚 | 未指定 | 可填 `STYLE_...` 或一组参考图；用于把整部漫画锁定到用户认可的画风，不把截图 UI 当风格 |
| 生图模型 | GPT Image 2 | 指向具体生成模型；不把渠道或 agent 当模型 |
| 生图渠道 | Codex CLI | 访问入口或执行方式；可显式切换内置 imagegen 或 Dreamina/即梦官方 CLI；即梦 `image2image` 的 1–10 图能力以本机 CLI `--help` 实时核验，检测不到可自动落 PNG 的入口时降级 manual |
| 生图分辨率策略 | 后端最高可达 | 默认请求当前模型/渠道可实际返回的最高原生分辨率；保留原始 master，排版只从 master 向下采样，禁止放大低分图冒充高清 |
| 参考一致性策略 | 共享参考图 | 共享参考图 / 主体库 / LoRA / 手工校对 / 高一致性共享参考图+多视图+形态继承。**主体库/LoRA 本线暂无执行实现**：选中后按共享参考图口径降级执行，gate 记 `consistency_strategy_unimplemented` warn；坚持 LoRA 需在本线外训练，把产出图登记为 registry 参考后照常走共享参考流程 |
| 定妆级别 | 长线专门定妆 | `长线专门定妆` / `长线专门定妆+高一致性` / `短 demo 锚点` / `锚点过渡` / `手工校对`；默认按长线连载补专门定妆和多视图 |
| 年龄形态继承 | 开启 | 开启后，少年/成年/受伤/觉醒/换装等形态必须继承同一角色 DNA；定型图优先级最高 |
| 角色一致性硬闸 | 开启 | 开启后，缺风格锚、角色 DNA、多视图或形态继承策略会阻断审查 |
| 文字语言 | 中文 | `中文` / `英文` / `中上英下` / `英上中下` / `自定义语言(...)`；控制后期嵌字和导出语言，不让出图 prompt 烘焙正文 |
| 嵌字方式 | 后期嵌字 | 推荐后期嵌字，避免图像里烘焙中文正文 |
| 导出格式 | webp+png | 发布分段用 webp，归档或透明素材用 png |
| 发行地区 | 未指定 | 涉及版权、字体、平台规范时补齐 |
| 合规用途 | demo学习 | `demo学习` / `自用草稿` / `发布候选` / `商用` / `授权交付`；demo 学习用途不触发发布前字体/素材授权 gate，发布、商用、授权素材使用前必须复核 |

已内置机检 profile：

- `Tapas`：按 2026-07-14 官方帮助页记录 940px 页面宽、PNG/JPG/GIF、单文件 10MB，以及 300x300 缩略图/2MB。
- `WEBTOON`：官方帮助页可访问但当前抓取页未暴露上传尺寸；发布/商用前按未核验 profile 阻断，需在 Creator Dashboard 或官方文档核验后更新。
- `快看漫画投稿`：官方投稿页口径为宽 1280px、PNG/JPG、RGB、首话成稿不少于 20 格；20 格仅是该投稿 profile 的收稿门槛，不是通用分话规则。
- `MANGA Plus Creators`：官方帮助页记录 PNG/JPG、单文件 5MB、最多 100 页；“超过 8 页”只是建议，机检始终为 WARN。

## 基础视觉风格候选

常用预设由 `skills/comic/_lib/settings.py` 校验，完整说明见 `references/视觉风格候选.md`。当前内置候选覆盖：

- 条漫/平台向：`彩色国漫条漫`、`韩漫清透条漫`、`韩漫恋爱柔光`、`韩漫奇幻厚涂`。
- 页漫/日漫向：`黑白页漫`、`黑白日漫页漫`、`日漫赛璐璐`、`日漫网点热血`、`少女漫画清透`、`青年漫画写实`。
- 美漫/欧漫向：`美漫硬线`、`美漫硬线超级英雄`、`美漫复古半调`、`美漫暗黑写实`、`欧漫清线`、`欧漫绘本水彩`、`法式写实冒险`。
- 国风/题材渲染：`国风厚涂条漫`、`新国风水墨彩漫`、`水墨国风`、`写实电影感`、`黑色电影高反差`、`赛博朋克霓虹`、`蒸汽朋克复古`、`暗黑怪谈厚涂`。
- 轻量/前期：`Q版轻喜`、`Q版四格轻喜`、`儿童绘本漫画`、`扁平矢量漫画`、`水彩治愈`、`像素漫画`、`铅笔草稿分镜`、`灰稿分镜`、`自定义`。

允许参数化补充，例如 `基础视觉风格: 欧漫清线(侦探, 低饱和, 1930年代城市)`；不要写具体在世画师、具体 IP 或“某作品同款”。

## 传统漫画工艺选择

`传统原稿流程=启用` 时，默认新增两层：

- `comic-name`：在正式 layout 前生成 `name_board.json`，记录页流、左右页、翻页钩子、格子轻重、气泡优先方向、原稿 `trim_box/safe_area/inner_frame`。
- `comic-finishing`：在出图包前生成 `finishing_plan.json`，记录每格 `ink_plan`、`black_fill_plan`、`tone_plan`、`value_plan`、`effects_plan` 和 `lettering_sfx_plan`。

这些字段服务传统漫画审美：缩略分镜先解决读者视线路径，墨线/黑场先解决黑白灰价值，网点/效果线再解决材质、情绪、速度和冲击。它们默认是工作流 warn/info，不替代角色脸、眼神、场景轴线等一致性硬闸；如果项目明确要投稿或商用，可以把这些缺口作为人工或用户授权制作代理签收项处理。
