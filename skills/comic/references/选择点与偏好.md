# comic 选择点与偏好

选择点首次询问并写入项目 `_设置.md`；同一项目之后沉默沿用。合规、不可逆、付费或覆盖已有导出的动作每次重新确认。

| 选择点 | 推荐默认 | 说明 |
|---|---|---|
| 输入模式 | 原创漫画 | `原创漫画` / `源本改漫画` / `脚本改漫画` |
| 漫画形态 | 条漫 | `条漫` / `页漫` / `四格` / `分镜稿` |
| 阅读方向 | 从上到下 | 条漫默认从上到下；页漫可选从左到右或从右到左 |
| 目标平台 | 通用 | 只作尺寸和分段建议，不写死平台 |
| 页面尺寸 | 竖向 1440 宽 | 仅为默认画布；可按平台修改 |
| 单话分段高度 | 12000 | 导出长图时的默认最大分段高度 |
| 基础视觉风格 | 彩色国漫条漫 | 风格词进入 style guide，不直接绑定模型 |
| 生图模型 | OpenAI image_generation（Codex 内置） | 指向具体模型/能力；不把渠道或 agent 当模型 |
| 生图渠道 | Codex CLI | 访问入口或执行方式；检测不到可自动落 PNG 的入口时降级 manual |
| 参考一致性策略 | 共享参考图 | 共享参考图 / 主体库 / LoRA / 手工校对 |
| 嵌字方式 | 后期嵌字 | 推荐后期嵌字，避免图像里烘焙中文正文 |
| 导出格式 | webp+png | 发布分段用 webp，归档或透明素材用 png |
| 发行地区 | 未指定 | 涉及版权、字体、平台规范时补齐 |
| 合规用途 | 自用草稿 | 发布、商用、授权素材使用前必须复核 |

`_设置.md` 建议格式：

```markdown
# 设置 — 画漫画《作品名》

## 选择点
- 输入模式: 原创漫画
- 漫画形态: 条漫
- 阅读方向: 从上到下
- 目标平台: 通用
- 页面尺寸: 1440xauto
- 单话分段高度: 12000
- 基础视觉风格: 彩色国漫条漫
- 生图模型: OpenAI image_generation（Codex 内置）
- 生图渠道: Codex CLI
- 生图AI: Codex
- 参考一致性策略: 共享参考图
- 嵌字方式: 后期嵌字
- 导出格式: webp+png
- 发行地区: 未指定
- 合规用途: 自用草稿
```
