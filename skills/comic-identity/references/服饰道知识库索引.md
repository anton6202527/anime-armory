# 服饰道知识库索引

用于漫画的服装、饰品与道具（简称“服饰道”）研究、设计和连续性管理。这里保存方法与权威入口，不把某一朝代的一套造型写死成所有项目的答案。

## 默认路线

除非用户明确指定，按作品先判型，再采用对应推荐：

1. `historical_traceable`（有明确历史时空）：时代/政权与地域 → 身份/品秩/职业 → 礼仪或劳动场合 → 季节气候 → 剧情状态 → 拍摄/生成版本。禁止跨朝代拼贴；资料不足时保守留白并登记不确定性。
2. `historical_inspired`（历史启发）：保留该时代的轮廓、层次、领襟、束系、材料和等级语法；改造项必须明确标为设计许可，不能伪称复原。
3. `contemporary`：年份/地区 → 组织与职业规范 → 场合 → 品牌与预算边界 → 角色生活状态；涉及制服、防护装备、宗教或族群服饰时优先查主管机构或社群一手规范。
4. `fictional`（奇幻、科幻、架空）：先锁世界的技术、材料、气候、经济、制度、职业、行动方式和安全约束，再设计轮廓、层次、开合、材料与磨损。奇幻也不允许无因果地漂移。
5. `hybrid`：分别标出史实层和架空层，逐项记录哪部分有证据、哪部分是设计许可。

用户明确指定可覆盖默认推荐，但必须记录 `scope / reason / requested_by / time / facts_overridden`；局部覆盖不得静默变成全项目规则。

## 证据等级

同一结论尽量取得两类独立证据：

| 级别 | 来源 | 默认用途 |
|---|---|---|
| A | 出土实物、考古报告、博物馆藏品记录 | 结构、材料、工艺、尺度、组合关系 |
| B | 同时代绘画、雕塑、壁画、俑 | 穿着方式、阶层场景、动作与整体轮廓 |
| C | 同时代制度、礼仪、法令、工艺文献 | 品秩、禁限、名称与使用场合 |
| D | 博物馆/高校研究、同行评议成果 | 解释争议、补足残缺证据 |
| E | 有正式美术团队的影视/舞台作品 | 戏剧功能、批量生产和观众可读性；不作史实证明 |
| F | 商业复原、博客、社媒、生成图 | 只作检索线索，不能单独定案 |

后世保存物只能作结构旁证，不能自动证明早期同样如此。服装史术语存在争议时同时保存原称、现代描述与置信度。影视剧照和演员造型不得作为生成附件或直接复刻，除非权利边界另有明确授权。

## 服装合同字段

- 身份条件：时代、政权/地域、身份/品秩/职业、场合/活动、季节气候、故事时间。
- 形制：内外层次、整体轮廓、领口/领襟、开合与交叠方向、袖、衣长/下摆、腰带、冠帽、鞋履。
- 材料：纤维/织物、厚薄垂感、染色与色域、纹样、装饰、金属/皮革件；禁止把“宋代简朴”等概括偷换成人人同色同料。
- 角色识别：永久身份佩饰、可拆服饰、临时剧情道具必须分开；标明佩戴锚点、左右侧、固定方式和何时摘除。
- 状态：`clean / travel / wet / dusty / bloodied / damaged / repaired` 等只在剧情触发后变化，记录首次出现格、持续范围和复位点。
- 版本：`hero / stunt / background / duplicate`；漫画/生成项目仍用该概念区分主特写、高动作、背景简化和备用一致版本。
- 禁止项与不确定项必须显式登记；不确定不等于可自由发挥。

## 道具合同字段

- `prop_id`、名称、戏剧功能、所有权/保管位置、时代地域。
- 尺寸与人物比例、结构/材料/工艺、可动件、重心、握持手与交互动作。
- 题字/纹章使用后期嵌字或已核验文本；禁止生成随机可读字。
- 状态版本、损坏/消耗/复位、首次出现与跨格连续性。
- `hero / stunt / background / duplicate`：特写件、高动作安全件、背景简化件、备份件。好看但不能按剧情可靠工作或无法复制的道具不合格。
- 危险物、武器、火、食品、药物等必须另过安全与合规闸门；视觉史实不能覆盖现实安全。

## 连续性与验收

1. 剧本拆解形成“角色 × 场次/格 × 服装/道具 × 状态”的连续性表；每次变化必须有剧情触发。
2. 定妆/锚点先通过人审，再进入批量生产。全身多视图检查层次、领襟、腰线、佩饰位置和鞋履；道具锚检查比例、结构、握持与可动逻辑。
3. 每格输出记录实际消费的 `outfit_id / prop_id / state_id` 和参考图 SHA。后改合同会使旧图进入重审，不自动宣判重抽。
4. 连续性记录应含图片与文字；服装变化、污损、修补和道具摆位/手侧须逐场更新。

落地时不得只把契约存在 JSON 里：`identity.py views` 必须把 `default_binding.outfit_id` 对应的 `wardrobe_standard` 编译进角色提示，生成/采纳 front 后自动登记为该套服装的真实参考。非默认换装用 `identity.py outfits --bindings CHAR_ID=OUTFIT_ID` 基于已采纳 front 生成专门全身服装锚；不得用官装 front 冒充山行素衣、便服或战损版。

## 权威入口（动态索引，执行时核验页面现状）

### 中国历史服饰与物质文化

- 中国国家博物馆，[中国古代服饰文化展](https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/)：跨时代服饰框架、实物与图像入口。
- 中国国家博物馆，[服饰研究论坛](https://www2.chnmuseum.cn/yj/yjxshjl/hy/fsyjlt/fslt2022/)：实物、文献、图像交叉研究及品秩/场合案例。
- 中国丝绸博物馆，[“打开八百年前的南宋衣橱”赵伯澐墓](https://www.chinasilkmuseum.com/jz/info_15.aspx?itemid=27809)：成套衣物、鞋袜和配饰及原始层次关系。用于宋代结构旁证时须注明南宋墓葬，不直接等同北宋。
- 中国丝绸博物馆，[“丝路霓裳”展品入口](https://www.chinasilkmuseum.com/yz/info_18.aspx?itemid=26598)：织物、纹样和墓葬服饰实例。
- 故宫博物院，[织绣藏品分类](https://www.dpm.org.cn/collection/embroiders/p/15.html)：服装、冠帽、鞋袜、佩饰和织物分类入口；具体断代以单件记录为准。
- 故宫博物院，[《清明上河图》](https://www.dpm.org.cn/collection/paint/228226.html)：北宋城市职业、阶层、动作和穿着场景图像证据。
- 故宫博物院，[幞头](https://www.dpm.org.cn/lemmas/240564.html)：宋代以后展脚、弓脚、卷脚、交脚等形制语法入口；角色设计仍需固定自己的脚长、角度和冠体高度。
- 道音文化，[略论道教服饰的几点意义](https://www.daoisms.com.cn/2017/12/17/8141/)：宋代道士按场合区分法衣、褐帔、常服道袍与大衫的文献线索；它属文献解读入口，须与同时代图像/材料证据交叉，不直接照搬现代道装。

### 影视生产标准

- ScreenSkills，[Standby costume assistant skills](https://www.screenskills.com/skills-checklists/scripted-film-and-tv/costume-department/standby-costume-assistant-skills/)：剧本拆解、时间线、复数量、动作替身、逐次换装和连续性记录。
- ScreenSkills，[Crowd costume supervisor skills](https://www.screenskills.com/skills-checklists/scripted-film-and-tv/costume-department/crowd-costume-supervisor-skills/)：群演服装规模、倍数、做旧和连续性计划。
- ScreenSkills，[Prop master](https://www.screenskills.com/job-profiles/roles/prop-master/) 与 [Standby Props checklist](https://www.screenskills.com/media/dscog2ax/standby-props-skills-checklist.pdf)：道具剧本拆解、历史研究、摆位复位、状态和连续性。
- Costume Designers Guild，[What Is Costume Design?](https://costumedesignersguild.com/what-is-costume-design/)：服装从角色与剧本出发，并为连续性、替身和做旧制作复数版本。
- Property Masters Guild，[What exactly is a prop?](https://www.propertymastersguild.org/post/what-exactly-is-a-prop-anyway)：功能、可预测性、复制与跨部门协作。
