# LabuTV

LabuTV 是 `anime-armory` 的 VS Code 制作面板，用来把作品按固定目录组织起来，并配合 AI agent 按 workflow skills 生产小说、漫剧和漫画。`anime-armory` 保留为仓库名和扩展内部 ID；n2d 这条漫剧生产线统一称为“制漫剧”。

扩展只内置三条创作线的 workflow skills：`novel`、`n2d`、`comic` 及其子 skills。种子 `创作区/` 只预置 `写小说`、`制漫剧`、`画漫画`；其中仅 `写小说/那妖魔是姜大人/` 带一份源小说 demo，漫剧和漫画目录只保留使用手册与新项目入口。

默认执行口径是“推进到下一个真实责任边界”：普通、可逆选择采用本线推荐值并写入 `_设置.md`，制作代理在同一任务完成常规 review/QC 与可逆返修，已有阶段预算包内不逐调用重复询问。逐图机器 QC 与实际像素检查不可跳过；作品已有明确 executor-visual 授权时可用 `human_signoff=false` 的 hash-bound 收据接力可逆中间生产，否则停给具名真人。阶段预算包创建/扩大/过期、不可推断的关键输入、权利合规、不可逆发布/覆盖和最终成品验收仍显式暂停，最终/发布验收始终不能代理。业务前沿只认 `_进度.md`，同一权威对象只认 canonical SHA-256，最终完成只认本线 release/completion verdict；终端命令成功或 provider `succeeded` 不是成品完成。

> ⚠️ 自带工作根位于已安装的扩展目录内，**升级或重装扩展会被覆盖**。要长期保存自己的作品，请把创作区切到你自己的目录（见下文「选择作品目录」）。

完整源码、skill 细节和脚本实现见 GitHub：
https://github.com/anton6202527/anime-armory

## 快速开始

1. 点开左侧 LabuTV 图标——面板会自动开一个终端，定位到当前创作区。
2. （推荐）用 `File → Open Folder` 打开你自己的项目根，或执行命令 `LabuTV: 选择仓库目录` 指定创作区——这样产物保存在你自己的目录里，且面板实时刷新最稳。
3. 在 `创作区/<系列>` 目录下新建作品文件夹，或直接打开内置 demo。
4. 在终端里让本地 AI agent 读取作品目录和 `_进度.md`，按当前阶段继续生产。

目录结构：

    your-workspace/
    └── 创作区/
        ├── 写小说/
        │   └── 那妖魔是姜大人/
        │       └── 从变身少女开始斩妖除魔.txt
        ├── 制漫剧/
        │   └── 使用手册.md
        └── 画漫画/
            └── 使用手册.md

每个作品目录建议保留：

    _进度.md    当前阶段、已完成产物、下一步
    _设置.md    平台、模型、分辨率、音色等选择

## 工作流

### 制漫剧

把小说改成 AI 漫剧短视频。推荐配音先行，用真实音频时长倒推分镜，减少音画错位。

    小说 -> 拆集 -> 台词 -> 配音 -> 分镜 -> 出图 -> 出视频 -> 合成

### 写小说

从主题/设定出发创作或改写一部小说：立意、风格、人物与世界观、成稿、润色与质检。

    创意 -> 设定/人物 -> 成稿 -> 润色/改写 -> 质检 -> 本地化/推广

### 画漫画

从原创梗概、小说源本或现成脚本出发，拆成漫画分格、页面排版、出图包、嵌字与长图导出。

    创意/源本 -> 分话 -> 格脚本 -> 页面排版 -> 出图 -> 嵌字 -> 长图导出

## 批量生产

可同时维护多个作品目录。把每个作品状态写清楚，让 agent 按 `_进度.md` 逐个推进：

    阅读 创作区/写小说/那妖魔是姜大人/从变身少女开始斩妖除魔.txt，分析改编方向。
    批量检查 创作区/制漫剧/ 下所有项目，列出每个项目下一步。

## 选择作品目录

创作区按以下优先级解析：

1. 经 `LabuTV: 选择仓库目录` 指定的外部作品根（会自动开启 `Use External Works`）；
2. 否则用扩展自带的种子工作根；
3. 否则用当前打开的工作区。

无论创作区在哪，面板开的终端都会 cd 到同一个根，产物始终落在该根的 `创作区/<系列>/` 下——和自带样例同一层级、同一套 `_进度.md` / `_设置.md` 约定。

**实时刷新**：面板会同时监听「当前工作区」和「解析出的创作区」两处，新文件通常在约 300ms 内自动出现——既覆盖你 `Open Folder` 打开的工作区，也覆盖工作区之外的自带根 / 外部根。若偶尔没刷出来，点面板顶部的「刷新」按钮即可。

## 面板说明

- 作品线目录置顶显示，读取当前创作区。
- `README.md` 和各系列 `使用手册.md` 显示在面板根层级，作为使用说明入口。
- 首次打开面板会自动开一个终端，定位到当前创作区目录。
- 在 `创作区/制漫剧/<作品名>` 上可右键打开 `生产看板`、`本集工作台`，或刷新按集数据。输出落在作品自己的 `生产数据/`：`board.html`、`episode_index.json`、`episodes/第N集.json`、`episode_app_第N集.html`。
- 文件树按 VS Code 风格懒加载：只在展开目录时读取；大目录默认先显示 500 项，点 `加载更多...` 继续展开；自动刷新只监听作品线顶层和已展开目录的浅层变化，适合含大量图片、视频和 JSON 的项目。
- `Skills` 文件树默认隐藏；调试时在设置里搜索 `LabuTV` 或 `anime-armory` 打开 `Show Skills`。
