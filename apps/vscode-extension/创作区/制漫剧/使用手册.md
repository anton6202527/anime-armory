# 制漫剧使用手册

入口 skill：`n2d`。产物放在 `创作区/制漫剧/<剧名>/`。适合把小说、源书或故事项目改成 AI 漫剧/短剧：剧本改编、配音/时长、分镜、出图、图生视频、合成和验收。

## 默认连续执行

普通、可逆选择缺失时由 producer 推荐器采用题材与规模感知默认值并写入 `_设置.md`；确定性前置、specialist 创作审阅、已有阶段预算包内的付费任务和可恢复返修在同一任务连续推进。预算包只在创建、扩大、过期或绑定合同变化时重新确认；provider 状态不明时先查询/结算，不换 attempt id 盲重放。

权利与真人声音/肖像授权、每张最终保留图片的当前像素具名验收、不可逆发布/覆盖和最终母版验收仍是硬边界。自动 runner、dashboard `done` 或 provider `succeeded` 都不能代签；最终是否完成只看当前 release verdict 与绑定当前母版 SHA 的验收收据。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 小说转漫剧 | “把这本小说改成 AI 漫剧，先做前 3 集 demo。” |
| 继续某集 | “继续 `创作区/制漫剧/<项目名>` 第3集，先查 gate。” |
| 只做前期 | “先不花钱，完成源理解、开发包、剧本和分镜。” |
| 出图 | “第 1 集素材齐了，进入 n2d-image 前先查 image gate。” |
| 出视频 | “第 3 集视频前置通过后，准备 video prompt 和模型路由。” |
| 验收 | “审第 1 集成片，重点查脸漂、接缝、字幕和发布债务。” |

## 推荐流程

1. 源理解：确认现代白话理解、爽点承诺、人物动机、伏笔和改编边界。
2. 开发包：系列 bible、改编策略、前几集追更弧、试播绿灯。
3. 阶段1：剧本改编，产 voiceover、角色/场景/style、BGM、封面。
4. 配音/时长：按制作模式决定真实配音、占位时长或原生音画。
5. 阶段2：导演排戏包 + 分镜设计，产 storyboard、素材清单、字幕。
6. 出图：先过 image gate，再出共享定妆和逐镜 PNG。
7. 出视频：模型路由、图生视频、接缝和身份继承 QC。
8. 交付尾段：合成、review、score、review-ui、release verdict；最终成片验收后才算完成。

## 开始项目

VS Code 轻量种子不预置漫剧 demo；这是独立于 Electron catalog 的打包例外。Electron 的制漫剧系列最多展示一个官方 Demo，并优先使用《那妖魔是姜大人》。在本扩展中可以用内置小说作为源书，在 `创作区/制漫剧/` 下创建新项目：

可试：

```text
把 创作区/写小说/那妖魔是姜大人/从变身少女开始斩妖除魔.txt 改成 AI 漫剧，先创建项目并完成前 3 集开发方案。
```

## 避坑

- 新项目默认自动采用 `混合自动路由`；只有用户明确要求逐项询问或固定兼容模式时，才在开局展示配音先行、原生音画、先出视频后配音等选择。
- 默认不在开局固定生视频后端，出视频前由 router/probe 决定。
- 占位配音只适合 demo 时长脚手架，正式出视频前要换真实配音并重定时。
- 脸漂、接缝、道具漂移要回源头镜头改，不要直接剪最终 MP4。
