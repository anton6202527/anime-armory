# 画漫画使用手册

入口 skill：`comic`。产物放在 `创作区/画漫画/<作品名>/`。适合原创漫画、源本改漫画、脚本改漫画、条漫/页漫排版、出图、嵌字、导出和审查。

## 默认连续执行

输入模式、版式、页面尺寸等普通可逆项缺失时采用推荐值并写入 `_设置.md`。在已授权阶段预算包内，制作代理可连续完成脚本、排版、任务包、`comic-review` 和可逆返修；Demo gate 是质量阶段，通过后按已给范围继续，不另等一次普通审查确认。进入实际出图后仍遵守单张边界：生成、机器 QC、查看当前像素并具名签收后，才生成下一张；不把候选菜单或重复费用确认夹在其中。

只有以下真实硬边界暂停：预算包创建/扩大/过期；改编权、字体或素材授权不明；每张最终保留图片的当前像素具名人审；不可逆发布/覆盖；最终页面图或长图验收。机器 QC 和同任务审阅不得代签真人回执。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 从点子开始 | “做一部条漫，主角是县衙女捕快，先建项目。” |
| 源本改漫画 | “把这篇小说前两章改成条漫。” |
| 继续项目 | “继续 `创作区/画漫画/<项目名>`，看第2话状态。” |
| 做排版 | “第1话脚本好了，生成条漫 layout 和气泡槽位。” |
| 出图 | “根据 panel_script 生成第1话出图包。” |
| 嵌字导出 | “把第2话嵌字并导出长图。” |
| 审查 | “检查第2话阅读顺序、文字遮挡、角色一致性。” |

## 推荐流程

1. 选择输入模式：原创漫画、源本改漫画、脚本改漫画。
2. 漫画脚本：分话大纲、panel_script、角色/场景/道具设定。
3. 页面排版：layout、阅读顺序、格子坐标、气泡占位。
4. 一致性资产：角色定妆、多视图、禁漂移项。
5. 出图：逐格 prompt/job 包；预算包内不逐次确认费用，但每张图仍在 post-QC 后按当前像素 SHA 具名验收，才能进入下一张。
6. 嵌字：用 lettering.json 后期绘制文字，不把正文烘焙进图里。
7. 导出/审查：页面图、长图、export_manifest、comic-review；当前像素人审和最终成品验收仍显式执行。

## 开始项目

扩展不预置漫画 demo。可以用内置小说作为源本，在 `创作区/画漫画/` 下创建新项目：

可试：

```text
把 创作区/写小说/那妖魔是姜大人/从变身少女开始斩妖除魔.txt 改成条漫，先创建项目并设计第一话。
```

## 避坑

- 漫画最小单位是 panel/格，不是视频 clip。
- 台词、旁白、拟声词优先后期嵌字，方便改文和审遮挡。
- 长线角色进入批量生产前要补专门定妆和多视图。
- 发布前再复核字体、素材授权、平台尺寸和切图规则。
