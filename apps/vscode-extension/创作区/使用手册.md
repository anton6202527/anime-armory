# 创作区使用手册

本 VS Code 轻量扩展只预置三条生产线；完整仓库和 Electron 产品另有 song / mv / ad，但不打进这个 VSIX。用户不需要背命令，直接说明目标、作品名、已有素材和约束即可；AI agent 会读取对应作品目录后继续推进。

| 想做 | 目录 | 入口 skill | 示例项目 |
|---|---|---|---|
| 写小说、改稿、审稿、评分、导出 | `写小说/` | `novel` | `写小说/那妖魔是姜大人` |
| 小说改 AI 漫剧/短剧 | `制漫剧/` | `n2d` | 新建项目 |
| 画条漫/页漫/漫画长图 | `画漫画/` | `comic` | 新建项目 |

## 通用规则

- 继续旧项目：先说“继续 `创作区/.../<项目名>`”，agent 会先读 `_进度.md`。
- 新建项目：说清楚“我要写/做/拍什么”，agent 会建作品根并初始化 `_设置.md`。
- 普通、可逆选择缺失时采用推荐值并落入 `_设置.md`；已明确授权的阶段预算包内，出图、出视频、云端作曲和机器检查可连续执行，不逐项暂停。逐图机器 QC 与实际像素检查始终不可跳；n2d 项目已明确授权 executor visual 时，可用 `human_signoff=false` 的当前 SHA 收据接力可逆中间生产，comic 等未实现该合同的线仍按本线逐图具名验收。预算包创建/扩大/过期、权利合规、不可逆发布/覆盖和最终成品验收需要显式确认，最终/发布回执不得由 agent 代签。
- 制作代理默认在同一任务内继续执行 review、score、QC、挑版和可逆返修，不要求用户另开一次“请审阅”。机器审阅是生产证据，不替代具名真人验收。
- Demo gate 是质量阶段，不是默认用户停点；指标通过就继续，未通过先在重试与预算上限内返修。只有继续会触及上面的真实硬边界，或在上限内仍无法达标时才暂停。
- 只查状态：说“看进度 / 下一步”，会走对应 `*-progress`，不改文件。
- 返工：不要直接改最终成片或导出物，优先回源头阶段改，再重跑下游。

## Demo 快速试用

```text
阅读 创作区/写小说/那妖魔是姜大人/从变身少女开始斩妖除魔.txt，概括故事并给出续写建议。
把这本 demo 小说改成 AI 漫剧，先在 创作区/制漫剧/ 下创建项目并完成前期方案。
把这本 demo 小说改成条漫，先在 创作区/画漫画/ 下创建项目并设计第一话。
```

各系列的更具体用法见对应目录下的 `使用手册.md`。
