# 作品卡片：封面与简介契约（cover / synopsis）

> 跨六条线的**产物字段契约**，单一真值源。桌面应用「作品列表区」的卡片要展示**封面缩略图 + 一段简介**，数据来自每个作品根目录的 `_meta.json`。
> 本文件是 docs 层的跨线约定（与 `docs/skill-design-principles.md` 同级，允许覆盖全部六线）；**具体写入由各线在自己的立项/生产流程内独立完成**，不建跨线共享 helper（遵 A1 独立性）。

## 1. 字段

在作品根 `_meta.json` 增加两个可选字段（不破坏既有字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `synopsis` | string | 一句话 / 一段作品简介，≤ 240 字。卡片里超出两行省略。来源见 §3。 |
| `cover` | string \| null | 作品级封面图，**相对作品根目录**的路径（如 `出图/封面/cover.png`），指向一张**竖版**（约 9:16 / 5:7）PNG。无封面时为 `null` 或省略。 |

桌面侧读取规则（已实现，`apps/desktop`）：`cover` 解析成绝对路径、限定在作品目录内且文件须存在，否则视为无封面；`synopsis` 裁剪限长。无封面 → 卡片回退产线图标占位；无简介 → 回退「有进度 / 仅初始」文案。

## 2. 封面策略（按线）

| 线 | 有无图片产物 | 封面来源 |
|----|------|----------|
| n2d（制漫剧） | 有 | 专门出一张竖版封面（复用已有 `脚本/第N集/封面.md` 封面策略 + identity registry 同源锚，遵 B7/B9） |
| comic（画漫画） | 有 | 专门出一张竖版封面（风格锚 + 角色定妆同源） |
| ad（拍广告） | 有 | 专门出一张竖版 key visual / endcard 作封面 |
| mv（制MV） | 有 | 专门出一张竖版 key visual 作封面 |
| song（写歌） | **无图** | `cover=null`，卡片用产线图标占位；只填 `synopsis` |
| novel（写小说） | **无图** | `cover=null`，卡片用产线图标占位；只填 `synopsis` |

## 4. 铁律约束（务必遵守）

- **A1 独立性**：各线只在自己 `skills/<line>*` 内实现，不 import 别线、不建 `skills/common`、`skills/<line>/**.md` 不提别线名。
- **C4 / B4 优雅降级**：封面出图**不得硬阻断主流程**。纯净机（断网、无重依赖、无付费凭证）上，封面步骤只产出**稳定的封面 prompt / job 包 + 合规留痕**，`cover` 保持 `null`；真正渲染出 PNG 后才回填 `cover` 相对路径。绝不伪装云端自动化。
- **C5 模型指代到具体模型**：封面 prompt / job 包里「由什么生成这张封面」必须落到具体模型名（含版本），渠道 / CLI 作为 access path 分列。
- **B5 进度回写**：封面作为一个生产阶段，完成后按各线确定性脚本回写 `_进度.md`（若纳入进度表）。
- **写入用 `write_if_absent` 语义不覆盖用户内容**：立项阶段只补缺，不 clobber 已有 `_meta.json` 字段。
