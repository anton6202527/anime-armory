# 制MV使用手册

入口 skill：`mv`。产物放在 `创作区/制MV/<曲名>/`。适合给歌曲做音乐视频：视觉蓝图、卡点、分镜、出图、图生视频、卡拉 OK 字幕、合成和审片。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 有成品歌 | “用这首 song.wav 做 MV，走先传音乐路线。” |
| 还没正式歌 | “先给这首歌做 MV 视觉蓝图，后配歌曲。” |
| 查卡点 | “分析 beatgrid，按副歌强卡点拆分镜。” |
| 出图 | “按 reference pack 出 MV 首帧和尾帧。” |
| 出视频 | “登记图生视频 takes，按身份/动作/卡点评分挑版。” |
| 字幕合成 | “生成卡拉 OK 字幕并合成成片。” |
| 审片 | “检查成片卡点、字幕、音轨、参考一致性和正式版 readiness。” |

## 推荐流程

1. 选歌曲输入时序：先传音乐或后配歌曲。
2. 立项：确定用途、风格、画幅、卡点策略、生成后端偏好。
3. 视觉蓝图：主角/主色/场景/段落视觉母题。
4. 卡点：正式歌入库后跑 beatgrid。
5. 分镜：clip_plan、timeline_manifest、semantic prompts。
6. 一致性包：identity_registry、asset_registry、reference_requirements。
7. 出图/出视频：首尾帧、video jobs、挑版、继承合约、video_qc。
8. 字幕/合成：karaoke、歌词烧录、成片。
9. 审片：mv-review + 人判视觉一致性和卡点体感。

## Demo

已有项目：`创作区/制MV/仗剑下山`。

可试：

```text
检查 创作区/制MV/仗剑下山 为什么还是 demo，给我正式版返工顺序。
```

这个 demo 已有 20s 成片、字幕和机检报告；`formal_readiness` 明确标记为 blocked，因为它不是正式整首 MV，且 reference pack 仍未齐。

## 避坑

- 后配歌曲路线不能在最终音频前正式拆 timeline、出图或出视频。
- demo 歌不能直接扩剪成正式 MV；换正式歌后必须重跑 beatgrid 和 mv-plan。
- 文字设定不等于参考图 ready；正式出图前要补多角度 reference pack。
- 成片问题要回源头：卡点回 mv-plan/video，脸漂回 mv-image/video，字幕回 mv-lyric-sync。
