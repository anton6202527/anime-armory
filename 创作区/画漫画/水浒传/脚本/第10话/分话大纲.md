# 第10话《拳打镇关西》

- 读者承诺：鲁提辖如何为一对素不相识、被恶霸虚钱实契逼债的卖唱父女出头，一路从酒楼管到状元桥的肉案前。
- 核心冲突：鲁达要替金氏父女讨一个公道，可他手里只有一个提辖的身份和一双拳头；越是要把事办干净，就越必须走到官法容不下的那一步。
- 转折：郑屠被“十斤精肉、十斤肥肉、十斤寸金软骨”消遣到忍无可忍，抢剔骨尖刀跳下肉案——鲁达等的正是这一刀。
- 兑现：三拳之后镇关西挺在当街没了入的气；鲁达假意骂一句“你诈死”，回下处卷了细软提条齐眉短棒奔出南门。
- 结尾：从经略府提辖变成在逃的杀人犯；追捕将起，留待第11话。
- 规模：48格，8个滚动段（钩子位 P006 / P012 / P018 / P024 / P030 / P036 / P042 / P048）。
