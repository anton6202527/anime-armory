# 故事圣经 — 《水浒传》漫画版

> 状态：可审草案（review）。本文件是长线设定真值，人物定妆、分格与后续改编应继承稳定 ID；未经人工编辑/艺术总监签核前不标记 confirmed。

## 项目定义

- 输入模式：源本改漫画，120回本。
- 漫画形态：1440px 单列竖向条漫，从上到下阅读，后期嵌字。
- 读者体验：说书史诗的气口 + 角色驱动的现代连载节奏 + 可验证的宋代物质细节。
- 风格 ID：`STYLE_SHUIHU_SONG_CINEMATIC`。
- 艺术概括：“宋画电影感国漫”——宋画兼工带写与淡设色作为绘画骨架，写实国漫人物与电影化动机光作为表演和镜头层。

## 一句话核心

一群被失灵秩序逼入江湖的人，以义气建立另一种秩序，却最终要在忠义、自由与生存之间支付代价。

## 主题与叙事不可丢失项

1. **逼上梁山的因果**：每个核心人物的选择必须有具体制度、人际和生存压力，不用“天生反贼”简化。
2. **义气的力量与代价**：义气能救人、聚众，也会形成压力、盲点和等级。
3. **忠义的裂缝**：“忠于朝廷”与“不负兄弟/百姓”不保证一致，矛盾必须可见。
4. **群像而非单一爽文主角**：宋江是长线组织中心，但鲁智深、林冲、武松、李逵、吴用等各有独立价值观与叙事重量。
5. **暴力有后果**：动作清晰但不猎奇；伤残、流离、内疚与关系破裂必须留在后续状态账。

## 人物

### 洪信 CHAR_HONG_XIN

- 功能：神话序章的行动主体和负面引信；他并非纯粹恶人，却把权势、面子和自信当成判断真相的依据。
- 年龄/体态：四十五岁左右，中等偏高，官员体态略厚，非武将肌肉型；上山后狼狈、沾尘，但不能突然变成滑稽丑角。
- 脸/眼/发：长方圆脸，下颌软但不肥肿；眼裂偏窄、眼距正常，情绪从稳拿转为心虚；发际线稍高，戴宋代官员幞头时仍锁定额角与鬓发。
- 衣装：朝堂与出使为绛/深褐系圆领官袍、深色幞头与革带；上山更换素色窄袖布衣、麻履，背黄罗诏包，持银手炉。
- 永久识别：微高发际线、窄眼、右眉尾轻微下压、直而略厚的鼻梁、指节圆润的非劳作手。
- 禁漂移：不使用任何已知影视演员脸；不变为俗套奸臣尖脸、武将壮汉或喜剧化肥官。
- 资产档位：`recurring_standard`，第1–2话须 front / three_quarter / face 三项业界基础定妆视图。

### 虚靖天师 CHAR_MASTER_XUJING

- 功能：超越官僚常识的真知者；以牧童形态试探洪信，不是故弄玄虚的神棍。
- 年龄/体态：外观十二至十四岁，身形清瘦、肩背松弛，倒骑黄牛时重心自然。
- 脸/眼/发：少年圆长脸、明亮偏长眼，两枚丫髻；笑意在眼不在夸张嘴角。
- 衣装/标志物：洗旧青布衣、草编绛带、芒鞋，铁笛；黄牛是本场坐骑，不并入人物身份 DNA。
- 禁漂移：不仙侠游戏化、不白发老神仙化、不出现现代魔法阵/UI光环。
- 资产档位：`recurring_standard`，须 front / three_quarter / face；牧童形态记为 FORM_YOUTH_HERDBOY，与后续真人形态共用脸部 DNA。

### 上清宫住持 CHAR_ABBOT_SHANGQING

- 功能：知晓规矩和后果的守门人，也暴露宗教机构在官权压力前的局限。
- 年龄/体态：六十岁左右，高瘦、背直，三十余年住持的克制与仪法感。
- 脸/眼/发：高额、清瘦颊、灰黑短须，上眼皮略沉但目光稳定。
- 衣装：青灰道袍、深褐缘边、不夸张的冠巾；不用明清影视金绣法衣套路。
- 禁漂移：不设计为阴险反派；不因恐惧而丢失一贯的高瘦轮廓、高额和灰黑须。
- 资产档位：`named_minimal`，至少 front / face。

### 宋仁宗 CHAR_EMPEROR_RENZONG

- 功能：序章中心怀百姓却受限于朝廷手段的统治者；先奉救民，不用平面化昏君脸谱。
- 外形：五十岁出头，宽额、圆长脸、神情疲惫克制；黑色平翼幞头、素红圆领袍，金织物只在领袖内层低调露出。
- 参考真值：服饰层级参照台北故宫《宋仁宗坐像》解读；只作时代与制度参考，生成原创脸。
- 资产档位：`named_minimal`。

### 范仲淹 CHAR_FAN_ZHONGYAN

- 功能：提出迎天师的关键奏请，表现为忧民而果断的参知政事。
- 外形：五十岁左右，瘦长脸、眼下疲色、姿态稳重；深红宋代官袍与平翼幞头，与仁宗的红色用材/层级明显区分。
- 禁漂移：不使用现代名人脸或古装剧演员脸。
- 资产档位：`named_minimal`。

### 赵哲 CHAR_ZHAO_ZHE

- 功能：与文彦博首先请求宽刑薄税与赈济，建立“朝廷并非无人努力，但结果仍失效”。
- 外形：年长宰相，体态端方，发须花白；紫褐官袍，低饱和。
- 资产档位：`named_minimal`。

### 文彦博 CHAR_WEN_YANBO

- 功能：与赵哲同奏瘟疫，作为赵哲的形象对照而不是克隆官员。
- 外形：四十余岁，偏瘦、下颌窄，深绿褐官袍；发须黑，语态稳健。
- 资产档位：`named_minimal`。

## 非人物与生物

### 吊睛白额锦毛大虫 MON_WHITE_TIGER

- 核心形象：真实华南虎体态基础，白额黑纹、近地爆发力强；不作奇幻剑齿兽。
- 叙事功能：试心而非猎杀，围洪信左盘右旋后离开，眼神与动作显示有意节制。
- 资产档位：`recurring_standard`（本话多格连续动作）。

### 雪花大蛇 MON_SNOW_SERPENT

- 核心形象：吊桶粗细的巨蛇，乳白与冷灰鳞片、少量金色眼光；不作西方龙或巨蟒电影怪物。
- 叙事功能：盘于石边逼近、吐气试心，后主动离开；毒气是低饱和冷白气流，不是高饱和魔法绿雾。
- 资产档位：`recurring_standard`。

## 世界观与场景锚

### 紫宸殿 LOC_ZICHEN_HALL

- 空间：中轴深进，御座在后景高台；文武两班分居画面左右，中间丹墀留奏对通道。
- 材质/色彩：朱、墨黑、暗金为权力色，金只用于领袖内层、御诏和御座局部；禁止满画面土豪金。
- 光：殿门方向的冷晨光 + 室内偏暖反射，面部继续可读。

### 嘉祐京师瘟疫街巷 LOC_CAPITAL_PLAGUE_STREET

- 空间：窄巷两侧木门连续关闭，药碗、清水桶与布帘形成民间应对疫病的生活证据；车辙沿纵深通往城门。
- 人物/边界：医者、亲属、送葬者保持距离与遮掩，用空门、空药碗和反应表达代价，不做尸体、病灶或痛苦的猎奇特写。
- 色彩/光：灰褐墙面、药渣黄褐、冷日光与室内极弱暖灯，与紫宸殿的克制朱金形成阶层反差。

### 东京至信州驿路 LOC_ROAD_TO_LONGHUSHAN

- 空间：一组步移景异的竖向旅程：汴京城郊→杨柳驿道→山村野店→信州迎候。
- 色彩：干土褐、柳灰绿、远山青黛；衣马掀起的红尘是转场连接元素。

### 上清宫 LOC_SHANGQING_PALACE

- 空间：山门→三清殿→方丈→左右廊→右廊后伏魔殿；松柏、炼药炉、石阶与山涧为常驻空间记忆。
- 建筑：以北宋木构逻辑、斗拱层级与素洁瓦面为基准，不套用明清宫殿琉璃金龙密集装饰。
- 色彩/光：苍松青、木褐、道袍青灰；山谷散射冷光，殿内香火微暖。

### 龙虎山后山山径 LOC_LONGHUSHAN_PATH

- 空间：丹霞赤壁夹谷、盘坡转径、松树突出点、盘陀石、山凹牧童出场线；五个地标方位连续。
- 地貌：红色砂砾岩峰柱与峡谷、灌丛、飞水组合，参考世界遗产“中国丹霞”对龙虎山的官方描述。
- 色彩/光：石青、石绿、赤褐、雾灰；上山前段日光、猛兽出现时云影压暗，牧童出现时返回柔光，不跳成异色魔幻世界。

### 伏魔殿外 LOC_FUMO_HALL_EXTERIOR

- 空间：上清宫右廊尽头的独立封闭小殿；搗椒红泥墙、朱红格门、铸锁、十数封皮与漆金牌额必须常驻。
- 光：廊下斜向日光照亮封皮，门缝没有奇幻露光，恐惧来自规矩和未知。

### 伏魔殿内 LOC_FUMO_HALL_INTERIOR

- 空间：窄长无窗殿室，入口在画面后方，中心石碑与龟趺大半没泥，四周无其他神像或杂物。
- 光：开门时冷天光形成窄条；入内后只由十数火把提供同一暖光方向；黑气冲出时火光被压暗，金光是唯一高亮。

## 核心道具与特效

- `PROP_IMPERIAL_EDICT`：黄罗包裹的丹诏；文字后期嵌入，生图时不生成随机可读字。
- `PROP_SILVER_CENSER`：有提梁的银手炉，持续燃龙香；上山跌落、拾回的状态必须连续。
- `PROP_FUMO_SEALS`：多代天师叠加的封皮、朱印与铜汁灌铸大锁；擘除顺序须可读。
- `PROP_STONE_STELE`：五六尺石碑、龟趺、正面符箓、背面“遇洪而开”；四字必须后期嵌字，不让模型现场伪字。
- `VFX_108_STARLIGHTS`：一道稠密黑气先上冲，至高点散为百十道暖金光；不画现代星座 UI、数字编号或游戏粒子门。

## 视觉风格合同 STYLE_SHUIHU_SONG_CINEMATIC

### 线、色、光、材质

- 线：人脸与手用细而有压力变化的墨线，建筑/道具线性精确，山石树木兼工带写；禁止均匀塑料勾边。
- 色：低饱和矿物色——土褐、墨青、靛蓝、石绿、朱砂点色、烟金；高饱和金只给御诏、神意和百道星光。
- 光：每场锁定动机光源与冷暖关系；用三值明暗保证手机竖屏可读，不追求摄影级真人皮肤。
- 材质：哑光绢/纸粒理，衣料、木、石、金属分层清楚；不做照片级 3D 皮肤、游戏 CG 甲胄或油亮树脂质感。

### 人物设计总则

- 同族群中通过脸型、眼型、眼距、发际线、身高、肩胯比和劳作痕迹区分人物，禁止“同一韩漫美型脸换发型”。
- 官员、道士、军汉、市井人的衣料、清洁度、体态和手部劳作痕迹必须体现阶层，不只靠颜色。
- 每个常驻/强曝光人物按 library tier 制作标准视图；形态、换装和伤痕通过 form/outfit/state 继承，不另造新脸。

### 竖条构图与节奏

- 将《清明上河图》式“步移景异”转译为竖向滚动：旅程、宫观和人群可连续展开，每个屏幕高度仍有单一焦点。
- 大环境格交代社会和空间；中景格建立轴线与行动；近景/特写只给选择、证据、反应和代价。
- 诗赞不整段堆字：以景别、节奏、环境声和少量 8–14 字旁白转译。

### 硬性禁止

- 不复制 1998/2011 等影视版本的演员脸、剧照构图、光位、标志性服装组合或布景。
- 不将任何影视截图、受限制馆藏图或搜索结果直接附件给生图模型；生图附件只能是项目自有/已授权定妆与原创风格锚。
- 不出现日式战国甲、明清翼善冠/补服、西幻盔甲、仙侠游戏 UI、霓虹高饱和魔法。
- 不在生图内直接生成可读诏书、牌额、碑文或对白；全部交给后期嵌字。

## 连续性账本规则

- 所有角色格必须绑定 character/form/outfit/expression/state；没登记的变体不准临时在 prompt 中发明。
- 常驻道具的持有人、手侧、完整性和位置要跨格传递；特别是第1话的丹诏、银手炉、封皮、石碑。
- 运镜可跨轴只能先用中性轴线格/运动格交代；反应格延续前格的眼线高度与方向。
- 伤痕、泥尘、湿度、破损和衣装切换都记入 state timeline，不可下一格自动复原。
