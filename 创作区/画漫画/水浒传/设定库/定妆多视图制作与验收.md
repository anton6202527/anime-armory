# 定妆多视图制作与验收 — 《水浒传》

> 当前状态：身份 registry 已建立，所有角色均诚实标记 `needs_fix/needs_reference`；未生成图像，未写人工 signoff。需先由用户确认生图模型、渠道、张数、规格和预算。

## 结论：要做，但不对 108 人一刀切

长线漫画的主要角色必须有业界可用的 turnaround/model pack，否则脸、发型轮廓、背面服装、体型和标志物会在长连载中累积漂移。但一百零八人全部五视图会制造巨额成本和审核债，因此使用分档制。

| 档位 | 使用对象 | 必需视图 | 附加包 | 放行条件 |
|---|---|---|---|---|
| `core_full` | 宋江、林冲、鲁智深、武松等长线主角 | front / three_quarter / side / back / face | 至少6表情、主服装正背、标志兵器/伤痕、体高对比 | 技术检查 + 五视图并排人审 + SHA signoff |
| `recurring_standard` | 跨多格/多话或重要变化人物 | front / three_quarter / face | 3表情，出现背面镜头前再补 back | 技术检查 + 三视图并排人审 + SHA signoff |
| `named_minimal` | 短线具名角色 | front / face | 只在剧情需要时补服装/道具 | 两视图人审 + SHA signoff |
| `restricted_partial` | 路人/群演/只出现一次的功能人物 | 无专门视图 | 用阶层群像契约，不建长线身份 | 不得在后续悄然升为主角；升档先补包 |

## 第1话定妆清单

### P0：风格锚（所有人物前置）

- `STYLE_SHUIHU_SONG_CINEMATIC`：1张原创非叙事校准画，用无具体身份人物+衣料/木/石/雾层校验线、色、光、三值明暗、哑光绢纸材质。
- 禁止：不附件任何影视剧照或馆藏图；不生成水浒具名角色；不拼贴、不九宫格、不带字。

## 生成顺序（不批准则不继续）

1. 先生成风格锚候选，只保留人工采纳的1张。
2. 以已采纳风格锚作 `style_only` 附件，生成洪信/虚靖天师 front 选角稿；风格图中人脸、衣服、体态、姿势与构图不得继承。
3. 人工选定 front 后，其它视图以 front 为身份锚派生，不再从文字独立抽卡。
4. 运行 model-pack 技术检查，修复错视角、裁脚、多人、重复图和画布不一致。
5. 给人并排审查；通过后才为当前图像 SHA 写 signoff。任意视图替换后旧 signoff 自动过期。
6. 再做 P2 角色、生物、场景和道具锚；最后才生成逐格面板。

## 技术验收（机器可检）

- 每张是可解码 PNG，记录路径、SHA-256、宽高、source view 和 derivation。
- front / three_quarter / side / back 必须从头顶到鞋底完整入画；face 必须是正面头肩近景。
- back 不可是正脸，side 不可是三分之四；同一图不得复制成不同视角文件。
- 全身视图画布规格一致，头脚安全边距一致；不得有文字、logo、水印、UI、多格或额外人物。
- 运行：

```bash
python3 skills/comic-identity/scripts/model_pack.py "创作区/画漫画/水浒传" check --write --json
```

## 视觉验收（人必须并排看）

- 身份：脸型、眼型/眼距、鼻嘴、发际线、发型轮廓、身高体态与永久标志物在所有视图一致。
- 服装：领型、袖型、腰带高度、主色、材质、花纹、配饰和背面结构连续；不把临时手持物固化为身份。
- 年龄/阶层：各视图年龄不跳变，官员/道士/百姓的面料、清洁度、体态和手部状态符合层级。
- 风格：同一线条压力、低饱和矿物色、三值明暗与哑光绢纸质感；不混入写真皮肤、游戏CG、韩漫脸或影视演员脸。
- 中性：不继承剧情格的打斗姿势、跌倒、左右站位、泥尘、毒气、同框遮挡或剧情光效。
- 签核命令只能由真实审阅者执行：

```bash
python3 skills/comic-identity/scripts/model_pack.py "创作区/画漫画/水浒传" signoff \
  --characters CHAR_HONG_XIN \
  --confirm-all --reviewer "实际审阅者" --reason "洪信三视图并排复核通过" --json

python3 skills/comic-identity/scripts/model_pack.py "创作区/画漫画/水浒传" signoff \
  --characters CHAR_MASTER_XUJING \
  --confirm-all --reviewer "实际审阅者" --reason "虚靖三视图并排复核通过" --json
```
