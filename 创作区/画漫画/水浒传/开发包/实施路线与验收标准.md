# 实施路线与验收标准 — 《水浒传》漫画版

> 本文档是执行清单，不是批准回执。人工签核和付费生成只能在真实发生后落盘，不得为了过 gate 补写虚假 reviewer、时间、SHA 或通过状态。

## 总流程

```text
源本/权利凭证
  → 视觉研究合同
  → 系列开发包 + 分话合同
  → 源语义归一化 + panel_script
  → 编辑签核
  → 原创风格锚
  → 人物 model pack / 场景道具锚
  → 艺术总监 SHA 签核
  → 缩略分镜/name board
  → 页面排版
  → 原稿收尾计划
  → 逐格出图包
  → 批量生成 + 缺陷定向重抽
  → 嵌字/合成
  → 一致性、权利、平台与发布 gate
```

## G5｜缩略分镜/name board、排版与原稿收尾

### 执行

1. 编辑确认 panel script 后运行 `comic-name`，生成缩略分镜与气泡占位。
2. 由人工或用户授权制作代理审阅缩略分镜的顺序、大小格、停顿和文字密度；修正后再生成 layout。
3. 项目开启传统原稿流程，所以 layout 后还要建 ink / black fill / tone / value / effects 收尾计划。

### 验收

- 缩略分镜/name board 与脚本 panel ID 1:1，无丢格/重格；阅读顺序从上到下唯一。
- 对白/旁白/拟声有安全区且不遮脸、手、关键道具和动作命中点；牌额、碑文和诏文坚持后期嵌字。
- P047 百星逃逸是最大竖向格，P048 回到洪信/住持反应并以“苦也”落钩；不将结尾大特效压成普通中格。
- name board/layout/finishing 各自的合同 SHA 连续，上游变更后下游自动 stale，不沿用旧批准。

## G6｜出图包与生成

### 开始前必须具备的执行合同

- 模型与渠道已设置为 GPT Image 2 / Codex CLI；执行前实时核实能力、附件上限与可用性。
- 已有预算、候选数、比例与最大尝试次数授权时，制作代理可在同一范围内自主选版与继续；只有实质扩大预算/付费范围才升级。
- 正式逐格生成前必须先过参考处方和 `image_preflight`，不以“少让用户批准”为由跳过确定性阻断。

### 验收

- 每格生成 job 的角色、场景、道具、风格参考均解析到真实路径与 SHA；缺引用不允许开跑。
- 生成记录含 model/channel/version、prompt SHA、参考 bundle SHA、输出 SHA、尝试次数与结果。
- 重抽只针对失败格；修脸不改场景，修文字不重抽图，修布局不扩散成整话重做。

## G7｜合成、质检与发布

### 验收

- 内容：格数、顺序、对白、旁白、拟声和源语义取舍一致，无漏格/重格/乱字。
- 人物：脸/眼/发/体型/服装/标志物通过本话和跨话一致性检查；眼线目标、手脚归属、道具接触点与状态账一致。
- 场景：空间布局、轴线、主光方向/冷暖、常驻物和道具位置不无因漂移。
- 图像：无多指/少指、断肢、融脸、乱文、水印、现代物件或不属于北宋的明显服建错置。
- 嵌字：简体中文字体授权可追溯，字号/行距/对比达标，气泡尾巴对准说话者，实机缩略图尺寸仍可读。
- 输出：页图、长图、分段图与 `export_manifest.json` 的尺寸、格式、顺序、SHA 一致；目标平台尚未指定时不声称平台验收通过。
- 发布：开发包、定妆、场景/道具、视觉质检、权利与平台回执都绑定当前 SHA；任一上游修改则重审对应最小范围。
