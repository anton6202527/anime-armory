# 故事圣经 — 《那妖魔是姜大人》

## 项目定位
- 输入模式：源本改漫画
- 漫画形态：条漫
- 基础视觉风格：暗黑国风彩色条漫，电影感荒野、血色夕阳、高反差冷暖光，人物脸部稳定。
- 改编原则：保留原作“穿越变身 + 妖魔乱世 + 百妖谱系统 + 为活命跨过道德线”的核心爽点；漫画节奏优先使用强画面、短台词和页末钩子。

## 一句话核心
现代人姜月初穿成大唐妖魔乱世里的罪臣之女，在尸横遍野的荒野醒来，为活下去，被迫用百妖谱夺取妖魔与武者的道行，走上一条以杀止杀的斩妖路。

## 第一话改编范围
- 源本：`源本/从变身少女开始斩妖除魔.txt` 第1章《百妖谱》。
- 截止点：姜月初明白“唯一还活着的生物”是裴长青，低声道歉后刺下那一刀。
- 第2话承接：获得二十年道行，一刀斩虎妖，收录虎山神，获得猛虎快刀。

## 主要角色

### CHAR_JYC — 姜月初
- 身份：现代人穿越成罪臣之女，囚服少女，刚进入妖魔横行的大唐。
- 年龄感：十六至十八岁少女外貌，现代人心理，开局弱小但反应快。
- 视觉锚点：灰白破旧囚服，长发凌乱，脸上有尘土和血点，瘦弱但眼神逐渐冷硬。
- 表演关键词：惊惧、吐槽式警觉、强迫冷静、道德崩塌后的求生狠劲。
- 禁漂移项：不要画成成熟女侠；第一话不能有华丽装备；表情变化从懵、怕、算计到决绝。

### CHAR_PEI — 裴长青
- 身份：陇右镇魔都司队正，押送队幸存者，重伤濒死。
- 年龄感：二十出头，身形高大，镇魔司黑衣赤纹劲装。
- 视觉锚点：黑衣赤纹、断刀、左臂不自然扭曲、浑身血污但仍有威慑。
- 表演关键词：虚弱、强撑、镇压感、最后错愕。
- 禁漂移项：不是反派嘴脸；他是危险但可信的秩序代表，死亡要有悲剧感。

### MON_TIGER — 虎妖 / 虎山神
- 身份：半只脚踏入鸣骨境的大妖，伪死复起。
- 视觉锚点：人身虎头，体魄如小山，胸口巨大血窟窿，妖血乌黑，爪牙厚重。
- 表演关键词：残忍、戏谑、压迫、看猎物般从容。
- 禁漂移项：不要画成普通老虎；必须是人形妖躯，胸口伤洞是第一话识别点。

## 关键场景

### LOC_WILD — 荒野尸场
- 破败荒野、枯草连天、风里有腥气，地上有囚犯尸体和镇魔司黑衣尸体。
- 色彩：灰黄枯草、血黑泥土、冷青风色、夕阳血红。
- 镜头语言：大远景建立绝望，低机位强化虎妖压迫，近景表现姜月初心理崩塌。

## 关键道具 / 系统

### PROP_HENGDAO — 横刀 / 断刀
- 镇魔司制式刀，第一话中先作为威慑，后成为姜月初越线的凶器。
- 出图时刀不必夸张发光，强调金属冷光和血污。

### SYS_BAIYAOPU — 百妖谱绘卷
- 古朴绘卷，金色字迹浮现，系统 UI 不要现代赛博化。
- 第一话只展示“宿主、境界、武学、道行”关键信息，文字后期嵌字。

## 视觉规则
- 面板图保持无字或空白气泡，正文台词、系统字和拟声词后期嵌字。
- 第一话的血腥只做叙事必要表现：血迹、血线、衣物染红；避免内脏特写。
- 姜月初脸部连续性优先级最高，其次是裴长青黑衣赤纹、虎妖胸口血洞。
- 台词尽量短，一格只承载一个主要阅读动作。
