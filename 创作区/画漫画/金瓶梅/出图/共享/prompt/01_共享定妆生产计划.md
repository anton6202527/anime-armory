1. 先生成 5 名本话登场人物的 `front / three_quarter / side / back / face` 五视图。因为本项目从古白话源本直接开画，没有已采纳角色图，首张 `front` 需用 `--allow-text-anchor` 从 `story_bible.md` 与 `identity_registry.json` 生成。
2. 再生成虎、场景和道具的 `__anchor.png`。
3. 重新跑 `comic-identity report --write`，把真实参考路径回填到 `panel_jobs.json`。
4. 重新跑 `image_preflight`，通过后再进入正式逐格出图。
