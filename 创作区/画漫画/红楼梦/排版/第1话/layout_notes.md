# 页面排版说明 — 第1话《序章·顽石入梦》

- 制式：B5 数字页漫，2079 × 2953 px，左到右；6 页、24 格。
- 安全区：138 px；内框：189 px；出血：64 px。
- 第1、3、5页末承担翻页问题，第2、4、6页给出回答或更深一层命运信息。
- 自动ネーム只负责格子轻重与页流；本 layout 已人工改为页内多列几何，不能再用单列 `build_layout.py` 覆盖。
- P001/P012/P016/P020/P024 使用无框或弱框，分别承担终局、化玉、还泪、入幻、谶语五个母题节点。
- P018/P019/P023 是多人和手部接触高风险格，出图前必须绑定全部角色多视图并保留气泡安全区。
- 所有 `bubble_slots` 只作排版占位；原画不得画气泡、空白框或正文文字。
