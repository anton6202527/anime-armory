# 故事圣经 — 《红楼梦》漫画版

## 项目承诺

- 输入模式：源本改漫画。
- 形态：B5 数字页漫，左至右阅读，兼顾屏幕阅读与印刷母版。
- 开篇策略：第1话先用“石头入世—木石前盟—甄士隐梦醒”建立全书母题；第2话起进入“黛玉别父进京都/荣国府初见”的人物主线。
- 叙事核心：不是把古典名著画成华服恋爱故事，而是从女性命运、情感真伪、家族秩序和盛衰无常四条线并行推进。
- 改编原则：保留关键诗词、判词、礼仪动作和物质文化；长篇议论压成画面、短旁白或章末附页；不为追求爽点改写人物伦理逻辑。

## 视觉总则

- 基础视觉风格：新国风工笔淡彩页漫；现实层用细劲墨线、低饱和矿物色和克制自然光，幻境层用水墨晕染、飞白、留白和少量朱砂/石青发光。
- 时代口径：小说刻意虚化朝代，因此采用“架空明清综合视觉”。女装以清前期汉族女性服饰的层次与材质为研究底，男装允许古装、戏装和清代细节的文学化综合；不做单一朝代复原宣称。
- 人物策略：同一角色先锁脸、发型轮廓、体态、服装剪影、色彩和标志物，再允许年龄、疾病、受伤、婚嫁、出家等状态继承变化。
- 场景策略：每个核心场景必须有平面关系、正反向视图、主光方向、常驻物件和禁漂移项；园林不是泛化“古风庭院”。
- 文字策略：原画无正文文字、无空白气泡。对白、旁白、诗词与拟声词均进入后期 lettering。
- 禁止：复制任何影视演员面孔、宣传照姿态、现成剧照构图或某一版完整服装组合；禁止泛韩漫脸、页游仙侠光效、现代影楼古装和无依据的满屏金碧。

## 长篇结构

1. 梦起：石头入世、黛玉进府、宝黛钗初会。
2. 园成：大观园与群芳秩序建立，诗社、节令、日常情感渐丰。
3. 裂纹：家族权力、性别秩序和经济压力逐渐显形。
4. 花落：群芳离散、误会与死亡推进，繁华反噬人物。
5. 梦醒：家族倾覆，情与物归于空寂。

## 核心角色 DNA

### CHAR_JIANGZHU — 绛珠仙子 / 林黛玉

- 身份层：同一灵魂、两种形态；仙子形态不是另一张脸。
- 脸：窄柔鹅蛋脸，内眼角略低，眼尾微挑但不锐，眉线细长，鼻口小而清楚；气质敏感、清醒、克制。
- 发：浓黑而轻，额际碎发柔软；凡人形态发式随年龄和礼仪变化，发际线、发量和脸侧轮廓不变。
- 色彩：月白、灰紫、淡青，病弱阶段降低饱和度，不用俗艳粉红。
- 标志：绛珠草叶形发簪/纹样只作极轻暗示；泪光是表演，不是永久妆效。
- 禁漂移：不得画成尖锥脸、夸张大眼网红脸、浓艳成熟御姐或某位演员肖像。

### CHAR_SHENYING — 神瑛侍者 / 贾宝玉

- 身份层：同一灵魂、两种形态；通灵宝玉是关联资产，不等于角色本体。
- 脸：少年圆润鹅蛋脸，直眉、柔和但清楚的眉骨与下颌，眉眼明亮，鼻梁不高耸，唇线清楚；无眼线或唇妆，秀润但必须一眼可读为少年男性，也不画成成年武侠男主。
- 发式/服装：少年男性束发配小型玉冠，禁止女式花髻和耳坠；朱砂男式直肩系带袍，有明确腰带，不做新娘礼服或裙装式高腰轮廓。
- 体态：平直但尚未成年的肩背、自然男性喉颈与腰胯轮廓，无女性胸型、女式妆面或新娘礼服轮廓。
- 发：黑发丰厚，额头与鬓角轮廓固定；凡人形态按礼仪束发。
- 色彩：朱砂红、暖玉白、旧金，随家族衰败逐步褪色。
- 标志：通灵宝玉、红色系主服色、对女儿世界的开放目光。
- 禁漂移：不得欧美骨相、短发、健身成年体型、邪魅霸总表情或某位演员肖像。

### CHAR_YINGLIAN_CHILD — 幼年英莲 / 香菱

- 身份层：三岁幼女，未来香菱形态必须继承额头、眼距、鼻口和脸型。
- 脸：幼圆脸、清亮杏眼、眉淡、鼻口小；天真而非娃娃滤镜。
- 色彩：藕荷、米白、嫩绿。
- 标志：眉心附近可识别的小痣位置固定；幼年发束与未来发际线继承。
- 禁漂移：不得画成现代儿童写真、塑料娃娃或成人缩小版。

### CHAR_ZHEN_SHIYIN — 甄士隐

- 脸：五十岁上下，清癯温和，眼下略有疲态，留修整短须。
- 服装：姑苏乡宦家居常服，素雅而不寒酸；竹青、米褐、旧靛。
- 表演：恬淡、好奇、爱女；梦醒后从困惑转为短暂欣喜。

### CHAR_MONK / CHAR_DAOIST — 茫茫大士 / 渺渺真人

- 共同原则：仙境中骨相清奇、衣纹简洁；落入凡尘时显癞头跣脚、跛足蓬头，但不能变成恐怖怪物。
- 和尚：暖灰与旧赭，宽袖，笑意慈悲中带讥诮。
- 道士：青灰与墨黑，身形更瘦长，动作轻快，目光清醒。

## 第1话场景锚

### LOC_DAHUANG — 大荒山·青埂峰

- 空间：高山云海，断崖与青埂峰形成斜向轴线；未用顽石位于画面低处，补天石阵在高处远景。
- 光：神话层冷青天光，女娲炼石处有低饱和朱金火光。
- 常驻物：云海、断崖、炼石余烬、苔痕、顽石。
- 禁止：仙侠宫殿、现代山景摄影感、霓虹法阵。

### LOC_SPIRIT_RIVER — 灵河岸·三生石畔

- 空间：三生石居画左后，绛珠草在石根，灌愁海雾从画右远景进入。
- 光：月白逆光；甘露只有一点暖玉色。
- 常驻物：三生石、绛珠草、浅水、雾、远处离恨天轮廓。

### LOC_TAIXU_GATE — 太虚幻境牌坊

- 空间：石牌坊横断前景，门后留大片空白与云雾，人物从画左向画右进入。
- 光：无明确太阳，玉色散射光；雷声出现时由画右上劈入。
- 禁止：实体宫殿堆满金饰、游戏副本 UI、可读模型乱码。

### LOC_ZHEN_STUDY — 甄宅书房

- 空间：书案画左，芭蕉窗画右，门通向庭院；士隐伏案位置固定。
- 光：午后暖白窗光从画右进入，室内木色与竹青压低饱和度。
- 常驻物：书案、卷册、瓷盏、芭蕉影、竹帘。

## 第1话关键资产

- PROP_UNUSED_STONE：粗粝青灰顽石，天然裂纹形似未完成的环；不可长出卡通五官。
- PROP_TONGLING_JADE：由顽石幻化，温润白玉带极淡胭脂色沁，扇坠大小；字样由后期嵌字，不让模型生成乱码。
- PROP_DEW_BOWL：神瑛侍者浇灌绛珠草的素玉小盏，形制简洁。
- FX_INK_DREAM_TRANSITION：现实木纹/石纹过渡为水墨云气，是整部漫画的梦境转场母题。

## 连续性铁律

- “顽石 → 通灵宝玉”是同一资产的形态变化，裂纹母题必须继承。
- “绛珠仙子 → 林黛玉”“神瑛侍者 → 贾宝玉”“幼年英莲 → 香菱”均进入形态继承账本。
- 大荒山冷青、灵河月白、甄宅暖竹色三套场景色群不得随机互换。
- 僧道的站位轴线固定：和尚多在画左、道士多在画右；剧情明确换位时才改变。
