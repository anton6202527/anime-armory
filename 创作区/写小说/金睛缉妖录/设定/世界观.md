# 世界观 — 《金睛缉妖录》（工作名）

> 全局规则总览（与设定圣经互为表里：圣经记"条目"，本卡记"全局规则与底色"）。

## 力量 / 修炼 / 法术体系
- **凡人术法链（职业，非升级流）**：无品 → 符吏 → 术士 → 高功。靠师承与衙门习得，不靠吞丹突破。
- **缉妖三器**：符（符箓护身/缚妖）、砂（朱砂丹砂破幻/显形）、器（取经遗泽法宝，稀有认主）。
- **金睛余烬**：唯一的"看破"之力，只属沈砚；只看不战，代价沉重（见设定圣经）。
- **妖**：取经未尽收/遗落/被镇压的妖魔；入人间必披人皮或幻形，按妖龄妖力分散妖（单元）与大妖（主线）。

## 政治 / 势力格局
- **大靖朝**：明风架空王朝，承光年间。皇权之下设六部、内阁、宗室；表面承平，暗里妖患渐起。
- **钦天监**：观天测妖正衙，掌妖患奏报与镇妖大阵。
- **缉妖司**：钦天监下的缉妖密衙，厂卫气质——缉拿妖魔、勘断妖案，行事隐秘，对外多以寻常命案结案。内部论资排辈、世家与寒门暗斗。
- **通妖暗流**：朝中有人系统性"放妖入京"，引四百年前被镇大妖之余孽为己用——主线暗线，幕后直指高位与一桩四百年旧约。

## 地理 / 地图
- **靖京**：架空都城（明风），主舞台。皇城、官署区、坊市、河渠、城外义庄乱葬岗（妖案高发）。
- **缉妖司衙署**：录事房（沈砚处）、缇骑值房、仵作验房（苏窈处）、镇妖牢。
- **镇妖塔**：城郊（或更远），四百年前镇压大妖的封印之地，主线后段关键场。
- **取经遗迹**：散落各地的遗泽（古寺、碑、塔），藏法宝或封印线索。

## 时间线（关键节点）
- 约四百年前：取经功成，神佛退隐；未尽收之大妖镇于镇妖塔。
- 约五年前：沈砚之师林缚查妖案殉职，案卷被抹（开篇前史）。
- 承光年间（现在）：妖患渐起，人皮命案为引，沈砚得金睛余烬，卷入缉妖与通妖大局。

## 世界基调 / 视觉底色
- 基调：明风厂卫的冷峻 + 志怪悬疑的诡谲 + 探案的紧凑。
- 视觉底色（供漫剧转制参考）：青灰官署、朱漆衙门、夜雨长街、烛火验房、人皮显本相的惊悚特写、开睛时白睛金丝的标志性镜头。
