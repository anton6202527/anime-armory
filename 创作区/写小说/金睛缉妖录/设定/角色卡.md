# 角色卡 — 《金睛缉妖录》（工作名）

> 字段依家族 schema（novel-craft/references/setting-bible.md）。每个主要角色带「复用范围 / 首现章」三列。能力与代价以设定圣经为准。

### 沈砚（复用范围：全篇　·　首现章：第1章）【主角】
- 身份/定位：缉妖司录事出身的低阶缇骑；寒门，无世家背景，靠脚力与脑子吃饭。
- 外貌锚点：清瘦、身量中等；眉骨高、眼神沉静；左手虎口有常年握笔与刀的薄茧；**开睛时白睛浮起细金丝**（平时不显）。
- 性格 / 口吻：冷静、记性极好、认死理；话少而准，问案时一句顶三句；遇压不慌，习惯先看再断。
- 核心欲望：查清亡师被抹的妖案、为师正名；在论资排辈的缉妖司里证明寒门小吏也能断妖案。
- 真正需要（Need）：学会不只靠"看破"，也敢于信人、用人、担责，从孤勇走向能带队的人。
- 误信 / 自我欺骗（Lie）：认定"只要我看得够清，就能一个人把真相揪出来"——高估单打独斗、低估协作与人心。
- 旧伤（Wound）：五年前亲历师父殉案、案卷被抹、自己人微言轻无力翻案。
- 核心恐惧：再一次"看见了真相却无力改变"；以及金睛被人识破后连累身边人。
- 常用策略：遇压习惯**回避锋芒、暗中查证**，以退为进，攒足证据再当众揭穿。
- 底线 / 不可做之事：不嫁祸无辜、不为结案而伪造证据、不拿百姓性命做饵。
- 越过底线的代价：若被迫越界，将失去"为师正名"的立身根基，自我认同崩塌。
- 不能主动做的事（除非伪装/被控制/重大转折）：不主动滥用金睛害人、不投靠通妖者。
- 关系温度边界：对同僚疏离克制，对信任之人沉默护短，对妖与通妖者冷硬。
- 口吻禁忌：不说现代腔、不油滑卖弄、不长篇抒情。
- 金手指 / 能力：金睛余烬（看破本相/识破伪装/辨法宝灵光）+ 代价（灼目目盲、只看不战、看深反噬、金丝外露暴露）。详见设定圣经。
- 成长弧线：孤勇独查的边缘小吏 → 在一桩桩妖案中学会信人用人 → 终局敢于带队直面朝堂通妖大局，为师正名、亦走出师之死的阴影。
- 关键关系：亡师林缚（执念源）、搭档裴决（战力与信任）、仵作苏窈（勘案拍档/潜在情感）、上官周衡（压制者）。

### 裴决（复用范围：全篇　·　首现章：第1-2章）【战力担当 · 搭档】
- 身份/定位：缉妖司术士、缇骑小队实际战力；符箓丹砂法器俱精，缉拿妖魔的一把好手。
- 外貌锚点：高大、面相冷硬、左眉一道旧疤；常年玄色缇骑服，腰悬符囊与一柄镇妖短刀。
- 性格 / 口吻：寡言、行事果决、信奉"能拿住才算数"；初时轻视只会动笔的沈砚，后渐认可。
- 核心欲望：拿住每一个该拿的妖，不让案子烂在手里。
- 误信 / 自我欺骗：认定"看破没用，拿住才有用"——轻视勘案与推理，直到沈砚的金睛屡破死局。
- 旧伤：曾因看走眼放跑一妖、酿成血案，自此只信亲手拿住的。
- 核心恐惧：再因"看不破"而酿成无可挽回的错。
- 常用策略：遇压**正面硬刚**，先动手控场。
- 底线：不滥杀、不拿同僚顶罪。
- 不能主动做的事（除非重大转折）：不背叛缉妖司、不弃同伴独走。
- 关系温度边界：对沈砚由轻视到并肩，是全书最重要的信任线之一。
- 金手指 / 能力：术士级符术与缉拿（凡人术法，有耗精血代价），非金手指。
- 成长弧线：只信"拿住"的硬汉 → 学会先信"看破"再出手 → 与沈砚成生死搭档。

### 苏窈（复用范围：全篇　·　首现章：第1-3章）【勘案拍档 · 潜在情感线】
- 身份/定位：缉妖司女仵作，验尸辨妖痕的行家；心细、机敏、嘴利。
- 外貌锚点：素净利落、指节有验尸留下的细疤、惯戴一副护目水晶片；笑时眼尾微挑。
- 性格 / 口吻：表面促狭爱呛人，内里极重实证；与沈砚一个"看活的"一个"验死的"，互补。
- 核心欲望：让每具无名尸都有个说法。
- 误信 / 自我欺骗：用"只认尸身证据"挡住对活人世界的失望。
- 旧伤：曾验出真相却被上面压下，尸主沉冤未雪。
- 核心恐惧：证据被权势抹去、真相再次被埋。
- 常用策略：遇压**用证据顶回去**，据理力争。
- 底线：不改验尸结论、不昧良心。
- 关系温度边界：与沈砚由斗嘴到默契，情感线克制慢热。
- 金手指 / 能力：仵作验术 + 基础辨妖痕（凡人技艺），非金手指。
- 成长弧线：只信死物证据 → 学会也信沈砚"看破"的活线索 → 共同撑起翻案。

### 周衡（复用范围：第一至二幕主　·　首现章：第2章）【中层压制者】
- 身份/定位：缉妖司主事，世家出身；论资排辈、好压案邀功，与沈砚作对。
- 外貌锚点：保养得宜、笑面、指上一枚祖传玉扳指；衣着比同僚精致。
- 性格 / 口吻：场面话漂亮、暗里捅刀；信奉"案子要结得体面、不惹上面"。
- 核心欲望：仕途稳进、不出纰漏；把功劳揽下、把麻烦推走。
- 误信 / 自我欺骗：以为压住妖案就是稳住朝局，实则被通妖者利用。
- 底线 / 越界代价：本意非大奸，但为前程会压案；一旦查到他头上会反扑。
- 不能主动做的事（除非转折）：未必真心通妖——是否被裹挟入暗线，留待中段揭示。
- 关系温度边界：对沈砚表面提携、暗中打压。
- 成长弧线：压制者 → 被通妖大局反噬 → 或醒悟、或沦为弃子（章纲中定）。

### 林缚（复用范围：前史/回闪　·　首现章：第1章提及，回闪渐显）【亡师 · 主线暗线起点】
- 身份/定位：沈砚之师，缉妖司老缉妖；五年前查一桩妖案殉职，案卷被人抹去。
- 外貌锚点：花白鬓角、左手缺半指（旧年缉妖所伤）、惯用一枚旧铜哨。
- 性格 / 口吻：沉稳老练、护短、信"案子比命金贵"。
- 在剧中作用：其死是主线"放妖入京"暗线的起点；遗物（旧案卷残页/铜哨）是沈砚追查的线索锚。
- 不可改：作为前史人物，其结局（殉职）已定，回闪不得推翻。

## 一致性约束（角色侧）
- [ ] 沈砚每次开睛守金睛代价；战力不靠自身、靠裴决/器物。
- [ ] 裴决=战力，苏窈=验证，沈砚=看破：三人分工不混淆。
- [ ] 周衡是否入暗线，留章纲定，前期只写"压案排挤"。
- [ ] 林缚殉职结局不可翻，回闪只补细节不改结果。
