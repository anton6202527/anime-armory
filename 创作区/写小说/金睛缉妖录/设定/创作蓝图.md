# 创作蓝图 — 《金睛缉妖录》（工作名）

> 这部原创小说的"宪法"。每条具体可判定。来源：用户"西游×大明朝"想法 → 立项访谈补全（架空明风+公版西游+原创主角，三支柱用户已确认）。

## 一句话故事（logline）
取经功成四百年后，大靖朝缉妖司一名不得志的低阶缇骑，因一桩"人皮命案"意外承接了孙悟空遗落人间的一缕**金睛余烬**——能一眼看破妖魔本相与虚妄伪装；他循着案子查下去，却扯出妖魔重返人间、朝堂有人通妖的惊天大局，只能凭一双灼目金睛，在缉妖司、朝局与人心之间，把藏在官袍与人皮下的妖揪出来。

## 题材 / 用途 / 平台 / 基调
- 题材类型：古代探案 · 缉妖 · 朝堂权谋（明风架空 + 公版西游神魔）
- 小说用途：**漫剧源书**（可接 n2d 转制 AI 漫剧/短剧）
- 目标平台：红果 / 抖音漫剧（竖屏短剧口味：黄金开篇、强钩子、案件节拍紧）
- 基调：沉稳爆爽 + 悬疑探案 + 克制的厂卫冷峻；以"识破—揭穿—翻盘"为爽感主轴，不滥升级

## 主角
- 是谁 / 出身 / 性格底色：**沈砚**，缉妖司"录事"出身的低阶缇骑（无世家、靠脚力与脑子吃饭），冷静、记性极好、认死理；表面是个被排挤的边缘小吏，内里有股不肯认命的轴劲。
- **金手指 / 核心能力（必须有代价/限制）**：**金睛余烬**——孙悟空当年遗落的一缕火眼金睛余泽，附于沈砚双目。
  - 能力：看破妖魔本相（人皮下的真容）、识破幻术/伪装/魂魄附身、辨认法宝灵光。
  - **代价/限制（铁律）**：①每"开睛"一次，双目灼痛、白睛染金丝，**用后短暂目盲/眼疾**，过用损寿；②只能"看破"，不直接给战力——揪出妖还得靠缉妖司的人、术、器去拿；③看得越深（看魂、看大妖本相）反噬越重；④金丝外露会被识货的妖/通妖之人认出，是把双刃剑。
- 动机 / 心结 / 渴望：早年其师（老缉妖）死于一桩被压下的妖案，案卷被人抹去；沈砚渴望查清真相、为师正名，并在论资排辈的缉妖司里，证明"寒门小吏也能断妖案"。

## 核心爽点（漫剧密度：每章至少一处）
- **一眼识破**：金睛开，当众揭穿伪装成人/官/亲眷的妖与通妖者——身份反差越大越爽。
- **以弱破强的探案翻盘**：没背景、没法力，靠观察+金睛+推理，把比他高位的人/妖按死。
- **打脸与昭雪**：被轻视的边缘小吏屡破悬案，打权贵/同僚的脸；为冤案/亡师昭雪。
- **抽丝剥茧的志怪奇案**：每案一个西游味的妖（公版体系延伸的小妖/遗孽），诡异开局→金睛点破→缉拿收束。
- **朝局暗涌**：案件背后渐次浮出"谁在放妖入京"，权谋与缉妖交织。

## 主线冲突（主角要对抗的最大阻力）
- 浅层：每案的妖/通妖者（单元反派）。
- 中层：缉妖司内部的论资排辈、压案、与沈砚作对的上官/世家子。
- 深层（主线暗线）：**有人在系统性地"放妖入京"**——把当年取经未尽收、被镇压的妖孽引回人间为己所用；幕后直指朝堂高位与一桩四百年的旧约。亡师之死正是这条线的起点。
