# 读者契约 — 《金睛缉妖录》（工作名）

> Demo 通过后同步关键字段进 `审稿/demo_gate.json.reader_contract`，由 draft_packets 塞进每章任务包。

## 核心题旨
- 一句话题旨：**当一个人能看穿所有伪装，他要如何对抗那些躲在体面与权势背后、看不穿的人心？**
- 核心戏剧问题：寒门小吏沈砚能否凭"看破"之力，在无神可依、论资排辈的世道里，把藏在人皮与官袍下的妖与通妖者揪出来，并为亡师正名？
- 这本书最后必须回答：看破真相，是否就等于能改变真相——以及他能否从"一个人看见"走到"带一群人改变"。

## 读者承诺
- 开篇承诺：第1章即给"诡案+金睛开睛看破本相+当众揭穿"的完整爽感闭环，立住金手指与基调。
- 中段承诺：一案比一案凶险，妖案渐次牵出缉妖司内斗与"放妖入京"暗线；身份反转与打脸密集。
- 终局承诺：直面镇妖塔大妖与朝堂通妖主谋，亡师之案真相大白、得以正名；沈砚完成从孤勇到带队的成长。
- 不可违背的爽点 / 情感兑现：**每一次"开睛看破—当众揭穿—翻盘打脸"必须兑现**；为冤者昭雪的情绪必须给足。

## 好看机制
- 主要吸引力：探案解谜的智斗 + 金睛看破的视觉奇观 + 寒门逆袭打脸的爽感。
- 反差 / 反转来源：越体面/越高位者越可能是妖或通妖；越不起眼的小吏越能断案；伪装与本相的反差。
- 每 3-5 章应出现的推进：一个完整妖案了结 + 主线暗线推进一步（新线索/新反派浮出）。
- 不能连续出现的疲劳项：连续同质化"开睛即破"无智斗过程；连续无代价滥用金睛；连章只刷打脸不推主线。

## 文学质感
- 文风气质：冷峻、克制、画面感强；明风厂卫的肃杀 + 志怪悬疑的诡谲。
- 具体意象库：夜雨长街、朱漆衙门、烛火验房、人皮显本相、白睛浮金丝、镇妖塔影、铜哨残页。
- 对白质感：短促、有信息量、留潜台词；问案如交锋，不废话。
- 情绪表达方式：以动作/勘案细节/环境烘托情绪，少直白抒情。
- 禁止的 AI 味 / 空泛句式：不堆形容词、不写"他感到一阵强烈的……"式空泛、不用现代网络腔。

## 禁偏清单
- 不要偏成的题材：不要写成宫斗言情或纯升级爽文；本质是探案缉妖+权谋。
- 不要盖过主线的人物 / 支线：情感线（苏窈）克制，不得喧宾夺主压过缉妖主线。
- 不要牺牲的角色弧光：沈砚"从孤勇到信人带队"的成长不能丢；裴决"从轻视到并肩"不能省。
- 不要违反的价值边界：不魔改西游经典人物、不戏说真实历史、金睛不得无代价、主角不越底线（嫁祸/伪证）。
