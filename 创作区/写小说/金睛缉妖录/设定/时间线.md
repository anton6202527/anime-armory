# 时间线 — 《金睛缉妖录》（工作名）

> 事件因果顺序表：开局前史 → 当前卷关键节点 → 伏笔回收窗口。回扫核对，防因果倒置。

## 前史（开篇之前）
- 约四百年前：唐僧师徒取经功成，神佛退隐人间（公版传说）；取经未尽收之大妖被镇于**镇妖塔**。
- 历代：取经遗泽（法宝/遗迹/封印）散落人间；妖魔零星潜回，朝廷设钦天监、缉妖司应对。
- 约五年前：沈砚之师**林缚**查一桩妖案殉职，案卷被人抹去；沈砚人微言轻，无力翻案——埋下执念与主线暗线起点。

## 第一幕（约第1–6章）：立世界 + 金睛登场 + 暗线引信
- 第1章（承光年间·现在）：**人皮命案**爆发，沈砚临场，机缘承接金睛余烬，开睛看破首妖，当众揭穿——开篇钩。
- 第2–6章：沈砚以金睛屡破小妖案，崭露头角；遭周衡压案排挤；裴决由轻视到初步并肩；首次出现"亡师旧案残页/铜哨"线索，暗示当年妖案与今日妖患同源。

## 第二幕（约第7–18章）：案案相扣 + 暗线浮出 + 中段大反转
- 第7–12章：妖案升级，渐次发现**有人在系统性放妖入京**；查证牵出朝堂高位影子；苏窈验出被压下的关键尸证。
- 第13章前后（中段大反转）：查到的线索直指亡师之死并非意外，而是被通妖者灭口；周衡的压案被揭出是受人指使（是否主动通妖，此处揭示）。
- 第14–18章：沈砚金睛过用、代价加重（目盲/反噬）危机；通妖者察觉金睛存在，开始针对沈砚；主线大妖（镇妖塔余孽）将醒的征兆显现。

## 第三幕（约第19–24章）：高潮对决 + 主线收束
- 第19–22章：镇妖塔封印松动，大妖余孽与通妖主谋图谋；沈砚联合裴决、苏窈及缉妖司可信力量，布局反制。
- 第23章：高潮——直面通妖主谋与大妖，金睛拼尽代价看破最后伪装，揭穿四百年旧约真相。
- 第24章：主线收束，亡师之案昭雪、得以正名；沈砚完成从孤勇到带队的成长；留续作钩（更深的旧约/更大的妖）可选。

## 伏笔回收窗口
- 铜哨/残页（第1幕埋）→ 第13章前后回收（指向亡师被灭口）。
- "放妖入京"暗线（第1幕暗示）→ 第二幕浮出 → 第三幕收束。
- 金睛代价累积（全程）→ 高潮处代价最重，成为对决的张力来源。
