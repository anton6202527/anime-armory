# 第16章 破壁人？我反过来敲诈你

　　石台天梯立在天火大陆的尽头，一头扎进地里，一头捅破了云。

　　王敦仰着脖子，看那道青衫身影一阶一阶往上挪。

　　贺平生爬得不快。这天梯邪门，越往上，每一阶都重得像背了一座山。可他没停，一步一个脚印，踩得稳稳当当。他每登高一寸，天穹深处便有一缕乳白的光华，顺着梯身淌下来，洇进这片大陆的地脉里。

　　那是人族的气运。压了千百年的浊气，被这小子一脚一脚，往上顶。

　　王敦站在梯底的石台上，周遭黑压压坐满了人。说是人，其实没几个真是人。长角的、生鳞的、披着羽的、顶着兽首的，密密麻麻挤了大半个天穹下。这石台之会，是金刚妖帝坐的庄，天火大陆有头有脸的妖帝神裔，今儿全来了，就为看一场热闹。

　　热闹本该是别人的。人族这种货色，往年也有冲梯的，爬不到三万丈就被那重力压趴下，灰溜溜滚下来，惹得满场哄笑。

　　今年不一样。

　　贺平生已经过了八万丈，还在往上爬。那从天而降的气运光华，一刻比一刻盛。妖族的脸，一张比一张难看。

　　王敦把这些脸色尽收眼底，心里那点得意，跟揣了只猫似的，挠得他直痒痒。他咧着白牙，扭头冲身旁一个生着雪白狐尾的小妖女挤眼睛：“瞧见没？我师弟。亲的。”

　　那小妖女叫南七七，是金刚妖帝座下管杂务的，先前给他们引过路。她翻了个白眼：“爬得越高，摔得越惨。你当那帮老凤凰是吃素的？”

　　王敦笑容没动，眼底却沉了沉。

　　他懂南七七的意思。

　　这一路他都盯着呢。看台西侧那片烧着凤羽火光的位置，坐着一群披羽的女修，为首一个清艳逼人的，正是三梦红尘里被他祸祸了个底朝天的凤晚曦。这煞星打从出梦那天起，眼刀就没从他身上挪开过，时不时还往他袖子里那处瞟——他知道她瞟的是什么。入梦之石。她以为那石头还在他手上。

　　凤晚曦身后，端坐着十三道更森然的气息。凤族十三长老，个个炼虚顶尖，有几个甚至摸到了合体的门槛。

　　这帮老东西，从贺平生踏上天梯的头一刻起，就没安好心。

　　果然。

　　贺平生爬到十万丈那道横亘天梯的赤色光壁前，脚步顿住了。

　　那光壁是天梯设下的关隘，本就要登梯者凭真本事破开。寻常时候，破不开，退下来便是，不伤性命。可此刻，那十三道凤族气息齐齐拔地而起，化作十三团赤红凤焰，绕着那道光壁，结成了一座杀阵。

　　他们要在这关隘上，把贺平生活活耗死在半道。

　　借着破壁的名头杀人，谁也挑不出错。横竖人族冲梯，年年都有死在壁上的。

　　“卑鄙。”南七七也看出来了，皱起小鼻子，“你师弟一个人，破不了这壁，还得防着十三尊围杀。死定了。”

　　王敦没说话。

　　他黑脸上那点嬉皮笑脸，一寸一寸地收了。

　　十万丈高处，贺平生孤零零站在那片赤焰里，青衫被罡风吹得猎猎作响。他没退。这傻小子，明知道是死局，还是把那点不肯弯的腰，挺得笔直。

　　这是要替人族争气，争到把命搭进去。

　　王敦在心里骂了句娘。

　　他原是不打算上去的。石台天梯这等改换一族命数的机缘，他自问扛不动，一身气运还是催命的，便把那块拼了命凝出的入梦之石，让给了师弟。让他这心里装得下苍生的傻子去扛，物尽其用。他自己乐得在底下当看客，嗑着瓜子看师弟封神。

　　可看客这买卖，得师弟活着，才做得下去。

　　“七七。”王敦慢悠悠地，从怀里另一处贴身的暗袋，摸出一块温润生光的白石头来，掂了掂，“你说，老子这块，还能不能用？”

　　南七七的眼珠子差点没瞪出来：“你……你不是把入梦之石给你师弟了吗？！”

　　“嘿。”王敦贱兮兮地咧嘴，把那石头在指间转了个圈，“老子当年在三梦红尘里玩得太开心，本源足得很，一不留神，凝出来俩。给了老弟一块，自个儿藏了一块。”

　　他这话半真半假。藏一手，是他王敦刻在骨头里的本能。打灵药谷当管事那会儿起，他兜里就没断过备用的牌——明面上递出去一张，暗地里压着另一张。这辈子能从齐国天牢、从各路煞星手里一次次扯呼活命，靠的就是这点谁也猜不透的留手。

　　石头到手，资格便有了。

　　他抬脚就要往天梯上踏。

　　“站住。”

　　一道懒洋洋的声音，从斜刺里飘了过来。

　　王敦回头，见一个穿赭红长袍的男人，正背着手，慢吞吞地踱过来。这人生得清瘦，下颌一缕山羊胡，眼皮耷拉着，一副看什么都提不起劲的模样。他周身那股气机，深得像口枯井，望不见底——大乘帝境。比那十三个凤族老儿，还要高出一线。

　　满场的妖帝神裔，见了这人，都微微坐直了些。

　　“破壁人，段飞红。”那男人自报家门，声音里没什么起伏，“专替登梯的，破壁。”他斜了王敦一眼，又往十万丈那座杀阵上瞟了瞟，嘴角扯出一丝惫懒的笑，“小胖子，你师弟那道壁，加上十三尊凤族，你俩谁也别想凭自个儿过去。”

　　“我这条道，是天梯认下的。我领着你们上，那十三尊老凤凰的阵，碰不得我，也碰不得我带的人。规矩如此。”段飞红伸出三根指头，懒洋洋地晃了晃，“三件帝境灵宝，我送你俩，直达顶端。怎么样？”

　　这是趁火打劫。

　　王敦心里跟明镜似的。这破壁人吃的就是这碗饭——专挑登梯者最走投无路的当口现身，开出天价。你不应？你师弟就死在壁上。你应了？倾家荡产。

　　换个人，这会儿怕是要赶紧掏家底了。

　　王敦不。

　　他上上下下把段飞红打量了一遍，那双在死人堆里磨出来的眼睛，飞快地绕着这惫懒男人转了三圈。这一扫，他心里就有了底。

　　“段大师。”他咧开白牙，笑得那叫一个真诚，“您这买卖，做得不地道啊。”

　　段飞红耷拉的眼皮，掀了掀。

　　“您是人族吧？”王敦背着手，慢悠悠地踱了两步，“瞧您这岁数、这修为，在天火大陆当破壁人，少说也当了几百年了。我就问您一句——这几百年，经您的手领上天梯的人族，有一个冲到顶的吗？”

　　段飞红那张惫懒的脸，第一次有了点细微的变化。

　　“一个都没有。”王敦自问自答，摇头晃脑，“为啥？因为您领着上去的，全是借您的力，自个儿没那个本事。气运这东西，认的是真章。借来的腿，跑不出真气运。您领上去多少，人族就白白糟蹋多少机缘。”

　　他往前凑了凑，唾沫横飞，活像个磨破嘴皮也要谈成买卖的胖货郎：“可今儿不一样。今儿天梯上头那位，是我师弟，贺平生。他凭自个儿，已经爬到十万丈了。这往天上倒的人族气运，您也瞧见了吧？几百年没见过这阵仗了吧？”

　　段飞红没说话，那双枯井似的眼睛里，却极淡地动了一下。

　　“老子告诉您。”王敦把胸脯一拍，“今儿这场，注定要载入人族的史册。您段大师，当了几百年破壁人，连个冲顶的都没碰上过。眼下天大的功德气运摆在您面前，您不来沾光，回头肠子都得悔青。”

　　“所以这买卖，得反过来做。”

　　他伸出两根胖手指，在段飞红面前晃了晃，笑得贱兮兮：“您不但不该收老子的宝贝，您还得倒贴。这么着——把您那储物戒指掏出来，让老子挑两件中意的。算老子赏您一个，跟着人族双璧沾光长脸的体面。您说，这买卖，划不划算？”

　　满场死寂。

　　看台上那帮妖帝神裔，全傻了。

　　几百年来，破壁人段飞红坐地起价，宰过的肥羊不计其数，何曾被人这么倒打一耙过？让被宰的羊，反手从屠夫兜里掏刀？这黑胖子，脸皮怕是拿城墙砖砌的。

　　南七七在旁边听得目瞪口呆，半晌憋出一句：“你、你这人怎么这么不要脸……”

　　段飞红盯着王敦，盯了足足十息。

　　然后，这位惫懒了几百年的大乘帝境破壁人，忽然嗤地笑了一声。那笑里头，竟有几分连他自己都意外的、被勾起来的兴味。他枯井般的眼睛里，头一回，落进了天梯上那道气运的光。

　　“有意思。”段飞红慢吞吞地，把储物戒指褪了下来，随手抛给王敦，“几百年了，头一回有人这么跟我说话。挑吧。”

　　王敦接过戒指，神识一扫，眉开眼笑地挑了两件最扎眼的帝境灵宝，揣进怀里，把戒指利索地丢了回去。

　　“多谢段大师赏脸。”他拱了拱手，转身就要往天梯上踏。

　　段飞红在他身后慢悠悠开口：“宝贝你拿了。现在，我领你俩上去。”

　　“不必了。”

　　王敦头也没回，一脚踏上了石台天梯第一阶。那阶梯的重力轰然压下，压得满场妖族都为他捏了把汗，他黑脸上的痞笑，却半分没塌。

　　“段大师，您这破壁的本事，留着挣别人的钱去吧。”

　　他抬手，遥遥指向十万丈那座赤红杀阵，指向阵里那道孤零零的青衫。两排白牙在天光下亮得晃眼。

　　“老子和我师弟，这趟天梯，不用破壁人。”

　　“我们人族的腰杆子，这回，自个儿挺。”

　　（第16章 完）
