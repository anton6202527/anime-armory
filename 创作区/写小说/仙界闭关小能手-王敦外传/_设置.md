# 设置 — 本作私有选择点（skills/novel-craft/references/选择点与偏好.md）

> 外传：配角平行视角，锚点处锁原作事件。

- **目标平台**：番茄
- **小说用途**：传统小说 / 短剧源书
- **权利来源**：user-declared
- **权利辖区**：user-declared
- **发行地区**：GLOBAL
- **外传模式**：parallel
- **输出格式**：txt,docx,outline（novel-craft/scripts/export.py）
- **小说生成模式**：稳妥初稿
- **小说生成工作流**：边写边自检
- **小批回扫间隔**：5章
- **章节生成粒度**：逐章
- **文本主创模式**：AI辅助
- **AI使用披露**：AI-assisted
- **短剧容量目标**：100集（小说每章约拆5个强钩场景）
- **王敦外形修订**：壮实、黑肤、宽肩、俊朗有压迫感；不再按肥胖谐角写
- **王敦情感线**：非滥交；明面妻子/正缘=重华；红颜知己=梁画秋、凤晚曦
- **王敦-贺平生耦合强度**：高；凡交汇章必须加厚王敦侧动机、代价、互救与互坑的情感账

> 这些值由 init 按 CLI 参数/全局默认落定；同项目后续**沉默沿用**，改了在此更新。合规/不可逆/花钱多的点每次仍向用户确认。
