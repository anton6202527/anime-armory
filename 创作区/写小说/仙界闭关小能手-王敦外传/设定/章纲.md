# 章纲 — 《王敦传：开局九龙气运，我在灵药谷装管事》（第一季 · 20 章 / 短剧 100 集容量）

> parallel 并行外传。锁原作 15 个锚点（A01–A15），锚点之间优先写王敦自己的逃亡、闭关、结盟、情感与势力经营。第三人称限知贴王敦。番茄/红果节奏：每章一爽点 + 章末强钩子；每章约拆 5 个短剧强钩场景，总容量按 100 集规划。

## 总体弧线
一个被全世界（齐国）追杀的"九龙气运"顶配天才，扮成灵药谷一个土憨小管事藏起来——可顶配气运注定藏不住。他一路被追、一路变强、一路护短，从炼气六层的灵药谷管事，打成飞升仙界、与师弟贺平生并称"人族双璧"、被混元神帝看中收徒、赢得帝女重华芳心的男人。王敦本相不走肥胖谐角，而是黑肤、宽肩、壮实、俊朗有压迫感；早期“黑胖”只作为通缉画像丑化、敌人口误或伪装误读。**藏 → 战 → 立**。内核母题：金手指即催命符——逍遥与被追杀的一体两面。

## 独立时间线与情感口径
- **独立时间线**：王敦不只是原作配角补丁。本传只在 A01–A15 等交汇事件上锁原作，其余篇幅优先补王敦单线：齐国皇监逃亡、灵药谷暗账、闭关突破、追杀反杀、灵界经营、仙界拜师与重华线。
- **王敦×贺平生**：全书最高耦合关系。每个交汇章都要写足“互相利用 → 互相托底 → 互相背锅 → 人族双璧”的情感账、代价账和名号债。
- **感情线**：王敦桃花运可以好，但不是滥交。明面妻子/正缘为重华；梁画秋、凤晚曦是两条红颜知己线；南七七等不收进暧昧后宫，只作盟友、吐槽或助攻。
- **短剧容量**：第一季 20 章按 100 集拆分，详见 `设定/王敦独立时间线_100集.md`。每章内部至少保留 5 个可独立成集的钩子：身份钩、爽点钩、情绪账、反转钩、章末追杀/情感钩。

## 三幕结构（≈5 / 10 / 5）
- **第一幕（1–5）藏**：灵药谷装管事，气运藏不住，被迫开跑。
- **第二幕（6–15）战**：金丹→炼虚，被追杀中一路翻盘、护短、飞升灵界。**中点危机=第10章天极绝地中毒濒死**。
- **第三幕（16–20）立**：人族双璧鹊起（季中高潮·17）→ 飞升仙界 → 重华初遇情线起点（季终·20）。

## 逐章（标题 / 主线事件 / 锚点 / 王敦境界 / 视角情绪 / 章末钩子）

- **第01章《九龙气运，全齐国都在抓我》** — 冷开场：王敦从齐国皇监九死一生逃出（留白#3半解），易容成土憨管事混进太虚门灵药谷；宽袍、含胸和通缉画像把他误传成黑胖矮子，本相应是黑肤壮实、肩背压得住道袍。｜锚A01前置｜炼气六层｜情绪：劫后余生的松弛+警觉，痞中带狠｜钩子：海捕文书贴到太虚门山门，画像隐约是他。
- **第02章《招个费钱货来给我供火》** — 灵药谷招主修火灵根的贺平生供火，王敦相中他纯火灵力（暗中也察觉师弟身上同样异常的气运直觉）。｜锚A01｜炼气六层｜情绪：识货的精明+同类相吸的好奇｜钩子：枯木真人察觉灵药谷火源有异。
- **第03章《偷半瓶花粉，糊弄老登》** — 教供火规则与采花粉、怂恿藏花粉糊弄枯木；埋对枯木的旧怨暗线（F03）。｜锚A02｜炼气六层｜情绪：贼兮兮的松弛 + 一闪而过的杀意｜钩子：紫色禁区灵气暴动，枯木起疑盯上管事。
- **第04章《龙吟榜第一，藏不住了》** — 时跳：王敦筑基成龙吟榜第一，易容络腮大汉堵贺平生硬拉去神将山交任务，被子兰拔剑护人。｜锚A03｜筑基·龙吟榜第一｜情绪：藏不住的张扬 vs 危机将至的警觉｜钩子：九龙宝镜测试令下，专筛"看见九龙的人"——正是冲他来的。
- **第05章《三十六计，跑为上》** — 城主府放风重测作弊者，王敦秒懂测试在精准猎他，火急跑路，叮嘱师弟别供他。｜锚A04｜筑基·逃亡｜情绪：决断+对连累师弟的愧疚（顶配气运的孤独初现）｜钩子：他一跑，火力果然引向贺平生——埋愧疚债。
- **第06章《九国大比，替死符给你》** — 时跳金丹圆满，九国大比替室女国出战重逢师弟，把仅两张的命根子替死符送他一张。｜锚A05｜金丹圆满｜情绪：豪气+托底的真心（塑料兄弟钢铁情）｜钩子：萧玄叫板，齐国势力在场盯上。
- **第07章《五招，一拳轰你吐血》** — 强横王敦五招破萧玄、洞穿冰柱连胜逼齐国认输。全季第一个大爽点。｜锚A06｜金丹圆满·炼体真身｜情绪：扮猪吃老虎亮底牌的爽｜钩子：龙渊确认他=九龙者，齐国三祖出动追杀。
- **第08章《好男不跟女斗，三祖来送死》** — 对梁画秋插科打诨；梁画秋第一次看见他嬉笑背后的护短和杀性，红颜知己线埋种但不收成暧昧。齐国三祖（化神）围杀，王敦凭气运+炼体反杀三祖。｜锚A06续/F01回收半｜金丹圆满｜情绪：快意恩仇+杀伐果决｜钩子：齐国之耻坐实"自王敦之后没人把皇室放眼里"；他成全修真界头号通缉。
- **第09章《老子的命，自己说了算》** — 母题章：处理三祖后事、独自咀嚼"顶配气运=全世界的猎物"的孤独与自由（留白#12）。再遁走闭关。｜锚（过渡）｜金丹圆满→元婴｜情绪：孤独、自嘲、倔强的自我和解｜钩子：天极绝地机缘传闻 + 师弟同行。
- **第10章《天极绝地，木生火要烧死我》** — 与师弟闯天极绝地，遭树妖"木生火天地大熔炉"围攻、中五品神毒。**中点危机·第一次真可能死**。｜锚A07｜元婴八层｜情绪：濒死的狼狈 + 不肯认命｜钩子：互救解毒生死关，师弟拼命救他。
- **第11章《出关即是王敦老祖》** — 解毒出关已元婴八层、成真灵谷"王敦老祖"、收徒慕容纤纤；红肚兜假信物坑师弟去找乌蜜。｜锚A07续｜元婴八层｜情绪：枭雄初成+损友本色｜钩子：飞升灵界在即；灵界妖帝当道、人族被轻视的传闻。
- **第12章《敢踩我师弟？给我个面子》** — 飞升灵界（"快百年了"），撞见师弟被炼虚大能明月佛尊踩，强行护短嘴炮拖延。｜锚A08｜化神八层｜情绪：明知打不过也要插手的护短血性｜钩子：明月是人族最强佛子，气运还归佛门——人族之耻的伏笔。
- **第13章《砍他双臂，然后扯呼》** — 联手砍明月双臂后果断保存实力撤；互赠替死傀儡、冰玉枇杷膏。护短高光+爽点。｜锚A08续｜化神八层｜情绪：狠+滑（该出手出手、该跑就跑）｜钩子：师弟借他名字，将招来空空兽大祸（他还不知）。
- **第14章《绑柱受刑，老子照样嘲讽你》** — 被空空妖帝一族围捕背锅（师弟被误喊"王敦"），绑柱受鞭刑仍嘴硬，自曝揍过蓝羽帝君（F05）。｜锚A09｜炼虚二层（已杀空空太子本体+五炼虚）｜情绪：硬骨头+黑色幽默｜钩子：妖帝抓他是为石台之会布局。
- **第15章《三梦红尘，我当了回皇帝》** — 三梦红尘试炼出梦（留白#8整章发力：梦中当皇帝祸祸凤族女选手遭围殴），荒唐桃花只写为梦劫与讽刺，不落实为滥情；把入梦之石让给师弟冲天梯。｜锚A10｜炼虚｜情绪：荒唐一梦后的清醒+成全师弟的义气｜钩子：石台天梯——冲高直接改变整个人族气运。
- **第16章《破壁人？我反过来敲诈你》** — 凤族十三长老堵在十万丈截杀；凤晚曦因梦劫旧账与族群立场误会王敦，却也看见他替人族硬扛的骨气，红颜知己二线埋种。王敦反向敲诈破壁人段飞红"在你戒指里挑两件宝贝"。｜锚A11前段｜炼虚·法天象地｜情绪：损中带霸的松弛｜钩子：放话不靠破壁人也要冲到顶。
- **第17章《须知少年凌云志，我王敦来了》** — 不靠破壁人与师弟并肩冲15万丈、吟豪放诗、羞辱凤族女帝，全场高呼王敦，**人族双璧之名鹊起**。**季中高潮**。｜锚A11高潮｜炼虚·法天象地｜情绪：为人族扛旗的热血巅峰｜钩子：一战封神，飞升仙界。
- **第18章《在下王敦，仙界都在传我的名》** — 飞升仙界太乙金仙，与师弟重逢撞破互相冒名顶替的乌龙；【王敦密码】（因果符二进制传讯）全仙界传开（F02回收·留白#6）。｜锚A12+A13｜太乙金仙｜情绪：天才本色藏不住的得意+兄弟重逢的暖｜钩子：连混元紫薇神帝都听说了"那个绝世天才王敦"。
- **第19章《拜入神帝门下，我要证道种》** — 留白#10发力：王敦拜入北极紫薇神帝门下的契机；正凝聚道种；侧写一个傲娇帝女总在打听他、转述他"人与人最重要是信任"（F06/留白#11）。｜锚A13尾｜太乙金仙巅峰·凝道种｜情绪：野心+被人惦记而不自知的钝感萌｜钩子：那帝女把师弟单独留下，旁敲侧击他"以前有没有道侣"。
- **第20章《重华公主，你信我还是信我师弟？》** — **重华初遇**：王敦躲屏风后设局，借重华向贺平生套话自证"从无女人"，得逞后贱兮兮现身；重华挽他胳膊"人家只是关心你嘛"。再携重华十六道君神车撞青莲道君帝宫、当面骂"老登"、丢仙晶扬长而去。**季终情线起点+丈母娘攻略种子**。｜锚A14+A15｜太乙金仙巅峰·得逆天伪装秘术｜情绪：情窦初开的笨拙痞甜+得意忘形｜钩子：岳父是受天道禁令"从不出手"的混元神帝；齐国旧账未清——季2预告。
