# 世界观 — 摘自《仙界闭关小能手》

> 第 2 步主对话填写。只摘原作已确立的规则，不发明能推翻原作的新规则。逐字深读结论，行号可回查。

## 修炼 / 能力体系

**三界飞升阶梯（逐级核对原文）**
- **修真界**：炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 炼虚期 → 合体期 → 大乘期（帝境）→ 飞升。每大境分多层（金丹十二层 23853、元婴十/十一层 30493、合体四层 41457、大乘帝境十二层 47661）。
- **灵界（天火大陆）**：沿用同一阶梯，顶端是**大乘帝境的妖帝/大帝**，统治"帝域/帝城"(41462)。妖族当道。
- **仙界**：玄仙 → 金仙 → 太乙金仙 → 大罗金仙 → 道元境（道君）→ 混元（神帝）(76267,85539,85722)。
- **神界**：需凑齐三十六枚同源大道秩序凝出**【神格】**方可入(85477)。
- **天劫/气运档位**：三九天劫 < 八九天劫 < **九九天劫=必杀之劫**，对应一品~九品气运。**王敦 = 九九天劫 / 九品 / 九龙气运的顶配**(24150,99475)。

**灵根 / 灵力规则**
- 灵根分主修属性、有强弱；太弱则"炼化不及"，灵气再浓也没用(2553)。火灵力品质分中品/上品，越纯越稳(2579)。
- 灵植/丹药分一品~九品，几品灵植炼几品丹(2616)；烈阳花=二品火属性，须稳定火源滋养，修士火灵力优于驳杂的火灵石(2620)。
- 五行相生相克可被反用：树妖以"木生火"诱敌自焚、火不克木(29781)。
- **空灵根**（萧玄）：无形无相、可模拟任意属性灵根(24355)——与王敦的纯力炼体形成对照。
- **替死符**：可代主人死一次的保命至宝，极稀有；王敦仅有两张，送了贺平生一张(23974)。
- **因果符**：可被王敦当二进制位编码（碎=阳/整=阴），底层支撑【王敦密码】全仙界传讯(84462)。

## 政治 / 势力格局

**修真界**
- **太虚门**：分外门/内门，内门在山上各"峰"。**灵药谷**是其下属灵药园，长老**枯木真人**坐镇，下设管事（王敦）+ 供火采粉杂役（贺平生）。后太虚门散，枯木等并入**御兽仙宗**(11722)。
- **齐国**：皇室势力，掌**九龙宝镜**测气运。曾囚禁王敦、被他逃脱并反杀三祖，视他为奇耻大辱(28592)。萧玄/冰极宗属此阵营。
- **室女国**：全女子势力，九国大比时王敦挂靠出战（唯一男选手）。
- 梁国（贺平生方）、九龙宝镜测试、九国大比、神将山秘境、天极绝地（天极神树·时空本源）、真灵谷、乌蒙圣境。

**灵界（天火大陆）**：妖族/神族当道，分诸帝域——朱雀帝城、天佛帝域（明月佛尊）、天昴帝域、大伦帝域（蓝羽帝君/孔雀王）、空空妖帝域。**石台之会 / 石台天梯**=妖帝主办的天骄竞技。

**仙界**：北极紫薇天（混元紫薇神帝）、浮屠仙域（明远/六觉佛帝）、金牛仙域、后土天为有仙域（青莲道君）、中极天（玉瑶公主）。

## 人族双璧的大背景（本传核心母题之一）
- 灵界/仙界由妖、神（凤族/巫族/金乌/空空兽）当道，**人族被普遍轻视**——"人族而已……你又能有什么强大的靠山"(40006)。人族天骄稀少，一度只有许身佛门的明月（成绩气运还归佛门 47925）。
- **石台天梯冲高直接改变整个种族的气运**(47658)，通常需大乘帝境"破壁人"助攀。
- 王敦与贺平生**不靠破壁人**冲到15万丈、压服凤族女帝，凭实力为人族争回气运与脸面，遂被尊为**人族双璧**(48401)。这是王敦"人族扛旗者"身份的根。

## 地理（关键地点速查）
- 修真界：太虚门/灵药谷、齐国定襄郡/定襄城（九龙宝镜）、室女国、神将山、天极绝地、真灵谷。
- 灵界：天火大陆诸帝域、石台天梯。
- 仙界：北极紫薇天、浮屠仙域、金牛仙域、中极天。

## 时间线（关键节点 · 跨度极大）
- 灵药谷岁月（炼气期）→ 龙吟榜第一（筑基）→ 九国大比·替死符（金丹圆满）→ 天极绝地·王敦老祖（元婴八层）→ 砍明月（化神八层）→ 飞升灵界（"快百年了" 38681）→ 空空妖帝囚刑·三梦红尘（炼虚）→ 石台天梯·人族双璧（炼虚·法天象地）→ 飞升仙界·拜入紫薇神帝门下（太乙金仙巅峰·凝道种）→ 重华初遇。
- **跨界之间常隔数十上百年**，原作只在重逢时一句带过——这些断点是本传补全王敦独立线的主场。
