# 角色卡 — 王敦

> 第 2 步主对话填写。基于对原作《仙界闭关小能手》第028–1515章逐字深读。所有结论可按"验证索引"回查原文行号。

## 来源
- 原作：仙界闭关小能手（主角 = 贺平生）
- 模式：parallel（并行外传 · 时间线锁原作硬锚点）
- 视角人称：第三人称限知（贴王敦）

## 外观
- **黝黑、肥胖、矮壮**。首登场"身材肥胖，身穿青色道袍"(2528)；战斗爆体时"黝黑而光滑柔韧的皮肤上浮现火红色纹路"(24171)。
- **招牌白牙憨笑 + 贱兮兮的笑**："黑黝黝的脸膛上露出两排洁白的牙齿"(47665/48693)；"王敦贱兮兮地走出来"(85584)。
- 易容是常态：第204章易容成"络腮胡子的大汉"(11655)；后期得逆天伪装秘术，连混元神帝都看不穿(85716)。本相 = 黑胖矮壮 + 一口白牙 + 痞笑。
- 反差萌：长得憨，却是顶配气运 + 一肚子坏水的天才。

## 出身（含原作留白 → 本传建构空间）
- **明面身份**：太虚门·灵药谷"管事"师兄，炼气期六层，替二品灵药【烈阳花】招主修火灵根的弟子供火、采花粉。灵药谷由长老【枯木真人】坐镇。
- **真实底色（原作已坐实）**：**齐国出逃的"九龙气运 / 九品气运 / 九九天劫"顶配大气运者**。九龙宝镜测出他逆天气运(24284/99475)；他从**齐国皇室监狱层层封锁中逃出**(24285/23856)，齐国为抓他翻遍天下、视他为奇耻大辱(28592)；后**亲手宰了齐国三祖（化神）**(28534)。
- **本传发力的出身留白**：他的家世父母、火+炼体功法师承、为何身负"现代二进制知识"、如何从齐国皇监逃到太虚门当个炼气六层小管事——原作全空白，是本传第一季的悬念引擎。

## 能力体系
- **火 + 炼体（肉身）双修**。火：赤红带白的纯火灵力，火拳/火指/火剑/火镰(24169,48349)。炼体：贺平生看破他"火属性外衣之下其实是纯粹的力量……这厮也是个炼体的，比老子还牛逼"(24215)。
- **功法未命名**（原作不给专名，本传可命名其火功 + 炼体神通；切忌套用贺平生的"离火真法/九毒炼金身"）。武器多变：黑色神枪、金色巨镰、赤红剑、长柄巨斧。
- **隐藏天赋·发明家**：独创**【王敦密码】**——把【因果符】当二进制位（碎=阳、整=阴），编码查"王敦阴阳码表"，实现全仙界即时远程传讯(84462)，是"传讯仙符"的底层。强烈暗示他携现代知识（疑似穿越者，原作未明说→本传可暗写不点破）。
- **气运即金手指即催命符**：九龙气运让他逢凶化吉、屡屡逃生("抓住了老子一溜烟也跑"23966)，也让齐国/各方顶级势力永远在追他。

## 性格底色
**豪爽 + 精明 + 护短 + 贱兮兮搞笑**四味一体，"快意恩仇"是底色(38873)。
- **护短第一**：见师弟被踩，明知打不过炼虚大能也插手——"敢欺负我师弟，老子今儿弄死他"(38687)。
- **精于讲道理/交换/敲诈**：被踩脚下还谈"你今天给我面子，他日还你十个面子"(38694)；反向敲诈破壁人段飞红"在你储物戒指里挑两件宝贝"(47677)。
- **滑头会跑、懂保命**：危难"懂得保存实力，扯呼"(38782)。
- **爱装、爱念豪放诗、享受人气**：冲天梯边冲边吟"须知少年凌云志，曾许人间第一流！我王敦，来了！"(48389)。
- **好色底子 + 真情转向**：早年梦中后宫成群(44528)；遇重华后被师弟包装成"眼中只有大道、从无男女"(85574)，反差萌。

## 动机 / 心结 / 渴望
- **核心渴望**：逍遥、变强、快意恩仇、出人头地；"有朝一日咱们兄弟联手，大大地干一番功业"(38927)。
- **贯穿母题（本传内核）**：顶配气运 = 被全世界盯着的命。他如何与"既是天才又是猎物"的命运相处，是全季内在主线。
- **心结一·枯木真人**：见到枯木"身子一抖，希望这厮进神将山，老子弄死他"(11726)——灵药谷岁月有旧怨，原作只给果不给因（本传发力点）。
- **心结二·被坑黑历史**：屡被蓝羽帝君/孔雀王（大乘帝境第一美人级）坑过，反复念叨"碰到个难缠的女人被坑了"(38805)——recurring 喜剧线。
- **升华**：拜入紫薇神帝门下后，眼中多了"前所未有的自信"(85586)，目标转向证道种、追重华、为师弟撑腰。

## 和原作主角（贺平生）的关系
始终：师弟喊"王师兄"，师兄喊"老弟/师弟"。演变五段：
1. **雇主/招募人**（灵药谷管事招炼气四层的贺平生供火，2530）
2. **同谋小兄弟**（教他偷藏花粉糊弄枯木 2781；借他十万灵石 11668）
3. **生死托底**（逃亡前把仅两张的命根子【替死符】塞给师弟一张，23974）
4. **并肩战友**（天极绝地互救解毒；化神期联手砍明月双臂 38724）
5. **人族双璧**（第822–823章不靠破壁人冲天梯15万丈，被全场高呼，二人并称人族双璧 48401）
> 红线：王敦戏份再亮，**不可盖过/矮化贺平生**，不可改写主线事件，只补"王敦这一侧"。

- 「须知少年凌云志，曾许人间第一流！我王敦，来了！」/「就问你霸气不霸气……我觉得爽就行！」(823章/48389) — 豪放诗+自嗨
