# 第28章 先斩走狗

姜决一头栽进断墙后头，半张脸贴着冰冷的碎石，大口大口地倒气。

他已经数不清，这是今天第几次以为自己要死了。

那柄比门板还宽的骨刀，一晚上擦着他要害划过去七八回，每回都把他从“死”那条线上，硬生生踹回来一寸。

【宿主重伤·气血亏空（危）】

“……我谢谢你啊。”姜决从牙缝里挤出一句，“早干嘛去了。”

废墟另一头，那道庞然的身影正不紧不慢地踏过碎石走来。

钟横。

陇右道叫得上号的鸣骨境，世家养在暗处的一条狗，专替主子做些见不得光的脏活。一身横练的肉，刀砍上去只听“铮”的一声脆响，连道白印都留不下。姜决这一晚上把虎爪、阴影、狼速全堆上去了，砍在他身上跟挠痒痒没两样。

闻弦境越一个大境界去捅鸣骨，本就是拿鸡蛋碰石头。

可姜决偏偏看出了一点别的。

每回他拼着挨一刀、在钟横身上撕开一道口子，那血肉翻卷的伤，眨眼之间就抹平了。不是钟横自己长得快——

是他身后那东西，在喂他。

姜决的目光，越过钟横，钉在十几步外。

一截黑铁锁链从钟横腰间垂下去，另一头，锁着一头通体赤红、形如恶獒的妖。那妖被铁链勒得伏在地上，每当钟横受创，它周身的赤气便顺着链子汩汩涌过去，补进那道伤里。

赤魈。

【探查：目标体内妖力非自生——经血契链由“赤魈”反哺。】

姜决心里那根弦“嗡”地一响。

懂了。

砍钟横，是砍不死的。这跟前世打带奶妈的副本一个道理——你把坦克血条磨到见底，奶妈一个大招又给拉满，气得你想砸键盘。

正解只有一个：先切了那个奶妈。

“老钟。”姜决撑着断墙站起来，晃了晃，咧出一个比哭还难看的笑，“你这身板挺横啊。可惜，是借的。”

钟横脚步一顿。

就这一顿，姜决动了。

他没冲钟横，反而擦着对方身侧，朝那条链子尽头猛扑过去。

【妖化·狼疾】

风从耳边炸开。借来的兽速把他整个人压成一道贴地的黑线。钟横反应再快，鸣骨的力气全使在那柄骨刀上，骨刀回防的弧光从他后心扫过——

姜决吐了口血，硬生生没躲，让那刀背砸在背上，借着这一砸的力，反而扑得更急。

“嘎啊——！”

赤魈察觉到危险，挣着锁链朝他扑来，血口大张。

姜决等的就是它离地。

【妖化·虎躯·虎爪】

四指成钩，金光暴涨。这一爪他没留半分力，连着这一晚上攒下的全部憋屈，狠狠贯进赤魈的咽喉，把这头反哺了钟横一整夜的妖，连皮带肉，按死在碎石里。

赤气炸开，溅了他满脸。

那妖蹬着腿，赤红的瞳孔里凶光飞快地散下去。

濒死了。

姜决眼里一亮——就是这个时候。

【收录——】

识海里，那卷沉寂的百妖谱无声翻开。一道赤红的影，被一寸寸抽进谱里。

【收录已结算·鬼魅谱 2/？】

【境界压制：宿主境界不足，“赤魈”神通封存大半，仅解锁残式——〖夺力·一线〗。】

【妖魔血肉炼为破境血食（少量）入谱。】

残神通。果然，越境收强妖，只能舔到一口汤。

可没等他咂摸这点失落——反噬来了，比以往任何一次都凶。

【警告：妖魂反噬·剧烈。镇压中……】

赤魈那缕新囚的妖魂在他骨头缝里疯狂打滚，又凶又横。可真正让姜决头皮发麻的，不是它。

是更深的地方。

百妖谱最底下那层翻不开的“空格”里，那缕苍老的、陌生的低语，又动了。它没说话，只是极轻地、几乎是欣赏地，往上探了探，像是被这口新血勾醒了馋虫。

——它在等他撑不住的那一刻。

“滚回去。”姜决咬碎一句，七窍渗血，硬是把那两股东西一道道摁回了识海深处。镇压妖魂的熟练度撑住了，那低语悻悻退下，可他知道，收的妖越强，这口缝就裂得越大。

这账，以后再算。

眼下——

他猛地转身。

钟横还愣在原地。他大概一辈子都没想过，自己引以为傲的不死之身，会被一个闻弦境的贱籍，从一条狗身上给拆了。

那道又一次被划开的伤口，这次，没有合拢。

“你……”钟横脸色铁青，骨刀横在身前，第一次现出几分忌惮，“你究竟是什么东西——”

“我？”

姜决抹了把脸上的血，金瞳里那点猩红死死压着，可眼神比刀还稳。

他抬手，掌心赤气流转——那是刚到手、还烫得他虎口发疼的〖夺力·一线〗。

“一个，专吃你们这种借来的力的东西。”

他扑了上去。

这一回，钟横身上每一道伤都老老实实地淌着血，再没人替他填。鸣骨的肉身还横，可一个流着血、回着气、力气一分分往外漏的鸣骨，已经不是那个砍不动的怪物了。

姜决把这一晚上记下的每一处破绽，全砸了进去。

虎啸压步，狼疾抢身，那道残式贴着钟横的脉门，一口一口往外抽他仅剩的妖力——

骨刀脱手。

姜决整个人撞进他怀里，一爪锁住咽喉，跟当初按死虎山神那一下，分毫不差。

“开局收录虎山神。”他贴在钟横耳边，气音破得不成调，“今晚加个餐——收录走狗一条。”

爪尖收紧。

陇右道叫得上号的鸣骨强敌钟横，喉骨碎裂的那一声闷响，消失在废墟的风里。

——

天快亮的时候，裴长青带着援兵赶到。

她踩着满地的妖血和碎石走过来，看着那具庞大的、再不会动弹的尸首，又看看靠墙瘫坐、连根手指都抬不起来的姜决，那张惯常冷硬的脸上，破天荒地裂开一道缝。

“闻弦斩鸣骨。”她蹲下来，声音压得很低，“你知不知道，你今晚捅了多大的篓子。”

“……是好事坏事？”姜决眼皮都懒得抬。

裴长青没答。

她只是极轻地，把自己的外袍解下来，盖在了他身上。

姜决正想嘴一句“队正你这是公器私用”，余光却瞥见远处。

一骑黑衣缇骑，自凉州方向疾驰而来，马上那人高举一支玄色令箭，老远就嘶声喊着两个字——

“都司——有令——”

那令箭上的纹路，姜决不认得。可裴长青认得。

她猛地站起身，脸色变了。

姜决心里咯噔一下。

前世他在公司当了三年透明人，老板连他名字都念不全。如今倒好，在这大唐砍翻一头鸣骨，居然把远在凉州、乃至更上头的某尊大佬，给惊动了。

他望着那支越来越近的令箭，慢悠悠地，在心里补完了一句：

——这下，是真被大人物，盯上了。
