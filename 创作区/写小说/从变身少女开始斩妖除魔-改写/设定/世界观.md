# 世界观 — 《镇魔司：开局收录虎山神》（改写自《从变身少女开始斩妖除魔》）

> 这里写的是**改写后**的现行世界，不是原作世界。底色承原作，金手指/感情线/定位按 新设定.md 覆盖。

## 力量 / 修炼 / 魔法体系（现行）
- **此方世界，武道为尊**（承原作）。境界阶梯（含前境 / 后境 / 圆满子阶）：
  1. **凡境**——搬运气血、熬炼筋骨，武道之始（江湖大多数人止步于此）。
  2. **闻弦**——气血达量，内听己身心跳血流、外闻草木风声鹤唳，**真踏武道门槛**；所修武技越玄妙、气血搬运越快。
  3. **鸣骨**——气血通达四肢百骸、淬炼骨骼发金石嗡鸣，**肉身强横、寻常刀剑难伤**。闻弦→鸣骨极难，**需海量天材地宝或妖魔血肉为引**点燃气血冲关。
  4. *（鸣骨以上为本作扩展·母本未明示，章纲随主角成长逐阶揭示，保持"炼体 + 感官 / 罡气"命名美学，暂拟）*：**易血 → 通窍 → 凝罡 → 蜕凡 → 武圣（陆地神仙）** —— 逐阶解锁，越往上越依赖妖魔血肉 / 天材地宝，主角的百妖谱"破境血食"在此成核心优势。
- **金手指·百妖谱**（详见 新设定.md）：收录即掠夺妖之神通 + 妖化形态 + 破境血食；与"妖魔血肉破境"设定咬合——主角天生"以妖证道"路线。

## 政治 / 势力格局（现行）
- **大唐王朝**：神州大地、王朝治世，但**妖魔横行、食人血肉、祸乱天下**。
- **镇魔司**：朝廷直属镇妖机构，缇骑威慑天下（"登门如阎王、小儿夜不敢啼"）。职级：镇魔卫 < 队正 < 都司 …。主舞台。
- **妖族 / 妖王**：散妖食人，上有结寨成势的妖王（虎山神之流）；人妖之争为大背景长线。
- **世家 / 朝堂**：将门世家（裴长青家族·逼联姻）、获罪官员（主角生父·冤案）等派系，提供权谋与翻案副线。
- **贱籍制度**：获罪没籍者沦为贱籍、可被发配苦役——主角逆袭的最低起点。

## 地理
大唐疆域；开篇 **陇右道**边疆（发配地）。骨架地名承原作：上盘村 / 广武县 / 金城县 / 凉州 / 陇右镇魔都司。按男频路线图重排推进（由边疆小县 → 州府 → 京畿 → 妖王巢穴，层层升级）。

## 时间线（关键节点·暂拟，章纲细化）
1. **荒野觉醒**（第1章）：男主穿成濒死贱籍逃犯，荒野遇未死虎妖 + 重伤女队正裴长青，觉醒百妖谱。
2. **首战收录**（第2–3章）：反杀 / 收录虎山神，得虎啸风雷 + 虎躯，震慑裴长青，"镇魔司来人"留钩。
3. **入司当差**：脱贱籍、入镇魔司，开启"收妖升境界打脸"主循环。
4. **中段支线**：裴长青逼联姻 / 主角搅局；家族冤案线索浮出。
5. **（结局开放）**：收录万妖封神 / 镇魔司登顶 / 人妖终局——章纲后定，为长连载留续航。
