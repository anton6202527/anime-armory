# 读者契约 — 《镇魔司：开局收录虎山神》

> 新版本的题旨与读者承诺。改写中段防丢内核、防偏题材的一号对照。

## 一句话题旨
小人物（现代毒舌魂 × 贱籍逃犯）靠一卷「收录即掠夺」的百妖谱，在妖魔横行、人比妖险的大唐，以妖证道、挣出自己的名分与公道。

## 核心戏剧问题
一个最底层、随时会死的贱籍逃犯，凭一卷有代价的金手指，能不能在镇魔司与朝堂妖谋的夹缝里，把命运从“被押送的死囚”改写成“令妖魔色变的姜大人”？

## 终局必须回答
- 百妖谱的来历与那缕镇压妖魂的低语，到底是什么？
- 主角家族的冤案能否翻案、正名？
- “以妖证道”这条路的尽头（封神 / 登顶 / 人妖之争）走向何方？

## 读者承诺（开篇三章已许诺）
- **收集流爽点**：收录即掠夺妖之神通+妖化形态，一只只收回来、谱系集齐解锁更强（第2-3章已兑现首爽：收录虎山神得虎啸风雷+虎躯）。
- **越阶打脸**：贱籍出身 vs 世家/缇骑/高境界强敌，靠掠夺来的神通越境反杀。
- **金手指有代价、有张力**：妖魂反噬 / 形态上限暴走——爽而不无敌（第2章已埋低语警示）。
- **毒舌爽感**：现代魂的反套路吐槽贯穿始终。
- **轻感情红颜**：与女队正裴长青的并肩与暧昧，点缀不喧宾夺主。

## 文风气质（aesthetic register）
现代爽文腔 + 大唐妖怪背景；短句快节奏，强镜头感战斗，内心 OS 毒舌，章末必留钩。第三人称限制视角（锁姜决）。

## 持续好看的机制（delight engine）
1. 收录新妖 → 解锁新神通/形态 → 越阶打脸 的爽循环。
2. 百妖谱进度 / 谱系完成度可视化，养成+集卡的持续期待。
3. 金手指代价（反噬/暴走）制造“爽点装刹车”的紧张感。
4. “人比妖坏”的朝堂妖谋 + 家族翻案，给爽文一条情感与悬念暗线。

## 禁止偏成（banned drift）
- ❌ 女频甜宠 / 恋爱主线喧宾夺主。
- ❌ 丢掉现代毒舌魂、写成古板正剧腔。
- ❌ 金手指无代价、无限叠形态的无脑无敌。
- ❌ 跑回女主旧设定（变身少女 / 独女 / 女体）。
- ❌ 大段照搬原作原文。
