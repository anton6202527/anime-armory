## 体系（金手指 / 力量 / 修炼）

### 百妖谱（核心金手指·男频"收录即掠夺"升级版）
- **是什么**：主角穿越带来、与魂魄绑定的一卷虚谱（旁人不可见、不可夺）。能将**击杀或重创**的妖怪「**收录**」入谱，录走该妖**毕生神通**与**妖化战斗形态**，并把其妖魔血肉之力炼化为**破境血食**（接母本"妖魔血肉为引方能破境"设定——一鱼两吃：得神通 + 得突破资粮）。
- **规则边界**：
  1. **收录前提**：须先把妖**打到濒死 / 重创**，再发动收录；活蹦乱跳的妖收不了。越完整收录，所得神通越全。
  2. **境界压制解锁**：低境界收录高阶妖，只能录到**残神通 / 封存形态**，须自身境界够才能**完全解锁**——给成长留坡度，防开局无敌。
  3. **妖化形态**：收录所得可外放为战斗变身——**全妖相（虎躯）/ 兽化 / 局部妖化（虎爪·狼速·鳞甲）**，可切换；后期可**多妖融合**（虎躯之力 + 狼之疾 + …）。
  4. **谱系收集**：百妖谱按谱系归类（山君谱 / 风雷谱 / 水泽谱 / 毒瘴谱 / 鬼魅谱…）。**集齐某谱系**解锁该系**更高阶神通 / 融合形态 / 隐藏词条**——收集图鉴流核心爽点；进度可视化（X/Y）。
- **代价限制（命脉·防无敌·用户敲定）**：
  1. **镇压妖魂**：收录即在魂中囚一缕妖魂。**妖越强，妖魂反噬越凶**——侵蚀理智、噩梦、嗜血冲动，镇不住会被妖魂**反夺心识（夺舍风险）**。镇压能力随境界 / 心性 / 百妖谱完成度提升。
  2. **妖化形态上限**：同时可驾驭 / 外放的妖化形态有**数量上限**（随境界与谱系完成度提升）。**超限强行叠加 → 妖化失控 / 暴走**：理智丧失、敌我不分、反噬己身（高风险高回报的"掀桌"底牌，慎用）。
  3. **非全得**：收录不等于即刻全功；高阶神通需对应境界 + 心性 + 谱系条件才逐步开放。
- **首现章·复用**：第1章（觉醒）→ 第2–3章（收录虎山神得虎啸风雷 / 虎躯，黄金三章首爽）→ 全书主线驱动。
- **不可违反点**：①谱与魂绑定、不可被夺；②必须重创才能收录；③代价三条恒成立，**任何爽点都要在代价框架内**——不许写"零代价无限叠形态"。

## 势力 / 组织
### 镇魔司（主舞台·承原作）
朝廷直属、专司镇压妖魔的高压机构。缇骑登门、天下色变。设都司 / 队正 / 镇魔卫等职级。主角由"被押送的贱籍逃犯"→借妖力救场→入司当差→一路升迁扬名（"姜大人"）。

### 妖族 / 妖王势力（新增·章纲细化）
散妖食人为祸，上有结寨成势的**妖王**（如虎山神之流）。百妖谱的"猎物库"与主线冲突源。

### 逼婚世家（新增·绑裴长青支线）
裴长青所出的将门 / 世家，为政治联姻逼其婚配。男主搅局 → 暧昧张力 + 势力冲突钩子。

### 主角родная家族（新增·翻案副线）
主角穿越身体的生父是**获罪官员**，满门牵连没入贱籍。家族冤案 / 翻案为长线副目标，给逆袭一个情感落点（与"脱贱籍→自由身→翻案正名"层层递进）。
