# 改动spec — 《从变身少女开始斩妖除魔》→《镇魔司：开局收录虎山神》

> 这部改写的"宪法"。动笔前与用户敲定。每条要具体可判定，别写空话。

## 一句话改动方向
把「现代**男**魂穿成**少女**、靠百妖谱收妖斩妖逆袭」的故事，改成「现代**男**魂穿成**贱籍男囚**、靠百妖谱『**收录即掠夺妖之神通**』在镇魔司一路逆袭打脸封神」的**男频收集流爽文**。

> 核心判断：母本主角本就是**现代男灵魂**（开篇自述「二十一世纪现代人穿越到陌生女子身上」、内心独白一口「老子」、毒舌社畜口吻），「变身少女」只是把男魂塞进女体当卖点。本次改写=**让男魂直接进男体**，魂、视角、毒舌、金手指、世界观几乎原样复用，只去掉"女体/萌变"这一层，并把感情对象性别对调。低摩擦、贴男频。

## ① 保留的内核（魂，不许丢）
- **主角人设内核**：现代灵魂的**毒舌 / 务实 / 反套路 / 底层小人物视角**——这是母本最活的东西（被老板灌鸡汤、画大饼的吐槽全留），只是从"男魂女体"变"男魂男体"。**丢了这股现代毒舌劲 = 改飞。**
- **情感主线**：与镇魔司那位搭档**从"生死相托"到"并肩捉妖"的羁绊**——保留这条关系弧（押送官差→救命→搭档→暧昧），只把搭档**性别对调为女**。
- **世界观底色 / 基调**：大唐王朝 + 妖魔横行食人 + **镇魔司高压威慑**（缇骑登门如阎王）+ 武道境界 + **诙谐爽**的叙事腔。全留。
- **必须保留的标志性桥段 / 意象**：①开局**荒野·未死的虎妖·插着断刀的镇魔司军官**这场戏的结构与压迫感；②**百妖谱**金手指与「**收录虎山神 / 虎啸风雷**」首战；③**贱籍逃犯→令人色变的"大人"**式草根逆袭爽线；④镇魔司这一主舞台。

## ② 改的部分（事件 / 设定 / 结局）
- **改主角性别**：女（男魂女体·变身少女）→ **男（男魂男体）**。删除"变身成少女 / 萌系少女变身"卖点。
- **改主角身份起点**：原作"京城高官**独女**被没入贱籍、发配边疆" → 改为"获罪官员**之子** / 寒门武者被没入**贱籍**、发配边疆"。★**保留「贱籍逃犯」逆袭起点**★（草根翻身爽感最强）。
- **改金手指机制（升级而非替换）**：百妖谱由"收录妖怪→得神通 / 妖化能力" → 强化为「**收录即掠夺**」：杀 / 收妖即可**录走其毕生神通**，并解锁对应**妖化战斗形态**；新增**收录进度 / 谱系完成度**，集齐某谱系解锁更高阶神通（收集图鉴流核心爽点）。详见 `新设定.md`。
- **改变身机制**：少女萌变 → **男频战斗变身**：妖相 / 兽化 / 局部妖化（虎爪、虎躯、**虎啸风雷**照用），可解锁、切换、后期融合多妖之力。
- **改感情线（1:1 性别对调）**：原男主**裴长青**（陇右镇魔都司**队正**）→ 改为**女队正·裴长青**（御姐、飒、刀子嘴）。关系弧不变（押送官差→男主借妖力自保救场→生死搭档→并肩捉妖→暧昧）。男频**轻感情**、红颜主线**不抢爽点**。
- **改婚配支线**：原作"第19章 不想嫁，那便不嫁"（女主被逼婚）→ 改为**女队正裴长青被家族逼政治联姻、男主搅局**，制造暧昧张力与势力冲突钩子。
- **改题材定位**：女频向 / 女主爽 → **男频爽文**：降感情戏权重，提**成长线 / 收集解锁 / 越境打脸**权重；境界与百妖谱进度可视化作"实力标尺"。
- **改结局走向**：开放，**章纲阶段定**（候选：收录万妖封神 / 镇魔司登顶 / 人妖之争终局；为红果 / 番茄长连载留续航空间）。

## ③ 加的新料（清单；详细体系进 新设定.md）
- **新金手指强化**：百妖谱「掠夺」规则 + 收录进度条 / 谱系完成度 + **妖化形态库**（解锁 / 切换 / 多妖融合）+ 掠夺的**代价 / 上限**（防无敌；男频金手指必写代价）。
- **新势力 / 反派**：章纲阶段细化（镇魔司为主舞台，外加妖族势力 / 朝堂派系 / 逼婚的世家）。

## ④ 禁偏清单（防改飞）
- ❌ 不准写成**女频甜宠 / 恋爱主线**——感情是点缀，爽点是主线。
- ❌ 不准丢**现代男魂的毒舌反套路腔**——那是母本的魂。
- ❌ 百妖谱「收录即掠夺」规则**前后不能自相矛盾**（掠夺条件、代价、上限一次定死，进 `新设定.md` 一致性追踪）。
- ❌ 不准**大段照搬原作原文**——原作只是参考素材，逐句重写（派生作品法律边界）。
- ❌ 不准**跑回女主旧设定**（变身少女、独女、女体细节）。
