# Ad Production Line (拍广告)

This directory contains all advertising projects. Each project should follow the standard `ad-*` workflow.

## Project Structure

Each project directory (`拍广告/<project_name>/`) typically contains:
- `_进度.md`: Status tracking for the project.
- `_设置.md`: Project-specific settings (private, not committed).
- `需求/`: Client briefs and requirements.
- `脚本/`: Scripts, storyboards, and legal checks.
- `配音/`: Voiceover assets.
- `出图/`: Image generation assets.
- `出视频/`: Video generation assets.
- `合成/`: Final composition and delivery files.

## Production Workflow

1. **Brief/Concept:** `/ad` to initialize and brainstorm.
2. **Scripting:** `/ad-script` for scripting and Ad-Law compliance.
3. **Voice/Image/Video:** Iterative asset production.
4. **Compose/Review:** Final assembly and quality check.
