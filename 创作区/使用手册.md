# 创作区使用手册

本目录按作品类型分成六条生产线。用户不需要背命令，直接说明目标、作品名、已有素材和约束即可；AI agent 会读对应作品的 `_进度.md` 和 `_设置.md` 后继续推进。

| 想做 | 目录 | 入口 skill | 示例项目 |
|---|---|---|---|
| 写小说、改稿、审稿、评分、导出 | `写小说/` | `novel` | `写小说/金睛缉妖录` |
| 小说改 AI 漫剧/短剧 | `制漫剧/` | `n2d` | `制漫剧/那妖魔是姜大人` |
| 画条漫/页漫/漫画长图 | `画漫画/` | `comic` | `画漫画/那妖魔是姜大人` |
| 写歌、改词、作曲、挑版 | `写歌/` | `song` | `写歌/仗剑下山` |
| 给歌曲做 MV | `制MV/` | `mv` | `制MV/仗剑下山` |
| 拍广告片/TVC/产品 demo | `拍广告/` | `ad` | `拍广告/星盒手账App` |

## 通用规则

- 继续旧项目：先说“继续 `创作区/.../<项目名>`”，agent 会先读 `_进度.md`。
- 新建项目：说清楚“我要写/做/拍什么”，agent 会建作品根并初始化 `_设置.md`。
- 花钱或不可逆步骤：出图、出视频、云端作曲、商用授权等需要单独确认。
- 只查状态：说“看进度 / 下一步”，会走对应 `*-progress`，不改文件。
- 返工：不要直接改最终成片或导出物，优先回源头阶段改，再重跑下游。

## Demo 快速试用

```text
看一下 创作区/写小说/金睛缉妖录 现在还能做什么。
继续 创作区/制漫剧/那妖魔是姜大人 第3集，先不要花钱，告诉我下一步。
把 创作区/画漫画/那妖魔是姜大人 第2话 做发布前检查。
继续 写歌/仗剑下山，给正式整首歌做下一步计划。
检查 制MV/仗剑下山 为什么还不能当正式版发布。
继续 拍广告/星盒手账App，先走零成本 demo 通道。
```

各系列的更具体用法见对应目录下的 `使用手册.md`。
