# 写歌使用手册

入口 skill：`song`。产物放在 `创作区/写歌/<曲名>/`。适合从主题写歌、改词、作曲、生成多版、挑版、翻唱/换声和质检。

## 你可以这样说

| 场景 | 直接说 |
|---|---|
| 从零写歌 | “写一首国风武侠歌，适合抖音 60 秒。” |
| 改词 | “这首歌副歌不够抓人，帮我改 hook。” |
| 歌词体检 | “检查歌词押韵、结构和可唱性。” |
| 作曲 | “按这份 lyrics.md 生成作曲任务包，准备多版挑版。” |
| 挑版 | “登记这些 takes，帮我比较哪版适合做 MV。” |
| 换声 | “用授权音色翻唱，不要克隆真人歌手。” |
| 交给 MV | “把正式 song.wav 和 lyrics.md 交给制MV。” |

## 推荐流程

1. 立项：确定歌曲用途、语言、时长、曲风、BPM/速度、目标平台。
2. 作词：产 `词/lyrics.md`，结构化为 verse/chorus/bridge。
3. 歌词体检：先拦结构弱、押韵弱、hook 弱。
4. 作曲任务包：生成 prompt、曲风说明和 takes_manifest。
5. 多版生成：Suno/Udio/ACE-Step 等外部或本地后端生成后登记。
6. 挑版定稿：试听评分，写入 `歌/song.wav`。
7. 可选换声：只用自有、授权或合成音色。
8. 质检/披露：补 AI 音频使用说明，发布前检查版权。

## Demo

已有项目：`创作区/写歌/仗剑下山`。

可试：

```text
继续 创作区/写歌/仗剑下山，规划正式整首歌怎么从 20s demo 升级。
```

这个 demo 已有定稿歌词和 20s ACE-Step 真唱，适合学习“短 demo 歌如何交给 MV，又如何规划正式整首歌”。

## 避坑

- TTS 只能说话，不能当作唱歌模型。
- 音乐生成方差大，不要一版定稿，至少多版挑版。
- 未授权真人歌手嗓音不能克隆。
- 交给 MV 前必须明确这是 demo 歌还是正式整首歌。
