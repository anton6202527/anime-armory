# 那妖魔是姜大人_第1集_分镜剧本

## 本集导演意图

- 集名：百妖谱
- 时长规划：约 88 秒（原生音画脚本时长）
- 核心看点：现代人穿越尸场，发现“斩杀生物得道行”的百妖谱后，为活命刺杀唯一还活着的裴长青。
- 视觉基调：冷灰写实3D国风漫剧；荒野尸场压迫，百妖谱金光只在系统触发后出现。
- 空间轴线：姜月初位于画面左/前景，裴长青位于画面右/近中景，虎山神在远景巨岩方向；所有反打守“姜月初/裴长青 ↔ 虎山神”的斜向轴线。

## 镜头 1（0:00-0:03）
**画面视觉描述：** ECU，姜月初猛然睁眼，脸侧压着枯草和血尘，瞳孔收缩；冷灰月光从画左上擦过，前景虚焦是囚服尸骸手指。固定镜头，极浅景深，静音也能读出“死人堆醒来”。  
**台词 / 音效 / 旁白：** 姜月初（惊醒）：“谁把我扔进死人堆里？” | 烧屏字：刚穿越就躺进死人堆，她今晚还能活下来吗？ | 音效：血风贴耳，低频心跳。  
**衔接：** 她抬眼扫视，切到荒野全景建制镜头。

## 镜头 2（0:03-0:06）
**画面视觉描述：** ELS→LS缓慢推近，荒野尸骸战场全貌：枯草连天，囚服尸骸散落，远处巨岩旁有巨大黑影；姜月初小小地坐在尸堆边。  
**台词 / 音效 / 旁白：** 旁白（低沉）：“三分钟前，她还是二十一世纪普通人。现在，身下不是床，是大唐荒野的尸堆。”  
**衔接：** 推近到姜月初低头看囚服。

## 镜头 3（0:06-0:09）
**画面视觉描述：** MCU，姜月初低头捏起灰褐囚服衣襟，手指发抖；镜头轻微下摇到麻绳腰束，再回到她惊疑的脸。  
**台词 / 音效 / 旁白：** 姜月初（茫然）：“囚服？我穿越成犯人了？”  
**衔接：** 她视线向远处巨岩一顿，eyeline cut。

## 镜头 4（0:09-0:14）
**画面视觉描述：** LS，远处虎首人身妖魔斜倚巨岩，胸口黑血窟窿仍在滴落；前景是黑衣赤纹镇魔司尸身局部，形成冷灰三层纵深。  
**台词 / 音效 / 旁白：** 旁白（压低）：“大唐，妖魔横行。她这具身体正被发配边疆；镇魔司一到，便是阎王爷敲门。” 旁白（惊惧）：“尸骸尽头，一头虎首人身的妖魔倚着巨岩，胸口破开黑洞，妖血淌了一地。”  
**衔接：** 黑血滴落声做 J-cut，切回姜月初。

## 镜头 5（0:14-0:18）
**画面视觉描述：** CU，姜月初屏息，眼神从虎妖尸身移到画右；背景虚焦里裴长青半跪撑断刀。轻微推近制造被盯上的压迫。  
**台词 / 音效 / 旁白：** 姜月初（屏息）：“死的...还好，是死的。” 裴长青（沙哑）：“过来。”  
**衔接：** 姜月初僵住，硬切到断刀飞来。

## 镜头 6（0:18-0:25）
**画面视觉描述：** 加速碎切。MS，姜月初后退半步；CU，半截断刀“咻”地钉在她脚前；MCU，裴长青惨白抬眼，浑身是伤，左臂不自然地扭曲着，黑衣赤纹战损。正反打守轴线：裴在画右看向画左，姜在画左看向画右。  
**台词 / 音效 / 旁白：** 姜月初（戒备）：“你都快死了，还能管我？” 旁白（紧张）：“半截断刀破风而来，钉在她脚前半步。” 裴长青（虚弱冷硬）：“镇魔司，裴长青。扶我往南，我必须把虎妖消息带回去。没有户籍路引，你逃到下一座城也活不了。”  
**衔接：** 姜月初低头看刀，再看裴长青，接她被迫妥协。

## 镜头 7（0:25-0:33）
**画面视觉描述：** MS→LS，姜月初咬牙把裴长青右臂搭到肩上，二人踉跄向画左南向移动；裴高大重伤压在她肩上，她脚步被拖得一晃。  
**台词 / 音效 / 旁白：** 姜月初（憋怒）：“这饼，画得比我前老板还圆。” 姜月初（压住恐惧）：“...行。你别把刀往我脸上丢。你若起了杀心，我这颗脑袋也没几分热气。”  
**衔接：** 二人刚走出几步，身后湿咳声 J-cut 先入。

## 镜头 8（0:33-0:42）
**画面视觉描述：** reveal reaction chain。先 CU 姜月初手一松，裴长青摔地；再低机位 LS，巨岩旁虎山神从“尸身”缓慢站起，胸口黑血窟窿仍在，但金黄凶眼亮起；反打裴长青脸色血色尽褪。  
**台词 / 音效 / 旁白：** 旁白（惊惧）：“她架起裴长青。没走几步，死透的虎妖竟然咳了一声。” 虎山神（戏谑）：“别跑了。荒郊野岭的，你们能跑去哪儿？” 裴长青（骇然）：“不可能...我明明斩穿了你的心。”  
**衔接：** 虎妖咧嘴，低频妖气盖住风声，接裴长青最后一扑。

## 镜头 9（0:42-0:51）
**画面视觉描述：** fight exchange。MS，裴长青捡起横刀，强行起身；快切到他扑向虎妖；CU 命中失败：虎妖右腿后发先至，蹬中裴胸口；MS，裴长青倒飞砸在姜月初脚边，尘土扑面。  
**台词 / 音效 / 旁白：** 虎山神（轻蔑）：“队正大人，你那一刀，只差一点。为了看你们认命，我可以慢慢等。” 裴长青（暴喝）：“走！” 旁白（急促）：“横刀劈下。虎妖一脚蹬出，裴长青倒飞回来，砸在姜月初脚边。”  
**衔接：** 裴落地的尘土遮挡切到姜月初脸部绝望特写。

## 镜头 10（0:51-0:59）
**画面视觉描述：** CU→POV，姜月初脸上尘土和冷汗，随后她视野里金色古卷光幕缓慢展开；面板只显示空光幕底框和符纹，文字数值由后期 overlay。  
**台词 / 音效 / 旁白：** 姜月初（绝望）：“刚穿越就死？我能排进番茄最拉胯穿越者榜单了。” 系统（冷静）：“百妖谱第一次开启。宿主：姜月初。境界：凡境。武学：无。道行：零。”  
**衔接：** 金光映到她瞳孔，match cut 到面板规则特写。

## 镜头 11（0:59-1:07）
**画面视觉描述：** system panel。过肩主观镜，金色百妖谱空面板稳定悬浮，内部留空给 overlay；下半幅是姜月初颤抖的手摸到横刀刀柄。镜头慢推到她眼神变化。  
**台词 / 音效 / 旁白：** 系统（冷静）：“斩杀生物，可得道行。以妖血为墨，可摹其形，夺其神通。” 姜月初（低声盘算）：“活着的生物...”  
**衔接：** 她视线从虎妖移到脚边裴长青，eyeline cut。

## 镜头 12（1:07-1:15）
**画面视觉描述：** 加速反打。虎妖远景逼近却仍不急；裴长青在姜月初脚边只剩一口气；姜月初握刀，手臂发抖，刀尖从地面慢慢抬起。  
**台词 / 音效 / 旁白：** 虎山神（嘲弄）：“小丫头，你还想拿刀？” 旁白（压迫）：“荒野上，虎妖活着。裴长青，也还剩一口气。她唯一能杀的活物，也许就在脚边。”  
**衔接：** 刀身反光划过姜月初眼睛，硬切到她低声道歉。

## 镜头 13（1:15-1:22）
**画面视觉描述：** fight exchange / 关系断点。ECU 姜月初嘴唇发颤说“抱歉”；CU 裴长青困惑抬眼；手部特写，横刀短促刺下，画面只给刀柄推进和裴长青瞳孔僵住，避免猎奇血腥。  
**台词 / 音效 / 旁白：** 姜月初（发颤）：“抱歉。” 裴长青（迟疑）：“什么？” 旁白（骤冷）：“长刀入胸，裴长青的眼神猛地僵住。”  
**衔接：** 入肉声后抽掉 BGM，只留风声和心跳。

## 镜头 14（1:22-1:28）
**画面视觉描述：** CU 定格，姜月初低头，半张脸被黑发遮住，百妖谱金光在眼底轻颤；前景是横刀刀柄，背景虎山神的巨大阴影停住。缓慢推近到她眼睛。  
**台词 / 音效 / 旁白：** 姜月初（低哑）：“我只想活下去。”  
**衔接：** 集尾硬断，低频悬停，不给结果。
