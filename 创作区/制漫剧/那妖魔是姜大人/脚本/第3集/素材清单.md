# 第3集 素材清单

## 角色
- CHAR_01 姜月初：既有脸锚 + 新镇魔司伪装态（黑衣赤纹、束发、横刀挂腰）
- CHAR_02 裴长青：既有遗体态，仅欠命象征，不复活。
- CHAR_04 陈青源：新角色，虬髯中年飞鹰门门主，火光下急迫恭敬。
- GROUP_飞鹰门马队：群体剪影/火把/马匹，不追清晰多脸。

## 场景
- LOC_01 荒野尸骸战场：第2集连续，浅坑/遗体/冷灰月夜。
- LOC_02 荒野官道夜路：新场景，官道纵深、冷月、火把马队。

## 道具 / VFX
- WEAPON_01 横刀：既有武器，Clip03 起挂姜月初腰侧。
- PROP_镇魔司黑衣赤纹：新服装变体，赤纹为图案不是文字。
- PROP_尸场物资包：银子、肉脯、水囊、衣服边角。
- MOUNT_GROUP_01 飞鹰门马匹与火把：马队、缰绳、鞍具、火把点阵；可拆成局部锚。

## 生成策略
- 每 Clip 默认 first/mid/end；Clip05 为马队高动态，使用 a1/a2/a3 多锚。
- 视频阶段无声 Image2Video；若后端产生音轨，一律丢弃。
- 文字/字幕全部后期 overlay，不让视频模型烤字。
