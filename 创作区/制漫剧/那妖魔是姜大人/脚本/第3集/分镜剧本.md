# 那妖魔是姜大人_第3集_分镜剧本

## 导演总则

- 单集约 81.1 秒，主看点是「偷穿制服求生→假身份真唬住人→成功立即反噬成救村死局」。
- 官道行动轴固定：马队画左后冲入，姜月初画右前迎向；陈青源与群众跪拜均朝画右前。
- 冷开群跪只给结果，不解释制服来历；EP03_CLIP07 以同构图闭合时间线。
- 埋尸、狼妖屠村只拍因果和反应，不做尸体、伤口与残害闪回。
- 黑底赤纹制服是唯一高饱和制度符号；全集不出现百妖谱金光、妖化或系统面板。

## 分镜验收要点

1. EP03_CLIP01 与 EP03_CLIP07 必须同构图：群众在画左后/中景跪拜，姜月初在画右前；前者保留原因悬念，后者给出求救因果。
2. EP03_CLIP03 换装后，黑底赤纹制服、束发和腰间横刀必须持续到集尾，不得回退到囚服或更换发型。
3. EP03_CLIP05 马队只有沿道路纵深冲近和勒马急停一条主动作；马匹保持乘骑接触与重量，不做环绕运镜。
4. EP03_CLIP06 沉默是表演主体：姜月初不直视镜头，只看戏内的陈青源；内心声全部不露口型。
5. EP03_CLIP07 禁止用狼妖屠村闪回消费惨状；“百十条人命”由跪地群众和她的反应承担。
