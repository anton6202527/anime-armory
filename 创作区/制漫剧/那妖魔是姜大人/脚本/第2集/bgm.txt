# 那妖魔是姜大人_第2集_BGM与音效

整体情绪：杀人后的道德失重 → 虎爪压顶的求生倒计时 → 二十年道行一刀爆发 → 斩虎后的死寂 → 百妖谱收录的诡异神圣感 → 获得圆满刀法的克制回报 → 对“摹影进阶”的不安悬断。

BGM风格：延续第1集冷灰暗黑国风母题；低音大提琴持续音、埙气声、稀疏战鼓与刀锋金属泛音。道行灌注时加入逐层收紧的皮鼓和反向弦音；斩击只在命中点给一次低频重击。百妖谱采用古卷摩擦、墨滴入水与极克制暖金钟磬，不做游戏升级铃声。

关键音效点：
- 镜头1：刀从胸口拔出的短促湿响后立刻压低环境声；姜月初呼吸、手抖与远处荒风清晰可闻。
- 镜头3：“二十年”落字时一记低频心跳，虎妖脚步仍在画外逼近，信息回报不暂停危险。
- 镜头5–7：虎爪破风 → 战鼓两次加速 → “斩”字前抽真空 0.15 秒 → 刀刃与爪风交错的尖锐擦响 → 虎首落地闷响；命中与 BGM drop 同帧。
- 镜头8：保留约 1 秒无音乐留白，只听喘息、血滴与枯草风声。
- 镜头9：“一百年”用比首次结算更深的低频重音，形成数值反转。
- 镜头10–13：古卷展开、墨线游走、虎啸由远及近又被卷入纸面；“圆满”出现时金属泛音上扬后立即收束。
- 镜头15：面板三项信息用三次轻微墨点声，不逐字配廉价提示音。
- 镜头16–17：BGM只留埙的残气和一根低弦，给道德余震留空间。
- 镜头18：“下一步”后虎影双眼短亮，极低虎啸反向播放，切黑。

卡点原则：第1次二十年到账是“生机”，斩虎是“动作兑现”，百年到账是“数值反转”，圆满刀法是“成长兑现”；四个重音层级递增，但结尾不做英雄凯旋，保留借妖之力的隐患。
