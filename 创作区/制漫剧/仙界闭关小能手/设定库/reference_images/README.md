# 定型参考图说明

本目录保存用户指定的男女主定型参考图。它们是身份和风格参考，不是直接成片截图。

## 使用规则

- 参考图用于锁定脸型、五官比例、眼神、气质和整体半写实 3D 国风仙侠漫剧风格。
- 不得继承截图里的播放按钮、搜索框、字幕、话题标签、水印、平台 UI 或录屏边框。
- 贺平生第 1 集是 14 岁少年杂役态，不能直接使用成年觉醒态外观；应从 `CHAR_HE_PINGSHENG_定型参考_成年觉醒态.png` 的脸部 DNA 年轻化派生。
- 女主姓名待剧情确认；确认后把 `CHAR_FEMALE_LEAD` 绑定到具体角色卡，并保留同一参考 lineage。
- 所有少年态、成年态、觉醒态、高阶态、受伤态都必须写 `reference_lineage`，不能无账换脸。
