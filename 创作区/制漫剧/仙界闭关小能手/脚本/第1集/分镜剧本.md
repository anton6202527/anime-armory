# 仙界闭关小能手_第1集_分镜剧本

制作模式：先出视频后配音。当前时长来自 `say` 占位/估算轨，只用于先推进无声视频；真实配音在出视频后补，若溢出优先压缩旁白或局部重定时，不拉长低优先级画面。

视觉风格：半写实3D国风仙侠漫剧，冷灰底层仙门环境 + 克制暖金奇物微光。禁止继承参考截图 UI、播放按钮、搜索框、字幕、水印、平台竖字。贺平生第1集为14岁少年杂役态，只从成年定型参考继承脸部 DNA，不出现成年觉醒金纹、血迹或华服。

总时长：58.967s。主时长给黑殿羞辱、挑水死令、挑水压迫和夜潭破盆；背景信息只给 3.003s 快闪。

## EP01_CLIP01 黑殿围审与费钱货羞辱
- 时长：19.573s
- 节奏角色：冷开场主钩 / primary
- 镜头意图：先定场黑暗杂役大殿，贺平生站在画面中下方，被群杂役半圆围住；张老大在中上高位俯视。前3秒无声也要读懂“少年被围审”。
- 景别与运镜：MS 定场 → CU 贺平生低头 → 张老大嘴角轻蔑反打 → 群杂役哄笑压画面。
- 表演重点：贺平生低头但眼神没散；张老大像习惯压人的杂役头目；群笑不要拍成长段，费钱货落点一出即切。
- 衔接：尾帧为群笑压向贺平生，张老大的命令声接入下一镜水缸。

## EP01_CLIP02 张老大落下挑水死令
- 时长：9.760s
- 节奏角色：主线任务落点 / primary
- 镜头意图：把羞辱变成身体任务。水缸和扁担先入画，张老大的命令随道具压到贺平生身上。
- 景别与运镜：CU 水缸边缘 → 张老大手势 → 扁担横穿画面 → LS 贺平生接下苦差。
- 表演重点：贺平生抬眼一瞬又压回去；张老大不咆哮，只用命令和近身压迫。
- 衔接：尾帧扁担压到肩上，匹配剪到下一镜破旧包袱带被攥紧。

## EP01_CLIP03 身世与杂役处境四秒快闪
- 时长：3.003s
- 节奏角色：背景一笔带过 / low
- 镜头意图：只交代“无处可退”，不展开父母死亡或杂役生活长段。
- 景别与运镜：三枚快闪：破旧包袱、空房粗饭、两口水缸。每帧只承载一个信息点。
- 表演重点：贺平生握紧包袱带即可，不给长哭戏。
- 衔接：空间跳转到夜路，用空镜缓冲，不用尾帧接力。

## EP01_CLIP04 贺平生主动提前认路
- 时长：2.960s
- 节奏角色：主角主动性 / primary
- 镜头意图：一句自语 + 一个动作，把他从被动受害者推成主动求生的人。
- 景别与运镜：夜路 LS，贺平生背空桶出门；听见远处笑声停半拍，继续向后山走。
- 表演重点：停顿不能软，停完继续走，表现谨慎和韧劲。
- 衔接：尾帧脚步踩进碎石，动作切到挑水蒙太奇。

## EP01_CLIP05 挑水压迫蒙太奇
- 时长：7.099s
- 节奏角色：身体压迫高光 / highlight
- 镜头意图：不拍完整二十趟，只拍最疼的三处，让观众感到他撑到极限。
- 景别与运镜：CU 肩背被扁担压红 → CU 水桶溢出 → CU 脚步打滑 → MS 第五趟抵达水边。
- 表演重点：手指发白、咬牙、喘息压低；不要拍成风景长镜。
- 衔接：尾帧脚下一滑低头看水，视线切到下一镜潭底微光。

## EP01_CLIP06 夜潭黑陶破盆微光硬断
- 时长：16.572s
- 节奏角色：集尾钩子高光 / highlight
- 镜头意图：观众先看见异常，主角后看见；主角误判“破盆”，观众看到它不普通。
- 景别与运镜：CU 水面微光 → 指尖入水 → 黑陶破盆边缘露出 → 贺平生疲惫失笑 → ECU 盆底微光硬断。
- 表演重点：贺平生不能提前知道宝物用途；他的反应是疲惫、务实、误判。
- VFX：暖金微光只在盆底一线出现，不扩散成法阵，不提前神器化。
- 衔接：最终 cliffhanger 定格，无下一 Clip 尾帧接力。第2集冷开场必须兑现清水变碧绿。
