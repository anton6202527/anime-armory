# 仙界闭关小能手_第3集_封面/首图

## 封面卖点
- 标题建议：`破盆一夜，劣米成金`
- 视觉钩：昏暗杂役小屋里，黑陶破盆盛满金灿灿极品灵米；十四岁的贺平生俯身看向盆中，震惊又急忙压住表情，门外有拍门阴影逼近。
- 情绪：发财/机缘的爽点与“马上会被发现”的危机同框。
- 留白：上方和右侧留标题区，底部留短字卡区。
