# 仙界闭关小能手 — P-1 试播打样绿灯

## 打样范围
- 第 1 集完整文字链路：剧本改编、分镜、素材清单、定妆图提示、视频 clip 规划。
- 第 1-3 集剧情链路：确认破盆从“捡到”到“金米显影”的递进不拖沓。
- 高风险媒体先打样：贺平生 14 岁少年杂役态、夜潭破盆、金米显影、参考图风格一致性。

## 绿灯标准
- 剧本追更承诺成立：第 1 集结尾必须留下“破盆是不是宝物”的问题，第 3 集必须兑现为金米反转。
- 主角定妆稳定：贺平生 14 岁少年态与成年觉醒参考图共享脸部 DNA，但服装、年龄、特效强度按剧情阶段变化。
- 风格稳定：半写实 3D 国风仙侠、金色符纹/法阵语言可用；截图 UI 和平台字样不得出现。
- 声音/字幕路线可执行：内部阶段允许 say 占位；正式阶段再替换中文角色音色并重算时长。
- 成本可控：过渡镜头短 clip，主预算给定妆、破盆、金米、战斗/法术奇观。
- review-ui / score / dashboard 不得有身份漂移、主干缺失、非关键长 clip、合规授权阻断。

## 小批量放量条件
- 第 1 集文字 gate 通过后，先做第 1 集关键图和视频高风险 clip。
- 第 1-3 集剧本连贯性确认后，再推进第 2-3 集图像和视频。
- 第 1-3 集通过后扩到第 4-10 集；每批都在剧本紧凑性、身份一致性、合规清单和视频 QC gate 停审。
