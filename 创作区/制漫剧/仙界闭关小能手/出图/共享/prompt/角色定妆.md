# 角色定妆

所有角色定妆继承本剧 `identity_registry.json`，先出共享定妆，再派生分镜图。
**统一风格锚**：`出图/共享/图片/风格锚_国漫写实.png`（登记在 `出图/共享/style_anchor_registry.json`）。
