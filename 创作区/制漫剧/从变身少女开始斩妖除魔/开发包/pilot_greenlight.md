# 从变身少女开始斩妖除魔 — P-1 试播打样绿灯

> 结论：文本开发条件绿灯；付费图片、视频与声音生成红灯。解除媒体红灯需要源文本/改编权证据、P-1人工签收和首批边界签收。

## 打样范围

- 第1集走完整文字→分镜→声音→图片→视频→合成→验收链路。
- 第1–3集先完成文字链路，用于验证“道德债—冒名—救村”追更弧。
- 单独打样百妖谱激活、姜月初常态/妖化身份差分、朱厌尺度与血雾动作三个高风险视觉合同。
- 先打样，不批量生成819章或830集；长篇按3集一批放量。

## 开跑前阻断项

1. 用户确认自己是作者/权利人，或提供覆盖本项目用途的改编授权与既有漫剧权利边界说明。
2. 开发包/signoff.json 获得创意组与制片组对当前文件哈希的人工签收。
3. 脚本/_拆集复核.md 的建议第1–10集边界获人工签收，再重建正式 raw；不能让新 split_plan 与旧 raw 混用。
4. 确认生图/生视频后端与重抽预算；当日核验官方能力和最小 smoke。
5. 外部参考保持 analysis_only；除非另有明确授权，永不作为后端附件。

## 绿灯标准

- 剧本：前3秒有问题；第1集兑现穿越死局、道德债、斩虎与妖谱首次录入；集尾有可复述追更问题。
- 边界：建议10集映射与来源章号经人工签收；单集 table read 落在150–210秒候选区间，超出则回剪内容，不加速念白。
- 角色：姜月初常态与妖化态分别完成 core_full 五角、turnaround、服装锚、脸锚和当前像素收据。
- 视觉：黑赤镇魔·水墨妖谱六字段合同贯穿 storyboard、图片总览与视频合同；常态现实域与妖谱子风格不混用。
- 动作：横刀、轴线、接触点、起落和伤势后果清楚；多主体难镜用身份槽与分层构建，不删剧情。
- 声音：姜月初外显十八岁女性声线但表演冷静克制；无真人克隆；最终合成前替换所有占位音。
- 合规：源文本/改编权可放行；用户参考权利与附件用途可审计；同 IP 高去重；无水印、Logo或竞品复制。
- 技术：后端能力证据为当日；预算上限已设；runner 预付费 gate 无 BLOCK；图片、视频和最终 review 均无核心阻断。

## 小批量放量条件

1. 第1集完整成片和P0高风险样片全部通过。
2. 第1–3集文字追更弧通过 table read 与人工剧本签收。
3. 下一批只推进第2–4集；之后每次最多3集。
4. 每批在 script、image_preflight、image、video_preflight、video、compose、review 留审点；任一主角身份、权利、力量规则或边界哈希漂移立即停批。
5. split_plan 长篇索引压缩已完成：schema v3 计划约 3.31 MiB，迁移前后生产语义及现有 raw 均一致；后续生成器必须继续默认 compact v3，禁止退回逐单元复制正文的 v2，旧版仅保留为可回滚压缩备份。
