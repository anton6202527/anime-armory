# 从变身少女开始斩妖除魔 — P-1 剧集开发圣经

> 内容已补齐，状态 confirmed 只表示可供创意/制片签收，不代表已经取得改编权，也不代替 开发包/signoff.json 的人工签收。

## 一句话卖点

一个现代男人被困进十八岁罪臣之女的身体，为活命杀死镇魔卫夺得第一笔道行，从此以黑衣横刀和“妖血为墨”的百妖谱在大唐边塞斩妖升级；她每一次变强，都在追问自己究竟要成为怎样的“姜大人”。

## 项目形态

- 竖屏 9:16 国漫写实漫剧。
- 长篇量产，先做第1–10集试播窗口，对应原著第1–18章；第19–20章留作下一窗口开场，避免把超长第18章与身体/营内冲突硬塞进同集。
- 单集候选时长 150–210 秒；以剧本 table read 后的真实语速和镜头负荷校准，不用原文字数硬塞。
- 当前用途 internal_only；目标平台、发行地区、付费模式和最终时长在权利确认及 P-1 签收后锁定。

## 目标受众

- 核心：16–35 岁，偏好女强成长、变身/性别错位、志怪斩妖、系统升级、机构成长与悬疑身世的中文竖屏观众。
- 次核心：喜欢写实国漫角色、电影化镜头和水墨志怪特效，但不希望整剧变成仙侠页游或静态海报的观众。
- 内容承诺：先兑现选择与代价，再给升级与反杀；爽点不抹平人物道德阴影。

## 主角欲望

- 外在：活下去，摆脱贱籍/逃犯身份，获得可自主选择的身份和力量。
- 内在：面对杀裴长青求生留下的道德债，并在男性意识与女性身体、婚嫁秩序之间建立新的自我。
- 首批弧：从只顾个人逃命，到回头救村、协战金城、以受约束的方式加入镇魔司。

## 长线悬念

1. 姜家为何获罪，为什么由镇魔司押送，魏合知道多少。
2. 百妖谱从何而来，道行与妖物反馈的边界是什么。
3. 裴长青之死和冒用身份何时反噬。
4. 姜月初如何理解并选择现在的身体、身份与关系。
5. 她在镇魔司成长后，是成为秩序的一部分，还是改写秩序。

## 世界观规则

- 妖祸笼罩的大唐边塞；镇魔司是对妖武装与调查机构，黑衣赤纹形成稳定视觉识别。
- 早期境界为凡境→闻弦→鸣骨→成丹；后续只按源书增量登记。
- 斩杀可得道行，道行只能投入武学或百妖谱中的明确去向，不能重复消费。
- 百妖谱以妖血为墨，依次表现摹影→染朱→点睛；妖物才可反馈武学、天赋或神通。
- 虎妖化必须在点睛虎山神后出现；解除后红发、金色竖瞳和赤色虎纹全部复原。
- 重伤、力竭、武器损坏、服装污损和能力代价必须跨镜承接。

## 核心爽感

1. 求生抉择：主角在最差选择中抢回主动权，而非无条件被奖励。
2. 妖谱升级：妖血如墨、摹影、染朱、点睛形成可重复又可升级的视听仪式。
3. 以弱胜强：横刀近战、伤势与环境共同决定胜负，先建立威胁再反杀。
4. 身份反转：逃犯冒充镇魔卫，最终被识破却以实力与选择争取入司。
5. 机构打脸：进入玄字营后在质疑中用行动立足，但不靠旁白宣布无敌。
6. 身体错位：现代男性思维与女性身体/社会规训产生克制、非低俗的戏剧反差。

## 关键角色弧

- 姜月初：求生者→背负选择后果的救人者→受约束入司的新镇魔卫。缺陷是自利、嘴硬、习惯先算收益；成长不是变圣人，而是愿意为选择负责。
- 裴长青：短线人物，却同时承担力量来源、制服来源、身份风险与道德债，不能被改成主动献祭。
- 魏合：从审视危险变量到把姜月初纳入可控秩序；权威来自判断与克制，不靠华丽造型。
- 刘沉：以真正镇魔卫的视角见证姜月初从可疑冒名者变成战场同伴。
- 魏清：提供组织内的人情与身体照料视角，和姜月初形成温婉/冷硬、素白/黑赤的视觉与性格区分。

## 视觉与声音主张

- 基础：国漫写实角色审美 + 电影级布光与镜头语言。
- 项目子风格：黑赤镇魔·水墨妖谱。常态是冷灰、土褐、墨黑的粗粝唐代边塞；朱砂标记状态；金色只属于点睛、竖瞳和封面强调。
- 姜月初常态必须是黑发高马尾、玄黑赤纹劲装、横刀；用户参考图中的白衣、毛笔、金甲和海报版式不进入常态。
- 音乐以低鼓、弦乐擦奏、木质敲击和稀疏古琴/箫气息构建边塞与悬疑；百妖谱出现时加入纸张、墨滴、低频兽鸣，不做持续轰炸式仙侠金光音效。

## 首批制作验收

- 前3秒有可读视觉问题或危险，不用背景旁白热场。
- 每集至少兑现一个上一集承诺，并打开一个下一集明确问题。
- 姜月初常态与虎妖化分别执行 core_full 五角、turnaround、服装锚和脸锚签收。
- 同 IP 样本只作为高去重市场研究；原图、竞品截图和带水印参考不进入后端。
- 第1集完整链路与高风险妖化/百妖谱 Clip 通过后，才允许3集一批放量。
