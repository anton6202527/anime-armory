# 角色定妆 Prompt

## 用户人物参考图脸锚铁律

姜月初参考图只作为脸部身份锚：只取脸型、五官比例、眼神气质、肤质、体态/年龄感。不得继承原图服装、裸露程度、发型/发饰、表情、姿态、配饰、场景、光色或原图剧情状态；战场形态、觉醒形态、服饰、配饰、武器、法宝、表情与状态必须按小说、角色圣经、identity_registry 的 form/wardrobe_profile 和本镜分镜状态执行。


## 人物/资产脸一致性铁律
任何画面只要出现可辨人物脸或具名角色体貌，无论是角色、VFX、武器、道具、场景还是分镜图，都必须绑定 `identity_registry` 的具体 `CHAR_xx/形态` 并使用同源定妆组锁脸；非角色资产默认 faceless，未显式 face_locked 时不得生成清晰人物脸。

## 全身照鞋靴铁律
人物全身、正面/45°/侧面/背面、三视图/turnaround、全身动作参考必须从头到脚完整入画，鞋靴/脚部清楚可见；半身、脸部特写、手部/局部参考除外。
