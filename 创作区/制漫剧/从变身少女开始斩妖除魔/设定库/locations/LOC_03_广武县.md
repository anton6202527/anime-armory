# 场景卡 — 广武县（ID: LOC_03）

- 建筑/环境风格：边地县城，夯土城墙、实用城门、商旅街与朴素客栈/官署；规模小于凉州都司。
- 时间 / 天气 / 光线：白日黄沙天或室内窗光/油灯；所有光源有方向。
- 主色调 / 氛围：土黄、木褐、暗青灰；短暂休整下仍有通缉与身世压力。
- 空间锁：城门—主街—客栈/官署明确；向金城去的人流方向固定，与第5集姜月初逆人流形成视觉钩。
- 差异锁：不使用凉州都司的黑瓦高墙、铜风铃和暗赤旗纹，避免地理层级同质化。

**Codex 图片 Prompt（中文）：** 唐代陇右边地县城，夯土城墙和实用城门，黄沙商旅街、朴素木结构客栈，土黄木褐暗青灰，真实磨损与有源光，竖屏9:16，国漫写实，不含华丽宫殿、Logo或水印。
