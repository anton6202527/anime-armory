## 关键因果

1. 无力求生 → 杀裴长青取道行 → 同时获得力量、制服线索、冒名条件和道德债。
2. 斩虎并以妖血为墨 → 建立百妖谱循环 → 点睛后才可虎妖化。
3. 穿镇魔司制服被误认 → 被推上救村选择 → 选择回头救人并暴露战力。
4. 金城灭村和猪妖线索 → 真正镇魔司进入 → 个人流亡线与机构调查线汇合。
5. 常规战力不足 + 虎山神点睛 → 首次完整妖化 → 斩朱厌后力竭。
6. 战后身份暴露 → 魏合给出押京或入司选择 → 姜月初以受约束的方式获得生路。

## 力量与状态规则

- 早期境界：凡境 → 闻弦 → 鸣骨 → 成丹。
- 斩杀获得道行；道行投入武学或百妖谱必须记账，不能重复消费。
- 百妖谱固定语法：妖血为墨 → 摹影 → 染朱 → 点睛 → 妖物反馈能力。

- 常态必须黑发、非金色竖瞳、无虎纹；妖化态才血红发、金色竖瞳、手腕至肩臂赤色虎纹；解除后全部复原。
