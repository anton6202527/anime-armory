# 从变身少女开始斩妖除魔_第1集_BGM与音效

整体情绪：尸城冷开压迫 → 朝堂绝境沉重 → 孤身光复燃起 → 系统灌注奇观爆发 → 阴山钩子悬停。

BGM风格：冷灰国风玄幻 / 低频战鼓 / 暗弦乐持续压迫 / 女主爽点用重鼓与铜钹炸点 / 系统与绘卷段加入空灵合成器与细碎金属铃。

段落规划：
- 镜头1-9：低频鼓点慢进，风声与远处残火噼啪作底，女主吸收精气时加入倒吸式气流声。
- 镜头10-16：切朝堂后 BGM 降低，保留沉重弦乐和钟磬尾音，皇帝下旨处给一次重鼓。
- 镜头17-24：重新推回战场，鼓点逐渐加速；镜头23“以一人之力，光复一道之地”落第一次 drop。
- 镜头25-33：识海绘卷段使用鼓点 + 金光升调，系统播报用短促机械低音，赤蛟点睛处给铜钹与龙吟。
- 镜头34-36：BGM 抽真空 0.5 秒，只留面板嗡鸣；“是否开始衍化内景”后悬停低频，不收尾。

关键音效点：
- [镜头1 满城死寂] 远风、残火、血雾低频翻涌。
- [镜头5 系统面板] 清冷电子提示音 + 光幕展开。
- [镜头16 皇帝下旨] 朝堂钟声一记重击。
- [镜头23 爽点] 战鼓 drop + 披风猎猎 + 低频震动。
- [镜头26 灌注] 识海轰鸣、绘卷展开、金光爆裂。
- [镜头30 赤蛟点睛] 龙吟短促上扬 + 金属亮点。
- [镜头35 集尾钩] 面板轻颤、空气抽空、三色光点微鸣。
