## 1. 全书现代剧情理解

全书以西门庆从地方富商攀升为官绅、扩张财富与家庭，再因贪欲和滥权猝死、家业迅速崩解为主轴。潘金莲、李瓶儿、吴月娘、孟玉楼、春梅、陈经济等人的欲望、处境、竞争与结局构成彼此咬合的群像。

前十回先用武松打虎建立“力量与公义”的标尺，再转入潘金莲的婚姻困境、试探武松失败、与西门庆相遇，在王婆撮合下通奸，继而伤害并毒死武大。西门庆以钱权掩盖罪行，武松追索真相却未能立即完成复仇，形成延续至第八十七回的长线因果。

本作不能被改成单纯艳情猎奇。主干是：人物做出选择 → 金钱和权力放大选择 → 受害与掩盖 → 家庭、官场和下层人物共同承担代价 → 权势崩解后旧债回收。

## 4. 主要人物动机

- 西门庆：想把金钱变成欲望满足、财产和官场权力；每次都可以克制，却不断用钱权消除阻力，最终在权势顶点被长期选择反噬。
- 潘金莲：想摆脱低位婚姻和被支配处境，追求欲望、体面与控制权；既是结构中的受困者，也主动成为共谋和伤害者，不能洗白或扁平妖魔化。
- 武松：想保护兄长、查明死因并恢复公道；制度被钱权扭曲后，陷入忍耐取证与直接复仇的冲突。
- 武大：只求靠小生意维持家庭安稳；阶层与身体弱势让他在发现背叛后几乎无力对抗。
- 王婆：利用信息、空间隔离和人情撮合获利；从掮客一步步成为谋杀共犯。
- 吴月娘：维护正妻地位、家产、香火和家庭表面秩序；家主死后转为守家求生。
- 李瓶儿：以感情、财富和儿子寻找归属与安全；得宠、产子后仍无法抵御嫉妒、丧子与死亡。
- 春梅：维护尊严、摆脱婢女身份并获得实际权力；上升后仍可能复制旧宅的权力模式。
- 陈经济：依附西门家获得享乐和翻身机会；不断在承担责任与投机纵欲之间选择后者。

## 5. 必须保留的因果

1. 潘金莲与西门庆相遇 → 王婆逐步设局 → 武大受伤 → 三人选择毒杀灭口。
2. 西门庆买通证人和程序 → 武松无法正常伸冤 → 急切复仇失手并被流配。
3. 西门庆以金钱处理婚姻、法律和官场阻碍 → 家宅、财富和权势扩张 → 内部代价同步增加。
4. 李瓶儿携财入宅、产子得宠 → 成为竞争焦点 → 丧子、病逝 → 西门庆短暂真情却未改变行为。
5. 仆役与下层女性持续承担豪门繁华成本 → 恐惧、死亡、怨恨和背叛累积。
6. 西门庆长期无度并忽视身体警告 → 第七十九回病亡 → 家产和关系网立刻崩散。
7. 潘金莲与陈经济私情败露 → 被逐、被卖 → 王婆交易结构重现 → 武松旧案复仇回收。
8. 西门宅形成的逐利与权力模式继续作用于陈经济、春梅等人 → 后续败亡与群体因果收束。
