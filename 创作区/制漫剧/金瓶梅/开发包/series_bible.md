# 金瓶梅 — P-1 剧集开发圣经（审定稿）

> 审定口径：以《金瓶梅词话》一百回为源，首批精修第一至十回。原文为明清章回白话，不按现代网文逐句改写；先转成现代剧情理解，再保留必要的时代称谓、人物关系与因果。

## 一句话卖点

一桩被钱权压下的命案，撬开清河县豪门百回兴亡：每一次欲望都变成交易，每一次交易都留下终将反噬的债。

## 目标受众

- 18 岁以上、喜欢古典名著新编、世情悬疑、宅门群像、权谋与因果追更的观众。
- 首发形态面向中文竖屏漫剧；平台尚未锁定，母版需保留跨平台裁切、字幕安全区和分级复审能力。
- 卖点不是露骨猎奇，而是“命案真相 + 豪门上升与崩塌 + 女性群像 + 钱权腐败”的连续剧情。

## 叙事中心与人物欲望

- 全剧负向中心：西门庆不断把金钱、情欲与人情转换成婚姻、财富和官场权力，却无法控制由此累积的身体、家庭与制度债务。
- 前十集追剧中心：武松要查明兄长死因、讨回公道；潘金莲要摆脱受困处境并争夺安全与主导；二人的选择被西门庆与王婆的利益合谋推向不可逆冲突。
- 长线群像中心：吴月娘守秩序、李瓶儿求归属、春梅求尊严与上升、陈经济求依附翻身；每条人物线都必须落到可见选择及其后果。

## 长线悬念

1. 武大命案能否越过钱权遮蔽获得真相与公道，武松何时完成复仇。
2. 西门庆靠交易与官商关系能爬到多高，盛极之后谁先反噬他与西门家。
3. 潘金莲进入西门宅后能否获得安全与主导，她从受困者走向共谋者的代价是什么。
4. 李瓶儿携财入宅、产子得宠后，财富与宠爱能否真正保护她和孩子。
5. 家主死亡后，依附于西门家的人、财产和秩序将怎样离散。

## 世界与不可破坏的规则

- 视觉统一为可信的前现代市井社会；承认原著宋代故事时空与明代生活经验交叠，不伪装成单一朝代考据纪录片。
- 权力来自金钱、官职、亲属、性别、主仆和信息差，不引入玄幻、系统、修炼或超能力。
- 钱权交易必须通过银两、账目、印信、礼物、证词与空间等级被观众看见，不能只靠旁白宣布。
- 妻妾、亲属、主仆和官职称谓是权力关系的一部分；“官人、娘子、都头、大娘、小叔”等关键称谓保留。
- 死亡、离散、再嫁、财产转移和官职变化是不可随意重置的连续状态。

## 核心追更快感

- 观众先看到秘密如何形成，再看证据、谎言和利益链一步步收紧。
- 让弱者偶尔识破强者、让掮客的妙计反成罪证、让金钱带来的即时胜利累积成长期反噬。
- 宅门争位不拍成无因果互撕：每次宠爱、财产、子嗣和名分变化都改变下一轮选择。
- 豪门繁华与底层代价并置；宴席越盛，账本、病症、怨恨和失序越清晰。
- 武大命案、李瓶儿母子、西门庆病亡与家业崩解是四个必须完整铺垫并兑现的情感/因果高峰。

## 关键角色弧

- 西门庆：圆滑占有、用钱消障 → 官商扩张、豪门高峰 → 身体失控、猝死 → 利益网络反向瓜分家业。
- 潘金莲：受困而机敏、渴望安全 → 参与合谋与伤害 → 宅门争夺不断升级 → 私情败露、被逐被卖、旧案回收；不洗白，也不扁平妖魔化。
- 武松：英雄与官差 → 程序被钱权击穿 → 急切复仇导致误杀流配 → 长线归来完成追责。
- 吴月娘：正妻秩序维护者 → 在默许、规劝与自保间摇摆 → 家主死后守产、守人、面对离散。
- 李瓶儿：以感情和财产寻归属 → 入宅得宠、产子达峰 → 丧子病逝，证明财富与宠爱不能提供真正安全。
- 春梅：有强烈自尊的婢女 → 借关系摆脱低位、进入权力中心 → 在上升中复制旧宅的欲望与支配方式。
- 王婆：靠信息与空间隔离牟利 → 从撮合者升级为命案共谋 → 晚期再次把女性当交易对象，形成结构回环并承担报应。

## 语言与叙述

- 对白以现代可懂白话为骨，保留关键古称谓与身份差异；禁止逐字硬译、满篇仿古腔和现代网络梗。
- 西门庆圆滑强势，潘金莲机敏锋利，武松短句克制，王婆市井油滑，吴月娘稳重守序。
- “话说、看官、且听下回分解”只作冷开场反讽、转场或集尾章回标识，不连续堆叠。
- 诗词曲仅在承担预示、反讽、人物心境或节奏时保留；其余转换成画面、动作或一句旁白。

## 内容与合规边界

- 成年人物的欲望、通奸、强迫、剥削、家庭暴力、谋杀和人口交易可保留其因果功能，但性行为一律非露骨表达。
- 用门窗、灯影、衣物、声音、视线和事后状态替代露骨身体描写；不情色化未成年人、受害者或羞辱场面。
- 不把强迫、剥削、交易和谋杀浪漫化为纯爱情；不把武大之死或家业崩坏单归咎于女性。
- 公开发行前须按实际平台、地区和分级重新走内容、版权、声音与素材授权审核。
